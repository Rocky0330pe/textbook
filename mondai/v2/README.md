# 問題集 第2巻・第3巻：わざの書き方（書く組への手引き）

第1巻の手引き（`mondai/v1/README.md`）と同じ形で書く。ちがう所だけを、ここに書く。第3巻（`mondai/v3/`）も、この手引きにしたがう。

決めたこと：第28回 M-1〜M-9、第29回 H-1〜H-11、第30回（第2・3巻の目録と書き方）。わざの番号と中身は `v2/CATALOG.md`・`v3/CATALOG.md`。

## 1. ファイル

- わざは組ごとのファイルに書く（`v2/a_*.js` など。組の分け方は CATALOG.md）。形は第1巻と同じ：`(function (M) { 'use strict'; M.add({...}); ... })(globalThis.MONDAI);`
- ほかの組のファイル・`core.js`・`build/*`・`tex/*`・`v2/parts.js` は書きかえない。要るものは報告に書く。
- `require`・`import`・外のライブラリ・`Math.random` は使わない。

## 2. 文の書き方（第2巻・第3巻）

- 教科書 第2巻・第3巻と同じ。**漢字にはかならずルビ**（`《漢字|よ|み》`）。分かち書きはしない（ふつうの日本語の文。句読点は「、」「。」）。
- 使ってよい漢字は、教科書のその巻までで使っている字（`v2/kanji2.txt`・`v3/kanji3.txt`）。`check.js` が確かめる。
- 目印などで強めたい所は `**…**`（本では太字、アプリでは太字と下線）。色だけで示さない。

## 3. 式の書き方：`$…$`（TeX の書き方の一部）

文の中の式は、`$…$` でかこむ。本ではそのまま TeX に、アプリでは HTML の式に組む。

| 書くもの | 書き方 | メモ |
| --- | --- | --- |
| 文字（斜体） | `$3x+2y$` | 文字は1字ずつ。かけ算の × は書かなくてよい（`2x`、`3(x+1)`、`ab`） |
| かけ算・わり算 | `\times`・`\div`・`\cdot` | |
| 分数 | `\frac{3}{4}` | 本では大きい分数（`\dfrac`）になる |
| 指数・下つき | `x^{2}`・`10^{-3}`・`x_{1}` | 2字以上は `{}` でかこむ |
| ルート | `\sqrt{12}`・`\sqrt[3]{8}` | |
| かっこ | `(…)`・`\left(…\right)`・`|x|` | |
| 記号 | `\pm`・`\pi`・`\le`・`\ge`・`\ne`・`\approx`・`\to`・`\infty`・`\%` | |
| 関数 | `\log_{10}2`・`\log_{2}8`・`\sin`・`\ln` | |
| 単位 | `$5\,\mathrm{m}$`・`$3\,\mathrm{km/h}$` | 単位は `\mathrm{}`。**漢字は `$…$` の中に書かない**（ルビがつかない。式の外に書く） |
| 欄 | `$\frac{3}{4}\times\frac{2}{9}=□$` | 式の中の □ も欄になる。□がなければ、最後に「＝ □」がつく |

- `$…$` の中にルビ（`《…》`）や `**…**` は入れない。
- 1つの式は1つの `$…$` にまとめる（`$3x$ ＋ $2x$` ではなく `$3x+2x$`）。

## 4. 答えと検算

- `a` が **式1つ**（`'$\\frac{5}{6}$'`、`'$x^2+6x+9$'`、`'$2\\sqrt{3}$'`）なら、`check.js` が、文字に3とおりの値を入れて次をくらべる。
  - 問題 `q` が式1つ（＋「＝ □」）なら、その値と答えの値。
  - 楽な形 `easy` の中の式（`$…$`。`=` で区切ったどれも）の値と、答えの値（`val` があれば `val` の値）。
- 答えが式でないとき（`'$x=3$'`、`'$x=2,\\ 3$'`、ことば、`'3 けた'` など）は、**`verify: () => true または まちがいの説明`** を書いて、自分で確かめる（方程式は、解を代入して成り立つか、など）。
- `easy` に途中の式を書いて値がそろわないときは `easyCheck: false`。
- 小数の答えは、検算で ずれないように、分数か、決まったけたの小数にする。√・π・log は、答えも `$2\\sqrt{3}$` のように式で書けば検算できる。
- 入れかえただけで同じになる問題（`3+5` と `5+3`、`2x\\times 3` と `3\\times 2x`）は、`key` をつけて同じ見開きに出さない（H-6）。

## 5. 欄の大きさ

- `boxw`：欄のはば（式の答えは広く。例 `'24mm'`）。ステップごとなら `{ s3: '30mm' }`。
- `boxh`：欄の高さ（**分数の答えは `'12mm'`**。ふつうは書かない）。ステップごとなら `{ s1: '12mm' }`。
- 第2巻は、本に書きこむ（答えの欄と、途中の計算の余白）。第3巻は、答えの欄だけ（途中の計算はノート。M-2）。

## 6. 確かめ（かならず）

2. `node mondai/build/check_fits.js 2`：自分のわなに、同じ部のほかのわざが当たらないか（H-1）。当たるときは、easy に行き先、`also` に番号。

4. `tex/mq2.*`・`tex/mq2-body.tex` などの書き出したファイルはコミットしない。
