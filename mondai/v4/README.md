第2・3巻の手引き（`mondai/v2/README.md`）と同じ形で書く。ちがう所だけを、ここに書く。

決めたこと：第28回 M-1〜M-9、第29回 H-1〜H-11、第30回、**第35回 K-1〜K-8**（`v4/CATALOG.md` のおわりの節）。わざの番号と中身は `v4/CATALOG.md`（4-01〜4-99）。

## 1. ファイル

- わざは組ごとのファイルに書く（`v4/a_kakuen.js`・`b_soji.js`・`c_sankakuhi.js`・`d_kansu.js`・`e_vector.js`・`f_kukan.js`）。形は第3巻と同じ（`mondai/v3/a_kansu.js` を見本に）。
- 部の見開き（`v4/parts.js`）は、自分の部の項目の `tsukuro`（作ってみよう 5問）だけを書く。`miwake` の数は変えてよい（見開きに入る数）。
- ほかの組のファイル・`core.js`・`build/*`・`tex/*`・`app/*` は書きかえない。要るものは報告に書く。
- `require`・`import`・外のライブラリ・`Math.random` は使わない。

## 2. 文の書き方（第4巻から）

- 教科書 第4巻と同じ。**ルビはつけない**（`《…》` を書かない）。**常用漢字まで**（`v4/kanji4.txt`。`check.js` が確かめる）。分かち書きはしない。
- 教科書がかなで書く語は、かなのまま：すい（円すい・角すい）、ひし形、おうぎ形、だ円、まさつ、こう配、ひじ、はしご。
- 目印などで強めたい所は `**…**`。色だけで示さない。

## 3. 式の書き方（第2・3巻に足すもの）

| 書くもの | 書き方 |
| --- | --- |
| 角度 | `30^{\circ}`（検算では $\dfrac{\pi}{180}$ 倍として読む。`\sin30^{\circ}` は $\dfrac12$） |
| 点・辺・角・三角形 | `\mathrm{A}`・`\mathrm{AB}`・`\angle\mathrm{ABC}`・`\triangle\mathrm{ABC}` |
| 平行・垂直・相似 | `\ell\parallel m`・`\perp`・`\triangle\mathrm{ABC}\sojisym\triangle\mathrm{DEF}`（∽） |
| ベクトル | `\vec{a}`・`\overrightarrow{\mathrm{AB}}`・大きさ `\lvert\vec{a}\rvert`・内積 `\vec{a}\cdot\vec{b}`・外積 `\vec{a}\times\vec{b}` |
| 成分・座標 | `(3,\ -1)`・`(1,\ 2,\ 2)` |
| 単位 | `5\,\mathrm{cm}`・`0.8\,\mathrm{rad}`・`7.5\,\mathrm{N\cdot m}` |

- 三角比の値は教科書と同じ形（$\dfrac{\sqrt3}{2}$、$\dfrac{\sqrt2}{2}$）。分母の有理化をした形を答えにする。
- **近似値（K-3）**：答えは $\sqrt{\phantom{2}}$・$\pi$ を残した形を正とする。約の値を聞くときは、使う値（$\sqrt2=1.414$、$\sqrt3=1.73$、$\pi=3.14$）とけた（「小数第1位まで」）を問題の文に書き、答えも同じ値で計算する。
- **電卓は使わない（K-4）**：角は 0°・30°・45°・60°・90° と、それを 180°・360° から足し引きした角、15°・75° だけ。ほかの値（$\sin25^{\circ}$ など）がいるときは、問題の文に書く。

## 4. 答えと検算

- 第2・3巻と同じ：`a` が式1つなら `check.js` が `q`・`easy` とくらべる。`\sin`・`\cos`・`\tan` は度（`^{\circ}`）も読む。
- 次の答えは `verify` で確かめる：成分・座標（成分ごとに計算し直す）、角が2つ（$210^{\circ}$、$330^{\circ}$）、ことば（合同条件、「西へ 14 m/s」）、記号（$\overrightarrow{\mathrm{AD}}$）、平面・直線の式（通る点と法線で）、近似値。
- `verify` は、問題を作った数とは別の道すじ（たとえば座標を作って距離を計算する、ベクトルを成分で計算する）で答えを出し直し、答えの文字と同じになるかを見る。

## 5. 図（K-2）

- **ステップ1・2 は図なし**（目録の「図なしの形」）。図はステップ3（とわな）に出す。見わけようはステップ1・2 から作るので図は入らない。
- 図を出す問題は、問題の物に `fig` を足す：`return { q, a, easy, fig: { s: 5, items: [ … ] } }`。
  - 部品は `core.js` の「図（第4巻から）」のコメントにある：`seg`・`poly`・`path`・`circle`・`arc`・`dot`・`label`・`angle`（`n` で2重・3重の弧）・`right`・`par`（平行のしるし）・`tick`（同じ長さのしるし）・`ellipse`・`grid`・`axes`。
  - `s` は1単位の mm（ふつう 4〜6）。図の横はばは 60 mm 以内（本の1列に入る大きさ）。
  - 点の名前のラベルは `'$\\mathrm{A}$'` か、ただの `'A'`（立てた字）。文字の角・長さは `'$\\theta$'`・`'$x$'`・`'5'`。
  - 図は、問題の数と同じ乱数から、おおよそ正しい形で描く。点の位置は数から計算する（目で置かない）。ラベルが線と重ならない向き（`n`・`s`・`e`・`w`…）を選ぶ。
  - 立体（4-19・4-26・4-79）：`const Q = p => M.proj3(p)`（x 右・y おく行き・z 上）で点を紙に写し、`seg`・`poly` でつなぐ。見えない辺は `{dash: true}`。円すい・円柱の底は `['ellipse', 中心, rx, ry, 0, 180]`（前の半分）と `[…, 180, 360, {dash: true}]`（うしろの半分）。長さはかならずラベルで書く。
  - 図のある問題は欄の列を1列（`cols: { s3: 1 }`）にする。
  - 本では、1列のとき図は問題の文の右に置く（`\mqpf`）。アプリでも文の右。
  - ラベルの字のはばは図の大きさに入る（見えないラベルで広げなくてよい）。O の向きは `['axes', …, {o: 'se'}]`、角の文字の距離は `['angle', A, B, C, '文字', r, n, 距離]`。
- 欄の大きさは、問題ごとに `boxw`・`boxh` を問題の物に書いてもよい（`return { q, a, boxw: '30mm' }`）。わざの `boxw` より先に使う。
- 図を見るには：`node -e "require('./mondai/core.js'); require('./mondai/v4/a_kakuen.js'); …"` で `M.figSVG(fig)` を HTML に書き、playwright で画像にして見る（scratchpad の自分のフォルダに置く）。本では `mk_pdf.sh 4` の PDF で見る。
