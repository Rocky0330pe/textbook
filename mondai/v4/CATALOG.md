# 問題集 第4巻『形と向き』 わざの目録（案）

- 目録の組（Q4-R）の案。委員会で番号を決めるまでは、番号・名前・★・組は変わることがある。
- わざの番号は「巻-2けたの通し番号」（例：4-37）。アプリにこの番号を入れると、そのわざの問題のプリントができる（生成AIは使わず、種つき乱数とアルゴリズムだけ。M-9）。
  - 教科書の章（4-8 など）とまちがえないように、本では丸い札「わざ 4-37」で示す。教科書の節は「4-8③」のように、章のあとに丸数字で書く（M-1）。
- ★：1 は教科書 第4巻の中身だけで解ける。2 は少し先（教科書にない公式・くふう。チャレンジ）。第30回の決定と同じく、教科書の章の★（1〜5）とは別の物差し。
- 作：アルゴリズムで問題を作れるか（第28回の区分）。A＝作れる（数や式を選ぶだけ。答えを先に決めて逆に作る）、B＝作れるが工夫がいる（人が書く文・場面の型紙に数を入れる）、C＝作れない（目録から外した。下の「外したもの」）。
  - **図**：問題に図を出すわざ。「図：」のあとに、どんな図か（点・線・角・ラベル）を短く書く。いま足している図の部品（点・線分・多角形・円・弧・矢印・角のしるし・直角のしるし・ラベル・方眼・座標軸）で描ける。
  - **図（立体）**：立体の見取図がいる。いまの部品では描けないので分けた（下の「図がいる問題」）。
  - **（図はステップ3）**：図なしで出せる形（座標・数・ことばだけで聞く）をステップ1・2で先に出し、図の問題はステップ3に足す。
- 組：中身を書く組（ファイル）。部と組は1対1にした（下の「組の分け方」）。
- 第3巻と同じく、答えの欄だけを置き、途中の計算はノートに書く（M-2）。答えが成分・座標・式（$(12,\ -14)$、$x+2y+2z=5$）のときは欄を広くとる。
- わざの数：90（4-01〜4-90）。6部・6組。図を出すわざは16（平面の図13、図（立体）3）。

## 文の決まり（書く組へ）

- 教科書 第4巻と同じ：**ルビはつけない**（常用漢字まで。第13回 L-A）。分かち書きはしない。`《…》` は書かない。
  - 教科書 第4巻が かなで書く語は、かなのまま：すい（円すい・角すい）、ひし形、おうぎ形、だ円、まさつ、こう配、ひじ、はしご。
- 式は TeX の書き方で `$…$` に入れる（第2・3巻の手引き `mondai/v2/README.md`）。第4巻で新しく使う書き方：
  - 角度 `$30^{\circ}$`、点と辺 `$\mathrm{A}$`・`$\mathrm{AB}$`、角 `$\angle\mathrm{ABC}$`、三角形 `$\triangle\mathrm{ABC}$`、平行・垂直 `$\ell\parallel m$`・`$\perp$`、相似 `$\triangle\mathrm{ABC}\sojisym\triangle\mathrm{DEF}$`（教科書の記号 ∽）。

  - 単位は第3巻と同じく `$5\,\mathrm{cm}$`・`$4\,\mathrm{rad}$`・`$7.5\,\mathrm{N\cdot m}$`。
- 三角比・三角関数の値は教科書と同じ：30°・45°・60° は $\sqrt{\phantom{2}}$ の形（$\sin30^{\circ}=\dfrac12$、$\cos45^{\circ}=\dfrac{\sqrt2}{2}$、$\tan60^{\circ}=\sqrt3$）。約の値は $\sqrt2=1.414$、$\sqrt3=1.73$、$\sin45^{\circ}=0.707$、$\sin60^{\circ}=0.866$、$\pi=3.14$、$g=9.8\,\mathrm{m/s^2}$（委員会で決めてほしいこと 3）。

## 部ごとの「見わけよう」「作ってみよう」（案）

- 見わけよう：その部のわざのステップ1・2と、わなをまぜる。答えは「わざの番号」と「楽な形」。使えるわざをすべて書き、わざがないときは「わざなし」（H-2）。
- 作ってみよう：答えが1つに決まらない問い（H-8）。答えの例と、「こうなっていれば正解」という確かめ方をつける（M-5）。

### 第1部　角と円

- 見わけよう：角の問題とおうぎ形の問題をまぜる。$\angle\mathrm{A}=40^{\circ}$、$\angle\mathrm{B}=60^{\circ}$ の三角形でCの外角（4-02）、$\mathrm{AB}=\mathrm{AC}$ で底角50°のときの頂角（4-03）、十角形の内角の和（4-04）、正九角形の1つの内角（4-05。4-04 でもできるが 4-05 が楽）、半径4・中心角90°の弧（4-08）、半径4・中心角2 rad の弧（4-11）、弧8・半径4の面積（4-09）、$\dfrac{3\pi}{4}$ を度で（4-10）、2辺が5 cm と7 cm で角がない三角形が1つに決まるか（4-07。決まらない）。
- 作ってみよう：
  - 1つの内角が整数の度になる正多角形を5つ作ろう。（確かめ：外角 $=180^{\circ}-$内角 が360をわりきる）
  - 弧の長さが $2\pi$ になるおうぎ形を、半径と中心角の組で3つ作ろう。（確かめ：円周 $2\pi r$ に 中心角÷360 をかけると $2\pi$）
  - 半径の比が $1:3$ の2つのプーリーで、小さいほうが6 rad 回る問題を作り、大きいほうの角を答えよう。（確かめ：大きいほうは2 rad）

### 第2部　相似・三平方・面積と体積

- 見わけよう：直角三角形の辺の求め方をまぜる。斜辺10・1辺6（4-20・4-21。4-20 が楽）、直角をはさむ2辺7と24（4-20）、45°で斜辺8（4-22）、30°で斜辺8の短い辺（4-23）、3辺 6、8、11 の三角形は直角か（4-24）、2辺5と7の三角形の3つめの辺（わざなし）、$(1,\ 1)$ と $(4,\ 5)$ の距離（4-25・4-20）、直方体 2、3、6 の対角線（4-26）。面積・体積：円すいの体積（4-29・4-28）、円すいの表面積（4-30）、相似比 $1:3$ の体積（4-18）。
- 作ってみよう：
  - 斜辺が25になる、辺が整数の直角三角形を2つ作ろう。（確かめ：$a^2+b^2=625$。7と24、15と20）
  - 相似比が $2:5$ の2つの立体で、大きいほうの体積を答えにする問題を作ろう。（確かめ：体積は $\dfrac{125}{8}$ 倍）
  - 体積が $12\pi$ になる円すいの、半径と高さの組を3つ作ろう。（確かめ：$\dfrac13\pi r^2h=12\pi$、つまり $r^2h=36$）

### 第3部　三角比と三角形

- 見わけよう：「どの定理を使うか」（教科書 4-7⑤の表）をまぜる。2辺とあいだの角で面積（4-41）、2辺とあいだの角で向かいの辺（4-44）、1辺と両はしの角で辺（4-42）、3辺で角（4-45）、直角三角形で斜辺と角から高さ（4-34）、高さと角から斜辺（4-35）、2辺とあいだでない角（わざなし。三角形が2つかけることがある）。三角比の値：$\sin150^{\circ}$（4-39）、$\cos60^{\circ}$（4-33）、$\sin20^{\circ}\div\cos70^{\circ}$（4-38）。
- 作ってみよう：

### 第4部　三角関数と加法定理

- 見わけよう：$\sin405^{\circ}$（4-48・4-49）、$\cos300^{\circ}$（4-49）、$\cos2\theta$ を $\sin\theta$ で（4-58）、$\sin105^{\circ}$（4-56）、$\sin\theta+\cos\theta$ の最大（4-59）、$\sin\theta=1$ の $\theta$（わざなし。1つだけ）、$\sin\theta=-\dfrac{\sqrt2}{2}$ の $\theta$（4-53）、1分に600回転の $\omega$（4-54）。

### 第5部　ベクトルと内積

### 第6部　空間・外積・いろいろな座標

- 見わけよう：$(1,\ 2,\ 2)$ と原点の距離（4-79）、$(1,\ 2,\ 2)\cdot(2,\ -1,\ 0)$（4-80。直交）、$(1,\ 2,\ 2)\times(2,\ -1,\ 0)$（4-85）、3点の三角形の面積（4-86）、$(0,\ 3)$ に $(4,\ 0)$ の力のモーメント（4-84）、$(-1,\ \sqrt3)$ の極座標（4-88）、北緯60°の $\theta$（4-89）。

## エンジンに要るもの（まとめ役へ。この組では書きかえていない）

- 文：第4巻はルビなし。`check.js` は第3巻まではルビと漢字を調べるが、第4巻（`vol <= 3` の外）では漢字を何も調べない。第4巻用に、`v4/kanji4.txt`（常用漢字表、または教科書 第4巻 `tex/ch4-*.tex` で使っている字）と、「`《…》` を書いていない」「常用漢字の外の字がない」の検査がいる。`badKanji` のエラーの文が「教科書 第1巻にない漢字」のままなので、巻の番号にする。本の組み方（`tex/bk-mondai.sty`）も、第4巻はルビなし・札「式」「答え」（L-A）にそろえる。
- 式（本の TeX とアプリの HTML の両方）：`^{\circ}`（°）、`\vec{a}`（文字の上の矢印）、`\overrightarrow{\mathrm{AB}}`（2文字の上の長い矢印）、`\angle`、`\triangle`、`\parallel`、`\perp`、`\sojisym`（∽。教科書の `bk-honbun.sty` の記号）、`\ell`、`\omega`・`\varphi`・`\theta`、`\lvert\vec{a}\rvert`、`\cdot`（内積）と `\times`（外積）を同じ式にまぜる。`core.js` の記号の表には `\vec`・`\overrightarrow`・`\ell`・`\sojisym` がない。
- 検算：
  - 度の三角関数：`evalMath` は `\sin` をラジアンで計算する。`\sin30^{\circ}`、`\cos(\theta+90^{\circ})` の `^{\circ}` を $\dfrac{\pi}{180}$ 倍として読む。$\theta$ を文字として代入して確かめる式（4-51、4-56、4-58、4-59）も、度で読む。
  - 成分・座標の答え（$(12,\ -14)$、$(1,\ 2,\ 2)$、$\left(\dfrac{\sqrt6}{2},\ \dfrac{\sqrt6}{2},\ 1\right)$）を、成分ごとに `evalMath` でくらべる部品。極座標 $(3\sqrt2,\ 135^{\circ})$ も同じ形。
  - `verify` で確かめるもの：角の答えが2つ（$210^{\circ}$、$330^{\circ}$）、ことばの答え（合同条件、向き「西へ14 m/s」）、記号の答え（$\overrightarrow{\mathrm{AD}}$）、平面の式（$x+2y+2z=5$ は、通る点と法線で確かめる）。
  - 近似値：$\sqrt3=1.73$ か 1.732 かで、小数第1位の答えが変わる（$49\sqrt3$ → 84.8 か 84.9）。答えのけたと、使う値を決めて、問題の文と答えで同じ値を使う部品（`M.approx` のようなもの）。
- 図の部品（いま足しているもの）に、第4巻で要るもの：
  - 使う部品：点・線分・多角形・円・弧・矢印・角のしるし・直角のしるし・ラベル・方眼・座標軸（上の表のとおり）。
  - 足してほしいもの：点線（補助線・のばした辺・回す軸・見えない辺）、平行の印（矢じるし）、等しい長さの印（二等辺三角形）、角のしるしの二重の弧（等しい角）、ラベルが線や角のしるしと重ならない置き方。
  - 問題の数と図の形を、同じ乱数から作る（図の角度・長さを、問題の数どおりに描く）。答えのページの図に、補助線や答えの角を書き足せる（`opt.answer`。ひっ算の図と同じ）。
  - 本の見開きの高さの見積もり（`mq_pages.py`）に、図の高さを入れる。見わけようで図の問題を出すときの、図の大きさ。
  - 図（立体）：頂点の $(x,\ y,\ z)$ をななめに写して紙の上の点にする部品があれば、直方体・角すいは線分と点線で描ける。円すい・円柱・球にはだ円の弧がいる。
  - 曲線（三角関数のグラフ）：細かい点を線分でつなぐ折れ線があれば描ける（第2版の候補）。
