## 3. 検算（第6・7巻で足したもの）

- **複素数**：第6巻から、式に $j$ があれば、`check.js` が $j$ を虚数単位として複素数でくらべる（`M.evalC`）。答え・問題・楽な形のどれでも。
- **微分方程式の解**：`calc: { kind: 'ode', x: 't', coef: [1, 5, 6], rhs: '0', init: [[0, 1], [0, 0, 1]] }`
  - `coef` は高い階から（$\ddot x+5\dot x+6x$ なら `[1, 5, 6]`、$\dfrac{\dd y}{\dd t}+2y$ なら `[1, 2]`）。`rhs` は右辺（$t$ の式。省くと0）。
  - `init` は `[t0, 値, 何回微分したか]`（`[0, 1]` は $x(0)=1$、`[0, 0, 1]` は $\dot x(0)=0$）。
  - 答え（`p.a` の式。`x=` の右）を入れて、左辺＝右辺とはじめの値を数で確かめる。2階までの線形の式に使える。$v'=g-kv^2$ のような式は `verify(p)` で。
- **行列**：`M.Mat`（成分は `M.F` の分数）：`make([[1,2],[3,4]])`・`add`・`sub`・`scale`・`mul`・`T`・`det`・`inv`（なければ null）・`pow`・`eq`・`eye(n)`・`tex(A, { factor: true })`（$\frac{1}{12}(\cdots)$ の形）・`np(A)`（numpy の表示）。
  - 行列の答えは `calc: { kind: 'mat', want: A }`（`want` は `M.Mat` の行列か、数・TeX の2重の配列）。答えの pmatrix と成分ごとにくらべる。
- 固有ベクトル（何倍でも正）・答えの組・プログラムの表示は `verify(p)`。

## 4. 図・表・プログラム

- 図はステップ3とわなだけ（K-2）。グラフは `M.graph`（第5巻）。
  - 複素平面：`const G = M.cplane({ x0: -3, x1: 3, y0: -3, y1: 3, w: 6, h: 6 })` → `...G.axes({ xt: [-2, 2], yt: [-2, 2] })`（軸の名前は Re・Im、目もりは $2j$）、`...G.point(2, 1, '$2+j$', 'ne', true)`（点とラベル。最後を true で原点からの矢印）。
  - 傾きの場：`...G.field((t, y) => 2 - 0.5 * y, [0.5, 1, 1.5], [0.5, 1.5, 2.5])`（方眼の点ごとの短い線分）。
  - ばね・抵抗（第7巻）：`...M.figSpring([0, 0], [3, 0], { n: 6 })`、`...M.figResistor([0, -2], [3, -2])`。曲がった矢印は `['arc', C, r, 度0, 度1, { arrow: true }]`。
- **表**：`return { q, a, table: { head: ['$t$', '0', '0.1'], rows: [['$T$', '80', '□']] } }`。表は問題の文の下に出る。表のセルに □ を書いたら、問題の文には □ を書かない（欄はどちらか1つ）。
- **プログラム**：`return { q: '次のプログラムで表示される数', a, code: 'x = 1\nfor k in range(3):\n    x = 2 * x\nprint(x)' }`。等幅の枠で、文の下に出る。
- 行列・表・プログラムは高いので、見開きに入る数に気をつける（`mk_pdf.sh` であふれないか確かめる）。
