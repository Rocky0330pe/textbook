## 4. 答えと検算（第5巻で足したもの）

- **calc**：問題の物に `calc` を書くと、`check.js` が数値で確かめる（`core.js` の `M.calcCheck`）。
  - `calc: { kind: 'diff', f: '(2x-5)^4' }`：答え（`p.a` の式。`f'(x)=…` なら ＝ の右）が `f` の導関数か。展開した形もしない形も通る。
  - `calc: { kind: 'int', f: '3x^2' }`：答え（`+C` つき）が `f` の不定積分か。`+C` がないとまちがい（L-5）。
  - `calc: { kind: 'defint', f: 'e^{-x}', a: 0, b: 1 }`：答えの値が、`f` を a〜b で積分した値か。`a`・`b` は `'\\frac{\\pi}{2}'` のような TeX でもよい。
  - 変数が x でないときは `x: 't'`・`x: '\\theta'`。くらべる点は `pts: [0.5, 1.2, 2.3]`（ふつうは 0.37・0.83・1.29。√ や ln の中が負にならない点にする）。答えが式でないとき（`f'(x)=` のあとに文があるなど）は `ans: '…'` に式だけを書く。
- 極限・Σ・接線の式・極値と x の組・答えが2つ・初期条件の式・近似値は、これまでどおり `verify(p)` で、別の道すじで確かめる（極限は小さい h を入れる、Σ はそのままたす、接線は接点と傾き、など）。
- **多項式の部品 `M.P`**：係数は `M.F` の分数。`M.P.make(1, -2, 0, 3)` は $3x^3-2x+1$（低い次から）。`add`・`mul`・`pow`・`diff`・`integ`・`at`（分数で代入）・`val`（小数で代入）・`tex(P, 'x')`。問題と答えを同じ多項式から作ると、まちがいが入りにくい。

## 5. 図（グラフ）

- 第4巻と同じく、ステップ1・2 は図なし、図はステップ3とわなだけ（K-2）。
- グラフは `M.graph` で描く：

```js
const G = M.graph({ x0: 0, x1: 3, y0: 0, y1: 9, w: 9, h: 6 });   // x と y で別の倍率。w・h は図の単位（ふつう w 8〜10、h 5〜7）
const fig = { s: 5, items: [
  G.area(x => x * x, null, 1, 2, { hatch: true }),   // y=x^2 と x 軸のあいだ（1〜2）を斜線でぬる。fill: true でうすくぬる
  ...G.axes({ xt: [1, 2, 3], yt: [4, 9], x: 't', y: 'v' }),   // 座標軸と目もり
  ...G.plot(x => x * x, 0, 3.2),   // 曲線（折れ線。わくの外で切る）
  ['seg', G.T(1, 0), G.T(1, 1), { dash: true }],   // 点の位置は G.T(x, y) で
  ['label', G.T(2.6, 7), '$y=x^2$', 'w'],
] };
```

- 横軸の上と下（正と負の面積）は、色だけでなく、斜線とうすいぬりで分ける（M-7）。
- 目もりの数は問題の数と同じにする。図の横はばは 60 mm 以内。図を読んで答えが出てしまわないように、目もりは問題に要る所だけにする。
