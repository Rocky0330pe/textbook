## 3. 検算（第8・9巻で足したもの）

問題の物に `calc` を書くと、`check.js` が答え（`p.a`。「＝」があれば右）を数でくらべる。`calc` の中の式（`f`・はし・道・`want`）は、TeX でも、ふつうの書き方（`'x*y^2'`・`'cos(t)'`・`'2*pi'`・`'sqrt(1-x^2)'`・`'theta'`）でもよい。`'4e-5'` は $4e-5$ と読まれるので、10のべきは数（`4e-5`、JS の数）か TeX（`'4\\times10^{-5}'`）で書く。

| kind | 書き方の例 | くらべ方 |
| --- | --- | --- |
| `pdiff`（偏微分） | `{ kind: 'pdiff', f: '3x^2y', vars: ['x', 'y'], wrt: ['x'] }`（2回は `wrt: ['x', 'y']`・`['x', 'x']`） | 中心差分と、いくつかの点でくらべる。展開した形もしない形も通る |
| 点の値 | `{ kind: 'pdiff', f: '100-0.01x^2-0.02y^2', vars: ['x', 'y'], wrt: ['x'], at: [30, 20] }` | 答えは数 |
| 欄が2つ・3つ | `{ kind: 'pdiff', f: '3x^2y', vars: ['x', 'y'], wrt: [['x'], ['y']], ans: ['6xy', '3x^2'] }` | `ans` に欄の順で |
| 勾配 | `{ kind: 'pdiff', op: 'grad', f: 'x*y^2+2z', vars: ['x', 'y', 'z'] }`（点なら `at: [1, 2, 3]`） | 答えは成分の組 `$(y^2,\ 2xy,\ 2)$` |
| 発散 | `{ kind: 'pdiff', op: 'div', f: ['2x+y', 'x-3y'], vars: ['x', 'y'] }` | `f` は成分の配列 |
| 回転 | `{ kind: 'pdiff', op: 'rot', f: ['3y', '-2x'], vars: ['x', 'y'] }`（3次元は3成分で、答えは成分の組） | 平面は $\dfrac{\partial F_y}{\partial x}-\dfrac{\partial F_x}{\partial y}$ |
| ラプラシアン | `{ kind: 'pdiff', op: 'lap', f: 'x^2+y^2-2z^2', vars: ['x', 'y', 'z'] }` | 熱方程式・波動方程式に代入する問いは `wrt: ['x', 'x']` などを組み合わせる |
| `defint2`（2重・3重積分） | `{ kind: 'defint2', f: 'x*y', x: [0, 2], y: [0, 'x'] }` | はしに相手の文字がある方が内側。順を決めるなら `ranges: [['x', 0, 2], ['y', 0, 'x']]`（外側から。3つで3重） |
| `polar`（極座標） | `{ kind: 'polar', f: 'r^2', r: [0, 3], theta: [0, '2*pi'] }` | $r\,\dd r\,\dd\theta$ の $r$ はこちらでかける（`f` にかけない）。`r` のはしに `theta` を書ける |
| `line`（線積分） | `{ kind: 'line', r: ['cos(t)', 'sin(t)'], t: [0, '2*pi'], F: ['-y', 'x'] }`・`{ kind: 'line', path: [[0, 0], [1, 0], [1, 1]], F: ['y', 'x'] }` | ∫F·dr。`f: '1', ds: true` で ∫f ds（針金の質量）、`f` と `dx: true` で ∫f dx |
| `vec`（成分の組） | `{ kind: 'vec', want: [-0.6, -0.8] }`・`{ kind: 'vec', want: ['2*x*y', 'x^2+1'], vars: ['x', 'y'] }` | 成分ごと。複素数は `complex: true` |
| `fn`（式を値でくらべる） | `{ kind: 'fn', want: '2/(s^2+4s+3)', vars: ['s'] }` | $s$・$t$・$\omega$ は半端な数、$n$・$k$・$m$ は整数1〜6を入れる。極（読めない・大きすぎる点）はよける。$j$ があれば複素数。部分分数の形も展開した形も通る |
| ほかの文字 | `consts: { zeta: 0.5, omega_n: 2, R: 2 }` | 下つきの文字は `'omega_n'`（`\omega_{\mathrm n}`）・`'varepsilon_0'`・`'x_1'` の形 |
| `mat`（$t$ の式の行列） | `{ kind: 'mat', vars: ['t'], want: [['exp(-4t)', 't*exp(-4t)'], [0, 'exp(-4t)']] }` | $t=0$・0.37・1.13 でくらべる（$t=0$ で $I$ になることも確かめられる）。前の $e^{-4t}$・$\frac12$ も読む |

## 5. 表：表計算の画面の形（8-03・8-06・8-09）


## 6. 本とアプリで見るときの注意（事務局が見たこと）

- 本の数式の書体（Latin Modern Math）には、∂・∬・∭・∮・∯・∇・ℒ・ζ・τ・Θ がある（字が欠けた警告なし）。
- アプリの数式は端末の書体（Times New Roman など）で組む。∬・∭・∮・∯ は書体にないことがあるので ∫ を重ね、輪は線でかいた。ℒ（`\mathcal L`）は端末の数学用の書体（Cambria Math・STIX Two Math・Noto Sans Math など）で出る。どれもない古い端末では字が出ないことがある（そのときも、本の答えは変わらない）。
- アプリの図のラベルの分数は「a/b」の1行になる（分母が2字以上なら「2/(3π)」と（ ）に入れる）。本では分数。ラベルに高い式（行列・Σ）を書かない。
- アプリの `\mathrm{grad}`・単位は、文の書体（Klee One）で出る（第4巻からと同じ）。
- 矢印の場の短い矢印は、矢じりも小さくなる。それでも点の間が 5 mm より小さいと見えにくいので、図は `s: 5`、グラフの `w`・`h` は 8 くらいにする。図の横はばは 60 mm 以内。
- アプリの第8・9巻のタブは、わざが0このときも出る（「この巻のわざは、まだありません」）。第8巻からのアプリの組み方（かっこののび・上下つきの重ね・長い上線・∗）は、第7巻までのプリントには出ない。
