## 0. 読み方と約束

### 0-1 番号とことば
- 指導要領の番号とことばは `guide-shidou.md` のとおり（例：`小3-A(4)ア(ｴ)`、`中2-C(1)`、`数Ⅱ-(4)ア(ｴ)`、`範囲外-行列`、`大-線形1`）。項目名はそこにある語を短く写した。
- 「学年」の高校の欄は、科目名に、`guide-shidou.md` 第4節の**一般的な例**（数Ⅰ・数A＝高1、数Ⅱ・数B＝高2、数Ⅲ・数C＝高3）を添えた。指導要領の規定ではない。

### 0-2 「扱い方」の記号（第1部の表）

| 記号 | 意味 |
| --- | --- |
| **同** | 指導要領とほぼ同じ範囲・深さで扱う |
| **詳** | くわしく（指導要領より深い・広い。証明を2通りにする、一般の形まで進む など） |
| **先** | 先取り（その巻の「学年の目安」が、指導要領の学年より下） |
| **後** | 後回し（その巻の「学年の目安」が、指導要領の学年より上。例：小3の内容を第4巻で） |
| **一部** | 一部だけ（語・考えの一部、「もっと知りたい」だけ、コラムだけ など） |
| **なし** | 扱わない（原稿の全文検索と小見出しで見つからなかった） |

「先」「後」は、`series.py` の巻の「学年の目安」と、指導要領の学年をくらべた結果。内容の深さ（同・詳・一部）とは別に書く（例：「同・先」）。

### 0-3 確かめ方
- 原稿は、ルビ `\R{親字}{よみ}` を外し、第1〜3巻は分かち書きの空白も外した全文で検索した（第1巻は「ひっ算」「時こく」のようにかなで書く語があるので、かなの形でも検索した）。章の小見出し（`\bksubsection`）と「もっと知りたい」（`motto`）の題はすべて一覧にして照らした。
- ファイル `ch2-3.tex`・`ch2-3-mondai.tex`・`ch8-9.tex`・`ch8-9-data.tex` は古い見本なので、検索から外した。
- 「〔未〕」＝確かめきれなかったもの。原稿の該当場所の題（小見出し・もっと知りたい・例題）を「 」で示した所は、原稿で確かめた。
- 第6〜9巻は、章の小見出しと、検索した語で確かめた（本文を1章ずつ通読はしていない）。

### 6-3 資料どうしの食いちがい
1. **第4巻の学年の目安**：series.py・guide-series は「中学2年〜高校2年」、仕様書4章の表は「中学2年〜高校1年」。第13回（その2）議事録 L-C で「学年の目安は『中学2年〜高校2年』」と決めているので、series.py が新しい。仕様書4章の表（ページ数・状態の列も第10回ごろのまま）は直していない。
2. **第5巻の学年の目安「高校1年〜2年」**：数Ⅲ（一般的な例では高3）の内容（5-5・5-6・5-14〜5-16）が入っている。目安は「この順で学べば」の意味か、学校の学年か、ガイドブックで書き分けが要る。
3. **9-7 →「3-8 の多項式のわり算」**：9-7 の本文に「3-8 の多項式のわり算で 2s＋5＝2(s＋2)＋1」とあるが、3-8 には多項式のわり算の節も語もない（3-8 にあるのは展開・因数分解・恒等式・係数比較・平方完成）。原稿の参照の誤りの可能性。
4. **5-17 →「下に凸、5-7」**：5-17 に「下に凸、5-7」とあるが、5-7 の本文に「凸」の語はない（5-7 は「2回微分で、山と谷を見分ける」）。
5. **構成案「集合と論理 ― 4-1の『命題』の範囲だけ」**：4-1 の原稿に「命題」の語はない（仮定・結論・逆・反例はある）。
6. **構成案「漸化式はオイラー法（6-2）の形でだけ」**：6-2 には「漸化式」の語はないが、7-10 は題名が「漸化式とオイラー法を行列で」で、等比数列・等比級数も名前を出して扱う。仕様書の「省く単元」の書き方より広い。
7. **guide-series 4-5「2-6（測定値の平均・ドットプロット）」**：2-6 の紙面は点を並べた図で名前は付けていない（「点の図」「ドットプロット」は原稿のコメントにだけある。10月30日 委員確認 rA で確かめた）。
