## 共通の決まり（第7巻と同じ）

- 直したあとも章は偶数ページ（奇数だと「メモ」のページが入る）。確かめ：`cd /home/claude/work/build && python3 tools/tryv.py 8-N <scratchpad の画像フォルダ> --kotae`（エラー0・1.7pt 超のはみ出し0・ページの下へのはみ出し0・行末の記号0）。直したページは画像で見る。全巻の組み直しは事務局。
- 数を直したら Python で検算し、同じ数が出てくるほかの所もそろえる。
- **章末問題の★**：基本は章の★の低いほう、チャレンジは高いほう。★が1つの章（(4,4) など）は、チャレンジを1つ上げる（8-2・8-5 のチャレンジは★5）。
- **記号と単位が並ぶ所は単位を〔 〕**（「密度 $\sigma$〔kg/m²〕」）。グラフの軸と数の組の単位は（ ）。
- **途中式の分数**は、別の行に立てた式では \dfrac か \frac（文中の小さな分数にしない）。文中では行間がのびないよう \tfrac か「a/b」。
- **「rot＝0 なら勾配で書ける」には必ず「すきまのない広がりの中なら」をつける**（物理 力-4 と 8-10 の言い方）。
- 章の書き出し（はてな？の前後か、思い出そうのあと）に、心理士の「1回でわからなくても大丈夫」の声かけを1か所。
