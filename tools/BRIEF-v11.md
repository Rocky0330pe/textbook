### 2-4（X10）分数のわり算
いまの「面積図で ÷3、×4」の説明は残し、その**前か後に、依頼者の示した説明を1つの節としてていねいに足す**。
1. わり算は分数で書ける（2÷3＝2/3。2-4 の前半）。だから (2/5)÷(3/4) は、分子に 2/5、分母に 3/4 がある「分数の中に分数が入った形」に書ける。図（大きな分数の線の上下に分数）を描く。
2. 「分子と分母に同じ数をかけても、分数の大きさは変わらない」理由：同じ数どうしのわり算は 1（1÷1＝1、4÷4＝1、(4/3)÷(4/3)＝1）。だから「分子と分母に同じ数をかける」は「1 をかける」ことと同じで、大きさは変わらない。約分・通分（2-4 の前半）で使ったきまりと同じだと書く。
3. 分母の 3/4 を 1 にしたい。3/4 に何をかけると 1 になる？ → 4/3（3/4 × 4/3 ＝ 12/12 ＝ 1。面積図や数直線でも確かめる）。分子と分母の両方に 4/3 をかける。
4. 分母が 1 になったので、答えは分子の 2/5 × 4/3。だから「わる数の分母と分子を入れかえた数（逆数）をかける」ことになる。ここで初めて**逆数**という名前を出す。
5. もう1つの数の例（整数でわる：(2/5)÷3、3＝3/1 の逆数 1/3）と、小数や帯分数の例。
6. 確かめ：答え×わる数＝わられる数 になることを計算して見せる（8/15 × 3/4 ＝ 2/5）。
7. まちがえやすいところ：わられる数の方を逆にしてしまう、かけ算でも逆にしてしまう、など。
説明は「考えている倍は丁寧に」。1ページに1つの考えで、図を毎回つける。

### 2-11（X12）計算の順番
「かっこの中が先」「×÷ が ＋− より先」を、**なぜそう決めたのか**から説明する節を足す（数ページ使ってよい）。
- きまりがないと、同じ式から人によってちがう答えが出てしまう。例：2＋3×5 を左から計算すると 25、×を先にすると 17。答えが2つあると式で伝えられない。だから世界中で1つの約束にした。
- なぜ「×÷ が先」なのか：×は「同じ数のまとまり」（第1巻 1-12）。3×5 は「5 が 3 こ」という1つのかたまり（1つの量）を表している。買い物の例：「100 円のりんごを 3 こと、50 円のみかんを 1 こ」→ 100×3＋50。かけ算の部分が「りんご全部の代金」という1つの量なので、先に1つの数にまとめる。面積の例（L字の部屋の面積）、時間と速さの例など、**3つ以上の場面**で同じことを確かめる。
- なぜ「かっこの中が先」なのか：かっこは「ここを1つのまとまりとして先に考えて」という印。5×5 を (2＋3)×5 と書いたら、2＋3 が 1 つの数 5 のかわりなので先に計算する。かっこをつけずに 2＋3×5 と書くと 17 になり、5×5＝25 と合わない（依頼者の例）。ほかにも、「2人分のケーキとジュースの代金 (300＋100)×2」など。
- 順番をまちがえたときに、答えがどうおかしくなるかを例で見せる。
- 例題・じぶんでとこうに、順番をまちがえやすい式と、文章から式を作ってかっこが要るかを判断する問題を足す。

### 5-4（X13）立方体の図

### 5-6（X15）積の微分
「最後の項は f′×Δg に近づき、Δg は 0 に近づくので 0 になる」を、次のように書き直す（数ページ使ってよい）。
- 3つめの項は (Δf/Δx)×Δg。前の部分 Δf/Δx は Δx→0 で f′（決まった数。たとえば 3）に近づく。後ろの部分 Δg は「g の変化そのもの」で、**Δx でわっていない**。Δx が 0 に近づくと g の変化 Δg も 0 に近づく。だから積は「3 × ほとんど 0」で 0 に近づく。
- **Δg/Δx とのちがい**をはっきり書く：Δg/Δx は、分子 Δg も分母 Δx も小さくなるので、割った値は 0 にならず g′ に近づく（例：g＝x² なら 2x に近づく）。Δg だけなら 0 に近づく。表で並べる（Δx＝0.1, 0.01, 0.001 のときの Δg と Δg/Δx。f＝x²、g＝x³、x＝1 などで計算）。
- 図では、右上の小さな四角（面積 Δf×Δg）は、まわりの帯（g×Δf や f×Δg）よりずっと速く小さくなることを、Δx を半分・半分にした図を並べて見せる。

### 5-10（X16・X18）定積分
いまの「右はしの長方形の和」の説明の前に、**(k/n)² がどこから来るか**を図で1段ずつ書く。
1. 0 から 1 までを n 等分する。1 つの長方形のはばは 1/n（なぜ：長さ 1 を n こに等しく分けるから）。
2. n＝4 の図：区切りの目もりに 1/4、2/4、3/4、4/4 と書く。k 番めの長方形の右はしは x＝k/4（なぜ：はば 1/4 を k こ進んだ所だから）。
3. 長方形の高さは、右はしでの y＝x² の値。k 番めなら (k/4)²。図の各長方形の上に (1/4)²、(2/4)²…と書く。表にもする。
