## 1. シリーズの設計

### 1-1 目的

- 国の方針で、工学の研究を発展させるために小学校〜高校の算数・数学カリキュラムを一新する。その教材として、小1の「リンゴは何個？」から、工学部で使うベクトル解析・ラプラス変換・フーリエ解析・行列・微分方程式までを、一続きの9巻で学べる教科書を作る（仕様書 2章）。
- 入試のための「発想力の数学」ではなく、「物理や工学の現象を説明するための数学」を、子どもの「なぜ？」に答えながら教える。この教科書を終えて大学の専門書を読むと、すんなり頭に入る状態を目標にする。
- 書名は第11回で「物理を理解するための数学」に変えた（旧「物理現象を理解するための数学」）。

### 1-2 設計思想（編集方針10項目と、書き方の原則）

編集方針（第1回、構成案・仕様書 5章）

1. 量＝数値×単位から出発する。「5」ではなく「5 m」。
2. 具体→表→グラフ→式の順。式は「表とグラフを短く書く方法」として最後に出す。
3. 大学まで続く種を早くまく（ひき算＝変化量、かけ算＝面積、九九の表＝行列）。7本の路線でつなぐ。
4. 微分方程式は「次の瞬間を決めるルール」。式で解く前に表計算で解く。第6巻を全巻の乗りかえ駅にする。
5. 計算の量より意味。九九と筆算は第1巻で手でできるまで練習し、第2巻からは電卓・表計算・プログラムに任せる。
6. どの章も実験や現象とセット。大学の章も、家や教室で確かめられる現象から入る。
7. 物理や工学で使わない単元は省くか軽くする（統計は戻した）。
8. 大学の内容も中学生の言葉で。「目でわかる→手でわかる→式でわかる」の3段で、前の2段は★★★以下の道具だけ。
9. 専門書の書き方に慣れさせる。新しい記号は1章に2つまでで、読み方・意味・英語を記号カードで示す。
10. 学年ではなく、★と道しるべで進む。

子どもに伝わる書き方の原則（仕様書 5章の1〜10、第11回追補の11〜14）から、ガイドブックで紹介しやすいもの

- **名前は最後**：場面 → ふしぎ・こまったこと → 手を動かす（はかる・数える・表にする・図をかく）→ 気づく → ことば・記号・式、の順に書く。新しいことばは体験のあとで「このことを〇〇といいます」と1回だけ紹介する。
- **公式は作ってから使う**：表や図でいくつかの数で同じことが起きるのを確かめてから、きまりにする。
- 数字と文章だけで説明しない（新しい考えには必ず図）。例題は考え方と途中式を1行ずつ全部書く。
- 式が出てくるたびに「なぜその式になるのか」、数が出てくるたびに「なぜその数なのか」を書く。初めての考え方は2通り以上で説明する（第11回）。
- 例題で見せていない形を、じぶんでとこう・章末問題に出さない。
- 工学につなげる：本物の機械・しくみで、その章の数学がどう働いているかを見せ、大学の工学への「種」を1つ入れる。
- 数学としてあとで困る言い方をしない（「かけ算すると大きくなる」と言い切らない、「0でわる」はできないと書く、√ は＋のほう）。たとえ話には「せいかくに言うと」を添える。

### 1-7 紙面の部品と使い方

章の基本の流れ（第2巻から）：章の帯 → 道しるべ → できるようになること → はてな？ → やってみよう → 思い出そう → 数学の道具（小見出し①②③…）→ もっと知りたい → たいせつ → この章で出てきたことば・記号カード → 例題とじぶんでとこう → まちがえやすいところ → 物理・工学ではこう使う・コラム → 章末問題（基本・チャレンジ）→ ふりかえり・ふきだし。第11回からページ制限をなくしたので、章の長さは章ごとにちがう（1章14〜32ページなど）。

### 1-8 第6巻以降の型：3つの段と「名前と実際の操作」

原稿を調べると、「3つの段」には2種類ある。

**(1) 章の3段：目でわかる → 手でわかる → 式でわかる**（\bkstage）

- 大学の内容を中学生の言葉で書くための型（編集方針8）。「目でわかる」（図と実験）と「手でわかる」（表計算・プログラム）は★★★以下の道具だけでたどれ、「手でわかる」の終わりに「ここまでで十分」の旗を立てる。そのあと「式でわかる」で★★★★★の式を作る。
- 原稿でこの3段を使っている章：6-10〜6-14、7-7〜7-10、8-1〜8-13（8-5 は2段）、9-1〜9-11。

**(2) 「名前」と「実際の操作」の型：名前の段 → 直す段 → 楽をする段、場合分けの表、流れ図**

- 依頼者の指示（10月29日）「操作の名前と実際の操作の違いは相当わかりにくく、どのような操作をすれば求められるのかも場合によりけりなので、この場合はどうすれば良いのかを丁寧にする必要がある」を紙面にした型（tools/kata8-int.md・kata9-int.md）。
- 考え方：∬・∫_C・∯ や $a_n$・$F(\omega)$・$\mathcal L[f(t)]$・$G(s)$・$e^{At}$ などの記号は**操作の名前**で、記号を見ただけではまだ計算できない。実際の値は、第8巻では「ふつうの定積分（第5巻）のくり返し」に、第9巻では4つの道具（ふつうの定積分／表を引く／部分分数／行列の計算）のどれかに直して求める。
- 3つの段：①**名前の段**（記号を読む：何を・どこで・1枚の量）→ ②**直す段**（場所を数で表す→1枚の量を書く→範囲を決める→ふつうの定積分などを計算）→ ③**楽をする段**（対称性・分ける・定理で取りかえる・数値で）。③は直す前に必ず確かめる。札の形（点線の枠・実線の枠・ぬりつぶし）で見分け、色だけにたよらない。章の3段（目・手・式）とは別もので、その1つ下の段。
- **場合分けの表**（列：記号／こんなとき（見分け方）／手順／例題）と、**流れ図**（ひし形の問いと四角の手順だけ）を見開きに置き、その章のすべての例題を流れ図でたどれるようにしてある。

## 4. 指導要領と照らすときに気をつけること

### 4-1 学年の目安・★・指導要領の学年は、それぞれ別もの

- 巻の「学年の目安」は編集のための目安で、生徒用の紙面には書かない。章の★は「今の課程での内容の高さ」（★＝小4まで、★★＝小5〜中1、★★★＝中2〜高1、★★★★＝高2〜高3、★★★★★＝大学）。だから、巻の学年の目安の外にある内容が、その巻にまざっている。
- 学年の目安の書き方が資料でちがう：第4巻は series.py で「中学2年〜高校**2**年」、仕様書 4章の表で「中学2年〜高校**1**年」。構成案（第1〜2回）では第1巻 21章・第5巻 19章・全151章など、今と数がちがう所がある。ガイドブックは series.py（と pages_actual.json）の値にそろえること。
- 第2巻は「小学4年〜中学1年」の1冊に、小学校と中学校の内容がまざる。学校の学年に合わせて読むなら、章ごとに分けて照らす必要がある。

### 4-2 学年をまたぐ章（★が範囲の章）

★が範囲になっている章は34ある：2-2・2-4・2-5・2-6・2-7・2-10・2-15（★〜★★）、3-2・3-3（★〜★★）、3-8〜3-12（★★〜★★★）、4-1・4-3・4-6・4-11（★★〜★★★）、4-2・4-5（★〜★★）、4-8・4-12（★★★〜★★★★）、4-14・4-15（★★★★〜★★★★★）、5-10（★★〜★★★★）、5-14（★★★〜★★★★）、6-5・6-15（★★〜★★★）、6-7（★★★〜★★★★）、6-10・6-11（★★★★〜★★★★★）、7-11・9-12・9-13（★★★〜★★★★★）。
このような章は、1つの章が指導要領の2つ以上の学年・科目にまたがるので、「できるようになること」の項目ごと（各項目に★がある）に照らすとよい。

### 4-3 章の★より「できるようになること」の★が高い章

章の帯の★の範囲をこえる項目がある（series.py と原稿の goal の★を比べた）。照らすときは項目の★のほうを見ること。
