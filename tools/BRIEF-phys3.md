## 2. 第3巻の決まり（第24回で決めたこと。くわしくは `docs/議事録/第24回編集委員会_議事録_物理第3巻の計画.md`）
1. **ファイル**：章は `tex/p3-NN.tex`（波-0 が `p3-00.tex`）。章ごとの絵の部品の名前は `rx`＋章の番号の英小文字（波-1→`rxb…`。第1巻の `px…`、第2巻の `qx…` とぶつけない）。ラベルは `ph:波-4:sec6` の形。共通のファイル（`tex/bk-*.sty`、`tex/ph3-*.tex`、`phys/*.py`、`tools/*`）とほかの組の章は書きかえない。要るものは報告に書く。
2. **章の★と3段（W-1）**：章の★は `phys/series_phys.py` のとおり。3段にする章は、★5 をふくむ波-2・3・4・6・7・11・13。章末問題の基本は章の★の低いほう。低いほうが★1・★2 で計算の問題が入らないときは★3 にしてよい（第22回 T-4）。基本には、基本の★の段の道具で解ける問題だけを入れる（第23回 U-2）。
3. **記号（W-2〜W-5）**：振幅 $A$（複素振幅だけ $X$）。波の速さ $c$（高校の $v$・$V$ は「思い出そう」で一言）。$c$ は、第1部は減衰係数、第2・3部は波の速さ、第4部は光速。同じ章で2つの意味にしない。ふりこの長さ $l$。角振動数 $\omega$ と角速度、ばね定数 $k$ と波数、強さ $I$ と慣性モーメント、などのぶつかりは、計画書 C-1 の分け方に従い、記号カードに書く。記号カードは、その記号がはじめて出た章だけに置く（U-6）。
4. **数学との重なり（W-6）**：数学 6-6〜6-14・9-8〜9-12 で計算が済んでいる所は、物理の章では「モデルの仮定・実物の値・仮定がくずれるとき」を主にし、同じ計算は数学の章を「（6-13⑩）」の形で指す。章が短くなってもよい。
5. **音速（W-7）**：気体の音速 $a=\sqrt{\gamma R_{\mathrm s}T}$ は熱-4 ⑥で導いた。波-9 は熱-4 ⑥を指し、液体・固体の音速と、波動方程式からの導き方（波-5）で広げる。
6. **後の巻の結果（W-8）**：波-13 で、電-15 の「出す光の強さは加速度の2乗に比例」を結果だけ使ってよい（「物理シリーズの『電磁気学』（電-15）で導く」と書く）。
7. **RLC 回路（W-9）**：電気の法則は導かない。「同じ形の式」として相似の表と共振だけに使う。
8. **第1巻・第2巻との約束**：第1巻が『波動』に送った約束（計画書 A-6 の表）は、割りふった章で必ず果たす（例：ふりこ・単振動は波-1）。第2巻の章を指すときは、熱の原稿（`tex/p2-NN.tex`）の節の番号・記号・数にそろえる（熱-4 ⑥の音速 $a$、熱-3 の $\gamma$、熱-11 の差分と変数分離、熱-13 の波長の予告、熱-14 の分子の速さ）。第2巻では、セルシウス温度は $\theta$、温度の差は K。
9. **数学の本の約束**：数学の本が「物理シリーズ（波動）で扱う」と書いた所（例：9-9:900 のラウスの表、7-8:794 の質量行列）は、計画書 C の表のとおり、割りふった章で必ず扱う。数学の本の文・数は変えない。
10. **数学の本に足りない道具**：計画書 C の表（楕円積分、質量行列のある固有値問題、ラウスの表、はりの振動の4階の式、ベッセル関数、分散関係と群速度、窓関数、情報量、球面波）は、物理の章の中で作るか、名前と値の表だけにする。
11. **漢字・書き方**：高校卒業程度（常用漢字はふつうに使う。周り・詳しく・繰り返す など。U-1）。機械の置きかえはしない。破線（dashed）と点線（dotted）の呼び方を守る（U-8）。紙面に委員会の回を書かない（U-7）。
12. **ページ**：自由。目安は1章 30〜50ページ。章は**中身で偶数ページ**（メモのページを入れない）。見出しだけがページの最後に残る所、下3分の1をこえる空き、短い囲みのまたぎを残さない（K-17）。

## 3. 試し組みと見直し（必ずやる）

1. `export TEXMFHOME=$PWD/texmf`（リポジトリの根で）。
2. `python3 tools/tryp.py 波-N 画像のフォルダ --kotae`。画像のフォルダは scratchpad の下に置く。通す条件は次のとおり。
   - エラー 0
   - 1.7pt をこえるはみ出し 0
   - ページの下へのはみ出し 0
   - 未定義の参照 0
   - フォントにない字 0
   - 偶数ページ
3. `python3 tools/check_overlap.py tex/tryp-p3-NN.pdf --out 画像のフォルダ`。赤い枠の候補を画像で見て、本物の重なりを直す。
4. 全ページを画像で見る。見るのは、図と字の重なり、図の中の字の大きさ（\footnotesize 以上）、空き、見出しの残り、字の間ののびた行。
5. 使った漢字を全部ぬき出し、常用漢字にない字がないことを確かめる。
6. 数値は、例題・じぶんでとこう・章末問題・こたえ・表・グラフのすべてを Python で計算して確かめる。スクリプトは `checks/物理第3巻/波-N/` に置く。
7. 物理として正しいかを確かめる。式の条件、符号（とくに第一法則と仕事の向き）、単位（K と ℃、kJ と J）、歴史の事実。
8. LuaLaTeX は重い。ほかの組も同時に組んでいるので、ロックファイルは消さない。`tex/tryp-*` は終わったら消す。
