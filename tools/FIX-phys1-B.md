## 4. 事務局に頼むこと

- **共通の部品（bk-physbody.sty）**：`phcode` の1行めに日本語のコメントがあると、その行だけ字の間がのびる（力-16 ③・力-3 ⑥）。章では行末に `\hfill\null` を足してしのいだ。\addplot coordinates を bkplot で使うと nullfont の字が出る（`\draw` でかいて回避）。
- **series_phys.py・前付**：章の★を 力-3 ★3〜4、力-4 ★2〜4 に（力-16 は ★4〜5 のまま）。力-16 の \phkoushiki をけずった。
- **記号**：力-16 ② の球の重さ $W$ は、数学 7-1（420〜457行）がそのまま引いている。手引き 6-3（重さは $mg$）に合わせるなら、力-16 と 7-1 を同時に直す必要がある（今回は変えていない）。
- **記号カード・分野でぶつかる記号の表**：$K$（運動エネルギー 力-4／剛性行列 力-16／体積弾性率 力-8・12・14）、$u$（ロケットの噴き出す速さ 力-3／節点の変位 力-16／流れの速さ 力-14）、$P$（仕事率・動力。荷重には使わない）。
- **巻末の物性値の表**：地上から低い軌道への Δv 約9.3〜10 km/s（重力・空気の損失をふくむ。Wikipedia "Delta-v budget"。理科年表などで要確認）。そのほかは今の値のまま。
- **数学の章**：直していない。数学が引いている力-4 の文・数（F1・F2・道A・道B・6.2791・「8-10で学んだように…」・「（すきまのない広がりの中なら）」・ストークスの1文）、力-16 の「u でまとめて行列で書く」・3本のばね・「（8-13）」は変えていない。力-4 の思い出そうは8-4・8-7・8-10 の3行に分けたが、grad の式の文言は同じ。
