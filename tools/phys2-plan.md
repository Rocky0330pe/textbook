## 0. 計画全体の考え方（要約）

1. **背骨はバランス式**（第8回の決定4）。「入る−出る＋生じる＝たまる」を、エネルギー（熱-2・4）、エントロピー（熱-6：生じる量が0以上）、水分（熱-9：空気の中の水）、熱の流れ（熱-11：小さな箱）にそのまま使う。第1巻の力-13（検査体積）とつなぐ。
2. **「一般の式から、よく使う式へ」**（`phflow`、第19回 6-1-1）は、本当に条件をおいて導く所だけに置く。熱学では、たとえば ① 第一法則 dU＝δQ＋δW → 定積・定圧・等温・断熱 → 高校の4つの変化、② 定常流動のエネルギーの式 → 熱の出入りなし・仕事なし・高さの差なし → ベルヌーイの式（力-13）、③ 熱方程式 → 定常・1次元 → フーリエの法則の直線の温度（6-3⑦）、④ ボルツマン分布 → 重力の場 → 大気の圧力の式（熱-3）、の形。
3. **経験則は経験則と書く**（第1巻と同じ）。比熱の値、熱伝達率の相関式（ヌセルト数の式）、限界熱流束の係数、放射率、ファンデルワールスの a・b は理論だけでは決まらない。導けたふりをしない。
4. **★は物理の物差し**（第19回 6-2）：★中学理科、★★高校物理基礎、★★★高校物理（発展をふくむ）、★★★★大学の初め（工学部1〜2年）、★★★★★大学の専門（工学部3年から）。構成案の★（数学の物差し）はつけなおした（B の各章の見出し、C-9 の決めてほしいこと1）。★★★★★をふくむ章は3段。
5. **例題は1章12前後**（序章3・読みもの4）。7段（場面→何を無視するか→図と記号→使う式を選ぶ理由→式を立てる→解く→答えを確かめる）。入試にチャレンジの枠はない（第19回 6-1-4）。高校の入試の型（2室の気体、ばねつきピストン、p-V 図のサイクル）は、章末問題の基本・チャレンジに入れる。
6. **答えのけた**：2けたが基本（第19回 6-4-6）。水の比熱は本文 4.2 kJ/(kg·K)（数学 6-3・6-4 の 4.2 J/(g·K) と同じ）、3けたが要る例題は 4.18 を使うと書く（g の 9.8／9.81 と同じ扱い。C-2）。
7. **熱学は「工学の熱力学」の本**。蒸気表・冷媒・空気線図など「本物の値を読む」（第8回の方針6）を大事にし、巻末の表は公式の式（IAPWS-IF97）から計算し直して組む（C-7）。

### A-7 符号の決まり（第一法則の W）——案

**ずれの中身**：高校の教科書は ΔU＝Q＋W（W は気体が**された**仕事）の形が多く、気体が**した**仕事 W′ を使って Q＝ΔU＋W′ とも書く〔要：各社の教科書の本文で確かめる。検索では、高校の教科書にどちらの形が多いかを確かめられなかった〕。物理・化学の国際的な書き方（IUPAC）も ΔU＝Q＋W〔確：QUDT の InternalEnergy の項は「Q は系に移った熱、W は系にされた仕事」。ISO 80000-5 の本文は有料で〔要〕〕。工学（機械の熱力学）の本は、エンジン・タービンが「する」仕事を正にして Q＝ΔU＋W（または ΔU＝Q−W）と書く〔確：テキサス大の講義ノートほか「工学者はこの形をよく使う」〕。

**案**：
1. **この巻の本文の式は ΔU＝Q＋W**（Q：系が受けとる熱、W：系が**される**仕事）。高校・国際の書き方と同じ。熱-2 ④ で、記号カードに「W は『される』仕事。気体が『する』仕事は W′＝−W」と書く。
2. **紙面ではいつも矢印の図で数える**（バランス式の背骨）。「入る熱 Q_入」「出る熱 Q_出」「される仕事 W_入」「する仕事 W_出」を、どれも正の数として矢印の図に書き、ΔU＝Q_入−Q_出＋W_入−W_出 と立てる。この形なら、どちらの決まりの本を読んでも、矢印を見て直せる。
3. **熱機関・冷凍機・タービン（熱-4〜9）**は、大きさ（正の数）と向きのことばで書く：Q_H（高温から受けとる）、Q_L（低温へ捨てる）、W_正味（取り出す）。定常流動の式（熱-4）は「1 kg あたりに入る熱 q_入、取り出す仕事 w_出」で、q_入−w_出＝Δh＋Δ(v²/2)＋gΔz と書く（工学の本と同じ形になる）。
4. **紙面での断り**：熱-2 ④ に「せいかくに言うと」を置き、「同じ法則を、ΔU＝Q＋W（この本・高校）と Q＝ΔU＋W（機械の本）の2つの形で書く本がある。W の向きの決め方がちがうだけ」と、矢印の図2枚で示す。熱-4 の「専門書をのぞいてみよう」で、機械の本の形 q＝Δh＋w_t（工業仕事）を読む。記号カードにも1行。
5. 数学の本との関係：8-7⑩ は「気体が外にする仕事 ∫p dV」と書いている（＝W′）。熱-2 ③ は 8-7⑩ を指して「8-7 の ∫p dV は、気体が**する**仕事 W′。この本の W は −∫p dV」と1行書く。

### C-2 単位・有効数字

- SI。数と単位は `\qty`（5けた以上は \num）。kcal・kgf/cm²・mmHg は換算表と「昔の資料を読む」でだけ（熱の仕事当量 1 cal＝4.184 J（熱化学カロリー）を熱-1・2 の札で。どのカロリーかで 4.184〜4.187 とちがうことを「せいかくに言うと」〔要：JIS Z 8202 の附属書〕）。
- **℃ と K**：温度差は K で書く（「20 K 上がる」。℃ と K の大きさは同じ、と熱-1 ②）。表の見出しは「温度 T〔℃〕」「温度差 ΔT〔K〕」（第21回 K-1 の「記号〔単位〕」の形）。
- **1 kg あたりの量は小文字**（u・h・s・v・q・w）、全体は大文字（U・H・S・V・Q・W）。単位は kJ/kg・kJ/(kg·K)。湿り空気は「乾いた空気1 kg あたり」で kJ/kg(DA)（DA は dry air、熱-9 ⑤ で断る）。
- **圧力**：絶対圧が基本（気体の式は必ず絶対圧）。ゲージ圧は「ゲージ圧」と書き添える（第1巻 C-2 と同じ。単位の後ろに G をつける書き方は使わない）。蒸気表は MPa・kPa。
- **体積の標準状態**：燃焼の m³N（0 ℃・1気圧）は熱-1 ⑧ で定義し、ほかでは使わない。
- **有効数字**：答えは2けたが基本（第19回 6-4-6）。水の比熱は本文 4.2 kJ/(kg·K)、3けたの例題は 4.18（はじめに書く）。蒸気表・冷媒の値は表の4けたをそのまま使い、答えは3けたでよい（「蒸気表の値を使うので3けたで書く」と例題のはじめに）。
- 回転数は「毎分3000回転（3000 min⁻¹）」（第1巻 C-2）。

### C-7 巻末の蒸気表・空気線図をどう作るか

**中身（案）**：見開きの空気線図（1枚）、飽和表（温度基準：0.01〜370 ℃、圧力基準：0.6 kPa〜22 MPa、各40行ほど）、過熱蒸気表（0.01・0.1・0.5・1・4・10 MPa × 100〜600 ℃）、h-s 線図（モリエ線図の主な範囲）、冷媒の飽和表（R32・R134a・R600a を各20行）、空気・水・金属・建材の物性値、燃料の発熱量、定数。構成案は「巻末 約30ページ」、series_phys.py の見積もりは10ページ（＋4の倍数に調える分）。→ ページ数は C-9 の5で決める。

**作り方**：
1. **自分で式を組む**：IAPWS-IF97 の領域1（液）・領域2（蒸気）・領域4（飽和線）を Python で組む（領域3 は 350 ℃以上の飽和の近くだけなので、表の 350〜370 ℃の行は領域3 を足すか、iapws の値を使う）。見本として、領域4 を `checks/物理第2巻/計画/if97_region4.py` に組んだ。
2. **3重の確かめ**：①IF97 の文書の検証の表（表35・36 など）——領域4 の6つの値は、自作の式と相対 10⁻⁸ 以下で一致した（検証の値は記憶から写したので、文書の原文で照合する〔要〕。iapws.org に届かなかった）②Python のパッケージ iapws（IF97 を組んだもの）③CoolProp（IAPWS-95：科学用のくわしい式。IF97 との差は 0.02 % 以下だった）。3つが表の最後のけたまで合わない行は、印をつけて人が見る。
3. **表の組み方**：表はプログラムで tex の表（`tex/ph2-steam.tex` など、名前は組4 が決める）に書き出す。手で写さない。数のけたは蒸気表の習慣（h・s は4けた〜5けた、v は4けた）。
4. **空気線図**：同じ IF97 の飽和蒸気圧から、相対湿度10〜100 % の線、比エンタルピー一定の線、湿球温度の線、比体積の線を計算し、pgfplots で描く（大気圧 101.325 kPa の線図と断る）。市販の空気線図（日本冷凍空調学会など）と数点を照らし合わせる〔要〕。
5. **冷媒**：CoolProp の値を使い、出典に「CoolProp 8.0（各冷媒の状態式）」と、その状態式の原論文を書く。NIST の REFPROP は使えないので、数点を NIST WebBook の公開値と照合する〔要〕。
6. **確かめのスクリプト**は `checks/物理第2巻/巻末/` に置き、表の全部の行を再計算して照合した結果（最大の差）を README に残す。

**この作業で計算した値の例**（`if97_region4.py` の出力）：63 kPa の飽和温度 87.18 ℃、101.325 kPa で 99.97 ℃、200 kPa で 120.21 ℃、20 ℃の飽和蒸気圧 2.3392 kPa、25 ℃で 3.1697 kPa。
