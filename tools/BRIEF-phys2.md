## 2. 第2巻の決まり（第22回で決めたこと）

1. **ファイル**：
   - 章は `tex/p2-NN.tex`（熱-0 が `p2-00.tex`）。
   - 章ごとの絵の部品の名前は `qx`＋章の番号の英小文字（熱-1→`qxb…`）。第1巻の `px…` とぶつけない。
   - ラベルは `ph:熱-4:sec6` の形。
   - 共通のファイル（`tex/bk-*.sty`、`tex/ph2-*.tex`、`phys/*.py`、`tools/*`）とほかの組の章は書きかえない。要るものは報告に書く。
2. **章の★と3段**：
   - 章の★は `phys/series_phys.py` のとおり（第22回で計画書の案に合わせて直した）。
   - 3段にする章は、熱-4・6・10・11・12・13・15。
   - 物理の★の物差しは BRIEF-phys1 の 6-2。
3. **第一法則の符号**：
   - 本文は $\Delta U=Q+W$（$W$ は気体が**された**仕事。高校の教科書と同じ）。矢印の図で、入る量・出る量を数える。
   - 機械の本の形（$Q=\Delta U+W'$、$W'$ は気体が**した**仕事）は、「せいかくに言うと」と「専門書をのぞいてみよう」で見せる。
   - サイクルの章（熱-5・7・8）では「した仕事 $W_{\text{出}}$」「された仕事 $W_{\text{入}}$」と添字で分けてよい。どちらかを記号カードに必ず書く。
4. **温度の記号**：
   - 絶対温度は $T$〔K〕。セルシウス温度は $\theta$〔℃〕（JIS Z 8202 の書き方。時刻の $t$ とぶつけない）。
   - 温度の差は $\Delta T$〔K〕。℃ の差と同じ数になることを、熱-1 ではじめに説明する。
   - 式の中の $T$ はかならず K。
5. **記号**：計画書 C の記号の表のとおり。主なものは次のとおり。
   - 熱容量は $C_{\mathrm{th}}$、熱抵抗は $R_{\mathrm{th}}$。数学の本と同じ書き方。
   - ボルツマン定数は必ず $k_{\mathrm B}$。
   - 熱貫流率 $U$ は熱-11・13 だけで使う。
   - 熱-4 では比体積を使わず、$1/\rho$ と書く。
   - ポリトロープ指数は $k$。成績係数は COP、圧縮比は $\varepsilon$。
   - 音速は $a$、マッハ数は Ma（立体の2文字）。
   - 1 kg あたりの熱・仕事は $q$・$w$。
   - 重さは $mg$（$W$ は仕事だけ）。
   - 同じ章で同じ文字を2つの意味に使わない（BRIEF-phys1 6-3）。
6. **水の比熱**：本文は 4.2 kJ/(kg·K)。3けたが要る例題だけ、はじめに「4.18 を使う」と書く（$g$ の 9.8／9.81 と同じ扱い）。
7. **蒸気・冷媒の値**：
   - 水と水蒸気は IAPWS-IF97 の式から Python（`iapws`）で計算する。
   - 冷媒（R32・R134a・R600a）と湿り空気は CoolProp で計算する。
   - 計算のスクリプトを `checks/物理第2巻/` に置き、出典を「IAPWS-IF97 の式から計算」「CoolProp 8.0 で計算」と書く。
   - 巻末の蒸気表・空気線図は、事務局がこのスクリプトで作る。本文の例題の値は、巻末の表と同じ値（同じ丸め）にする。
8. **第3巻『波動』との境目**：
   - 気体の音速 $a=\sqrt{\gamma R_{\mathrm s}T}$ は**熱-4 で導く**。第3巻（波-9）は熱-4 を指す。
   - 熱学は第3巻より先に読むので、ふりこ・単振動（波-1）を前提にしない。
   - 熱ふく射の光の波長は「物理シリーズの『波動』（波-12・13）」と予告だけ。
   - 第3巻の計画書 `tools/phys3-plan.md` の C-5-2 も読み、言い方をそろえる。
9. **第1巻との約束**：第1巻が『熱学』に送った約束（計画書 C-5-1、21か所）は、割りふった章で必ず果たす。
   - 例：力-12「くわしくは熱-3 で学びます」、力-3「ノズルの形のひみつは熱-4」。
   - 果たした所を報告に書く。
10. **数学の本の約束**：
    - 8-7⑩ のコラムは「p-V 図の閉じた道の面積は物理 熱-6」と書いている。熱-6 ⑧ に必ず入れる。
    - ほかに数学の本が熱の章を引いている所は、計画書 C-6-3 にある。数学の本の文・数は変えない。
11. **数学の本に足りない道具**：計画書の表（偏微分の −1 の関係、ルジャンドル変換、積分因子、$\int x^n e^{-ax^2}dx$、誤差関数、対数平均温度差、スターリングの近似）は、物理の章の中で作る。数学の本は変えない。
12. **漢字**：
    - 物理シリーズは高校卒業程度（BRIEF-phys1 6-4-2）。常用漢字は、読みやすさを見てふつうに使ってよい（周り・渦・滑る・繰り返す・詳しく など）。
    - 常用漢字にない字は使わない。
    - 機械の置きかえはしない。
13. **ページ**：
    - 自由。目安は1章 30〜50ページ。
    - 章は**中身で偶数ページ**にする（メモのページを入れない）。
    - 見出しだけがページの最後に残る所、下3分の1をこえる空き、短い囲みのまたぎを残さない（K-17）。
14. **事実**：
    - 歴史・定数・実機の値・規格・法令は、出典で確かめて章のファイルの頭のコメントに書く。計画書の〔要〕は必ず確かめる。
    - WebSearch・WebFetch を使ってよい。e-Gov・厚生労働省・JIS・ISO のサイトも調べてよい（依頼者の了承）。
    - 届かないときは、確かめた二次資料を書くか、報告に「〔要確認〕」として書く。

## 3. 試し組みと見直し（必ずやる）

1. `export TEXMFHOME=$PWD/texmf`（リポジトリの根で）。
2. `python3 tools/tryp.py 熱-N 画像のフォルダ --kotae`。画像のフォルダは scratchpad の下に置く。通す条件は次のとおり。
   - エラー 0
   - 1.7pt をこえるはみ出し 0
   - ページの下へのはみ出し 0
   - 未定義の参照 0
   - フォントにない字 0
   - 偶数ページ
3. `python3 tools/check_overlap.py tex/tryp-p2-NN.pdf --out 画像のフォルダ`。赤い枠の候補を画像で見て、本物の重なりを直す。
4. 全ページを画像で見る。見るのは、図と字の重なり、図の中の字の大きさ（\footnotesize 以上）、空き、見出しの残り、字の間ののびた行。
5. 使った漢字を全部ぬき出し、常用漢字にない字がないことを確かめる。
6. 数値は、例題・じぶんでとこう・章末問題・こたえ・表・グラフのすべてを Python で計算して確かめる。スクリプトは `checks/物理第2巻/熱-N/` に置く。
7. 物理として正しいかを確かめる。式の条件、符号（とくに第一法則と仕事の向き）、単位（K と ℃、kJ と J）、歴史の事実。
8. LuaLaTeX は重い。ほかの組も同時に組んでいるので、ロックファイルは消さない。`tex/tryp-*` は終わったら消す。
