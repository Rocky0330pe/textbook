## 2. 第5巻の決まり（第31回で決めたこと。くわしくは `docs/議事録/第31回編集委員会_議事録_物理第5巻の計画.md`）
1. **ファイル**：章は `tex/p5-NN.tex`（原-0 が `p5-00.tex`）。章ごとの絵の部品の名前は `tx`＋章の番号の英小文字（原-1→`txb…`。第1〜4巻の `px`・`qx`・`rx`・`sx` とぶつけない）。ラベルは `ph:原-4:sec6`、例題は `ph:原-4:ex3` の形。共通のファイル（`tex/bk-*.sty`、`tex/ph5-*.tex`、`phys/*.py`、`tools/*`）とほかの組の章は書きかえない（要るものは報告に書く）。
2. **章の★と3段（N-1）**：計画書 B の表のとおり（事務局が `phys/series_phys.py` を直す）。章末問題の基本は章の★の低いほう（T-4・U-2・X-1）。
3. **量子力学の深さ（N-2）**：1次元の時間によらないシュレディンガー方程式を主にする。水素原子は 1s を代入で確かめ、ほかは結果を読む。演算子は「専門書をのぞいてみよう」で名前だけ。観測の問題は「まだわかっていないこと」。
4. **虚数単位（N-3）**：原-5〜8 は物理の慣用どおり $i$ と $e^{-iEt/\hbar}$。原-5 ④で「数学の本の $j$ と同じ数」と一度だけ書く。回路の章（原-9・10）は $j$。
5. **記号（N-4・N-5）**：計画書 C-1 の表のとおり。崩壊定数 $\lambda$ は第4部だけ。放射能 $A$ と質量数 $A$ は章で分ける。実効線量 $E$ を使う原-14 では、エネルギーに添字。半導体の電場は $\mathcal E$、ドナー・アクセプターは $N_{\mathrm d}$・$N_{\mathrm a}$（アボガドロ定数 $N_{\mathrm A}$ とぶつけない）、電流増幅率は $h_{\mathrm{FE}}$。光の振動数は $f$（$E=hf$）で、高校の $h\nu$ と同じと一言。$\nu$ は1回の分裂で出る中性子の数。
6. **放射線の単位と防護（N-6）**：物理量・防護量・実用量に分けて書く。「安全か危険か」の二択にせず、量で書く。LNT は両方の見方を紹介し、防護では LNT を使うと書く。
7. **原子力と事故（N-7）**：賛成・反対の立場をとらない。物理（崩壊熱・水素・冷却）と公的資料の事実を書く。被災した人に配慮する（心理士・小学校教師の委員が原-15・原-16 を先に読む）。原爆は、被爆者の健康調査がリスクの土台になっていることと、核分裂の発見から短い期間で兵器が作られた事実を、短く書く。
8. **数値の出典（N-8）**：定数は CODATA 2022、原子の質量は NIST（AME2020）、減弱係数は NIST、放射線は環境省「放射線による健康影響等に関する統一的な基礎資料」を主に使い、不足は DDEP・NNDC・JAEA・JENDL などの一次資料で確かめる（届かなければ二次資料2つ以上で照らし合わせ、年を書く。Y-7 と同じ）。炭素14 は数学の本と同じ 5730年で計算し、「いまの評価は約 5700年」と一言。
9. **安全（N-9・計画書 C-8）**：放射線・放射性物質・高電圧・レーザー・紫外線・X線・液体窒素・ドライアイス・火を使う「やってみよう」は置かない。やってみようは分光シート・乾電池と LED・光電池・サイコロの崩壊・照度計アプリの逆2乗・自治体の線量データを見ること、まで。安全の囲みを原-1・5・8・11・14 に置く。
10. **数学・前の巻との重なり（N-10）**：W-6・Y-9 と同じ。計算が数学の本で済んでいる所は数学の章を「（6-14⑤）」の形で指し、物理の章は法則の出どころ・エネルギー・実物を主にする。前の巻が『原子』に送った約束（計画書 A-6 の62件）は、割りふった章で必ず果たす。
11. **漢字・書き方・ページ・出典の確かめ方**：第4巻と同じ（下の 14〜16 の項目は、第4巻の手引きのまま）。
14. **漢字・書き方**：高校卒業程度（常用漢字はふつうに使う。周り・詳しく・繰り返す・違う など。U-1・X-4）。「はかる」「おくれ」はかな（X-4）。「コンデンサー」「モーター」と長音をつける。機械の置きかえはしない。破線（dashed）と点線（dotted）の呼び方を守る（U-8）。紙面に委員会の回を書かない（U-7）。μ は立てて書く（`\si{\micro F}` など。X-6）。上限は切り捨てる（X-7）。

    - 作業環境から届くサイト（11月5日に確かめた）：e-Gov 法令（laws.e-gov.go.jp・elaws.e-gov.go.jp）、厚生労働省（www.mhlw.go.jp）、JIS の閲覧（webdesk.jsa.or.jp）、NIST（webbook.nist.gov・janaf.nist.gov・physics.nist.gov）、IAPWS（www.iapws.org）、NASA（www.nasa.gov）、建築研究所（www.kenken.go.jp）。WebFetch で本文を読む。

## 3. 試し組みと見直し（必ずやる）

1. `export TEXMFHOME=$PWD/texmf`（リポジトリの根で）。
2. `python3 tools/tryp.py 原-N 画像のフォルダ --kotae`。画像のフォルダは scratchpad の下に置く。通す条件は次のとおり。
   - エラー 0
   - 1.7pt をこえるはみ出し 0
   - ページの下へのはみ出し 0
   - 未定義の参照 0
   - フォントにない字 0
   - 偶数ページ
3. `python3 tools/check_overlap.py tex/tryp-p5-NN.pdf --out 画像のフォルダ`。赤い枠の候補を画像で見て、本物の重なりを直す。
4. 全ページを画像で見る。見るのは、図と字の重なり、図の中の字の大きさ（\footnotesize 以上）、空き、見出しの残り、字の間ののびた行。
5. 使った漢字を全部ぬき出し、常用漢字にない字がないことを確かめる。
6. 数値は、例題・じぶんでとこう・章末問題・こたえ・表・グラフのすべてを Python で計算して確かめる。スクリプトは `checks/物理第5巻/原-N/` に置く。
7. 物理として正しいかを確かめる。式の条件、符号（とくにエネルギーの符号・準位の数え方・崩壊の向き）、単位（eV・J・Bq・Gy・Sv・u・m⁻¹ など）、歴史の事実。
8. LuaLaTeX は重い。ほかの組も同時に組んでいるので、ロックファイルは消さない。`tex/tryp-*` は終わったら消す。

## 6. あとから足した決まり（まとめ役）

- **℃ の書き方**（熱W1 の報告から）：物理の共通部品で、`\qty{20}{\celsius}` も本文と同じ「℃」の1字で組むようにした。どちらの書き方でもよい（`\qty{20}{\celsius}` か「20\,℃」）。単位の積 `J/(kg.K)` は「J/(kg·K)」と、点の前後をあけずに組まれる。
- **ph5-pages.tex**：`tools/tryp.py` が、なければ自動で作る（`phys/gen_phys.py`）。
- **nullfont の「.01pt」の警告**（電W6・電W7 の報告から）：pgfplots の `\addplot[only marks]`・`\addplot coordinates`・`table` で出ることがある。紙面の字は欠けないが、`\draw`・`\fill` と `axis cs:` の線に置きかえると消える。
- **`phcodeout` の中身の最初の行が「[」で始まる**と、題として読まれる（電W3 の報告から）。`\begin{phcodeout}[実行結果]` のように題を書いてよける。
