## 直すときの決まり
- 直してよいのは、自分の組の章の原稿（`tex/p4-NN.tex`）と、組で決めたファイルだけ。共通の部品（`tex/*.sty`）、`phys/series_phys.py`、ほかの組の章は直さない。要るものは最後の報告に書く。
- 漢字の置きかえは1か所ずつ読んで手で行う。原稿を上書きするスクリプトは動かさない。
- 章の題名（`\phchapter`）、共通の節の題、さくいんの読み（`\bkidx` の1つめ）、数学の巻が引いている物理の文・数は変えない。
- 札（`\bkreidairef` など）のあとに `\nobreak` や `\,` を足さない（K-5 で共通部品が直した）。
- 数を変えたら Python で検算し、スクリプトを `checks/物理第4巻/確認/` に置く。

## 確かめ（章ごとに必ず）
1. `python3 tools/tryp.py 電-N 画像のフォルダ --kotae`：エラー0・1.7pt 超のはみ出し0・ページの下へのはみ出し0・**偶数ページ**（メモのページなし）。
2. `python3 tools/check_overlap.py tex/tryp-p4-NN.pdf --out 画像のフォルダ`：赤い枠の候補を画像で見て、本物の重なりを直す。
3. 直した所のページを画像で見る（見出しだけがページの最後に残っていないか、下3分の1をこえる空きがないか、字の間ののびた行がないか）。
4. 画像や一時ファイルは scratchpad に置き、リポジトリに入れない（`tex/tryp-*` は消す）。
