## 依頼者の指示（13:34）にかかわる、全組の決まり（新しく足す）

- **流れ図は「例題を1つずつ流して確かめる」**。流れ図を作ったら（直したら）、その章の**すべての例題とじぶんでとこう**を、流れ図の上から順にたどり、表の記号どおりの四角に着くことを確かめる。着かない例題があれば、問いの順・問いの文を直す。報告に「例題○題をたどり、すべて表の記号に着いた」と書く。
- **ひし形の問いは、はい・いいえが1つに決まる文にする**（「場は対称？」のように、何について対称かがあいまいな問いにしない。「場の大きさを知りたい（球・円柱・平面の対称で、面の上で一定）？」など）。
- **どの四角にも、入る矢印と出る矢印がある**（「下の問いへ」と書いた四角は、本当に下の問いへ矢印をつなぐ）。
- **例題の形は kata8-int §1 の順（必ずこの順）**：「場合：…」の次に**「名前」の札の行**（積分しない例題でも「名前は ∬ だが、ここでは積分しない（対称で外に出す）」を見せる）→直す段→楽をする段（使ったとき）。
- **大事な式は、名前（点線）とふつうの定積分（実線）の枠で**（本文の大事な式・たいせつ・まちがえやすいところ）。
- **たいせつの「場合のまとめ」は、8-7 と同じ表（bktable）の形**にそろえる。
- 式の変形を Python に任せて省かない（外積の成分などは bkhenkei で1行ずつ）。

組 V8-4 は、`tools/kata8-int.md` の流れ図の節に、この「例題を流して確かめる」手順と、問いの文の決まりを書き足す。
