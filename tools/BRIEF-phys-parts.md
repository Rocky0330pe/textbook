# 物理シリーズの本文の部品（第13回編集委員会（物理第1巻）：組 P-0 がまとめた説明）

物理第1巻『力学』の章（`tex/p1-NN.tex`）を書くときに使う部品です。数学シリーズの部品（`tools/BRIEF-vol4.md` の「3. 使える部品」）は、ほぼそのまま使えます。ここでは**物理で足した部品**と、**物理で書き方が変わる所**だけを書きます。見本はすべて `tex/p1-sample.tex`（見本の章。本には入らない）にあります。まずそれを読んでください。

部品の定義は `tex/bk-physbody.sty`（物理の親ファイルだけが読む。数学の巻には効かない）。

---

## 0. ファイル・試し組み・ページ

| すること | やり方 |
| --- | --- |
| 章のファイル | `tex/p1-NN.tex`（力-0 が `p1-00.tex`、力-16 が `p1-16.tex`）。`tex/ph1-body.tex` が読む（ないときは飛ばす） |
| 試し組み | `python3 tools/tryp.py 力-3 画像のフォルダ --kotae`（`3` でもよい）。ページ数・エラー・1.7pt 超のはみ出し・Overfull \vbox・未定義の参照・フォントにない字を表示し、画像を書き出す。席（ロック）を1つとる |
| 見本の試し組み | `python3 tools/tryp.py sample 画像のフォルダ --kotae`（力-1 の場所で組む） |
| 巻全体 | `flock /tmp/bk-lualatex-slot0.lock flock /tmp/bk-lualatex-slot1.lock ./buildp.sh 1`（2つの席を両方とる） |
| ページ合わせ | `./buildp.sh 1` → `python3 tools/syncpages.py p1` → `python3 phys/gen_phys.py` → `./buildp.sh 1` → `python3 tools/check_pages.py p1`（ずれ 0）。章が全部そろうまでは、ない章は計画のページのまま（check_pages の NG は「まだない章」のせい） |
| チェック表・つぎの巻へ | `python3 tools/mkchecklist.py p1`（ふりかえり → `tex/ph1-checklist.tex`）、`python3 tools/mknext.py p1`（道しるべの「この章の先に」の 熱・波・電・原 の章 → `tex/ph1-nextuse.tex`） |

- 章は偶数ページから始まる。奇数ページで終わると「メモ」のページが1枚入る（できれば内容で偶数に）。
- ルビなし・常用漢字まで・5けた以上の数は `\num`／`\qty` で（数学第4巻と同じ）。`\qtyrange{9.78}{9.83}{m/s^2}` は「9.78〜9.83 m/s²」になる。
- 章ごとの絵の部品の名前：章の頭文字 `px` ＋ 章の番号の英小文字（力-0→`pxa…`、力-1→`pxb…`、…、力-16→`pxq…`。見本の章は `pxs…`）。共通のファイル（`bk-*.sty`、`ph1-*.tex`、`phys/*.py`、ほかの人の章）は書きかえない。

## 1. 章の頭

```latex
\phchapter{3}{ぶつかる・噴き出す：運動量と衝突}{ロケットは、何もない宇宙でどうやって進む？}{\bklevel{4}}{ぶつかる・噴き出す：運動量と衝突}
\bkmichishirube{5-12,5-14,8-6,力-2}{力-13,熱-4,波-3}
```

- `\phchapter[読みもの]{番号}{題名（2行は \\）}{なぜ？}{★}{柱・しおりの題名}`。番号は数（力-3 なら 3、序章は 0）。題名・なぜ？・★は `phys/series_phys.py`（もくじ）と同じにする。★は `\bklevel{4}` か `\bklevelrange{4}{5}`。力-16 は `[読みもの]`。
- 帯に「なぜ？」の副題が自動で入る。柱（偶数ページ「力学　第1部　動く」、奇数ページ「力-3　題名」）・つめ（部の番号）・しおり・`BKPAGE` も自動。
- 道しるべ：数学の章（`4-11`）は数学の巻の色、物理の章（`力-2`・`熱-4`）は物理の巻の色の札になる。
- ラベルは `\label{ph:力-3:キー}`。ふりかえりは `\bkfurref{ph:力-3:キー}`。
- 本文で物理の章をページつきで指す：`\phchapref{力-13}` →［力-13］P.224。
- さくいん `\bkidx{よみ}{語}`、記号カード `\bkkigocards{\bkkigocard{記号}{読み方}{意味}{英語}{力-3}}{…}`、こたえ `\bkjans{…}`・`\bkpans{…}` は数学と同じ（巻末に自動で集まる）。

## 2. この章で導く中学・高校の公式（章のはじめ。できるようになることのすぐ下）

```latex
\phkoushiki{%
\phk{$v=v_0+at$（等加速度運動）}{高校物理基礎}{ph:力-1:toukasoku}
\phkx{$T=2\pi\sqrt{\dfrac{l}{g}}$（ふりこ）}{高校物理}{波-1 で導く}
}
```
- `\phk{公式}{ふつう習う所}{ラベル}`：ページの列は `\pageref{ラベル}`（その公式を導く所に `\label` を置く）。
- `\phkx{公式}{ふつう習う所}{文字}`：ほかの章で導く公式。
- 「ふつう習う所」は「中学理科」「高校物理基礎」「高校物理」の形で書く（学年の数字は書かない。→ まとめ役に確認中）。

## 3. 一般の式から中学・高校の公式へ（依頼者の要求④）

```latex
\begin{phflow}[題（なくてもよい）]
\phflowrow{$m\dfrac{\dd v}{\dd t}=mg$}{$g$ が一定\\はじめ止まっている}{$v=gt$}
\phflowrow{$\dfrac{\dd y}{\dd t}=gt$}{はじめの位置を\\0にする}{$y=\dfrac{1}{2}gt^2$}
\end{phflow}
```
- 左＝一般の式（巻の色の枠）、矢印の上＝条件（理想化）、右＝中学・高校の公式（だいだいの枠）。段はいくつでも。1段は1つの絵なのでページで分かれない（囲み全体はページをまたげる）。
- 条件は2行までに。改行の位置は `\\` で決める（語の途中で切れないように）。
- 前の段の右の式を、次の段の左に書けば「段を踏んで」導く形になる。

## 4. 式が出るたびの3つの見方（依頼者の要求②）

```latex
\pheq{m\dfrac{\dd v}{\dd t}=mg}{N ＝ kg × m/s$^2$}     % 別行の式＋右はしに次元チェックの札
\begin{phyomi}[$F=ma$] … \end{phyomi}                  % この式の読み方（[ ] は題。式を書くとよい）
\begin{phmijika}[題] … \end{phmijika}                    % 身近な例では
\begin{phbaisuru}{質量 $m$} … \end{phbaisuru}            % 「質量 m を2倍にすると？」
\begin{phbaisuru}[半分]{長さ $l$} … \end{phbaisuru}      % 「長さ l を半分にすると？」
```
- 3つとも左の線だけの軽い囲みで、ページをまたいでよい。中にグラフ（`bkplot`）を入れてよい。「2倍にすると」は、できるだけグラフか図で見せる。
- 次元チェックだけを文中・式の中に置くとき：`\phdim{m/s ＝ m/s$^2$ × s}`。

## 5. モデル化の札・桁の感覚・工学の駅（第8回で決めた4つの囲み）

```latex
\begin{phmodel}[落ちるボール]
\phignore{空気の抵抗。ボールの回転。}        % 無視したこと
\phassume{重力だけ。g は一定。}              % おいた仮定
\phlimit{紙や羽根。速さが大きいとき。}      % 仮定がくずれるのは
\end{phmodel}
```
- 3つの項目は決まった順・決まった見出し（それだけで1行）。式を立てる直前に置く。ページをまたがない。

```latex
\begin{phketa}[題]
\phketaline{鋼のヤング率}{約\qty{205}{GPa}}
\phboxhead{答えが桁で合っているか}
…
\end{phketa}
```
- 実機の典型値（出典を確かめる。出典は本文か巻末の表に）と、答えの桁の確かめ方。ふつうは「工学ではこう使う」の中に置く。`\phboxhead{見出し}` は囲みの中の小見出し（それだけで1行。どの物理の囲みでも使える）。

```latex
\phstation{機械力学,車両の運動,衝撃と落下試験}{自由落下、重力加速度、終端速度}
```
- 1つめ：この章の先の工学の科目（カンマ区切り、4つまで）。路線図の駅の形で出る。2つめ：専門書で出てくる言葉。

## 6. 工学ではこう使う（数学の「物理・工学ではこう使う」の物理版）

```latex
\bksection{phgear}{工学ではこう使う}
\begin{phkougaku}[題] … \begin{phketa}…\end{phketa} … \end{phkougaku}
\phstation{…}{…}
```
- **ページをまたげる**（2つめから先の箱の左上に「工学ではこう使う（つづき）」の札）。中の `phketa` などの囲みは分かれない。数学の `butsuri` は物理の本では使わない。

## 7. まだわかっていないこと・この先は大学で（依頼者の要求②）

```latex
\begin{phmada}[重さと質量は、なぜ同じ割合なの？] … \end{phmada}
\begin{phsaki}{題}  … \end{phsaki}            % 「この先は大学で」
\begin{phsaki}[大学院]{題} … \end{phsaki}     % 「この先は大学院で」（題は {} で空にしてよい）
```
- どちらもページをまたげる。**事実として正確に、言いすぎない**（「〜はわかっていない」と書くときは、どこまでわかっていて何がわかっていないかを分けて書く。年と実験の名前は確かめる）。

## 8. 例題の段（依頼者の要求③）

```latex
\bksection{reidai}{例題でたしかめよう}
\begin{phreidai}[ビルの屋上からボールを落とす]
問題文
\phbamen    …   % ① 場面
\phmushi    …   % ② 何を無視するか（理想化）
\phzu       …   % ③ 図と記号
\phriyu     …   % ④ 使う式を選ぶ理由
\phtateru   …   % ⑤ 式を立てる
\phtoku     …   % ⑥ 解く
\phtashikame …  % ⑦ 答えを確かめる（単位・大きさ・極端な場合）
\kotae 約\qty{2.0}{s}
\end{phreidai}
```
- `phreidai` は**ページをまたいでよい**例題（2つめから先の箱に「例題1（つづき）」の札）。番号は数学の `reidai`（ページをまたがない短い例題）と共通（`\bkreidairef{1}` で指せる）。
- 段の見出しは `\phstep{名前}` でも作れる（番号は例題ごとに①から）。見出しはそれだけで1行。段の中の別行の式は `\[ … \]`。
- じぶんでとこう（`jibun`）は数学と同じ（ページをまたがない）。

## 11. シミュレーションのプログラム（依頼者の要求③）

```latex
\begin{phcode}[Python]
g = 9.8
for i in range(5):
    v = v + g * dt
\end{phcode}
\begin{phcodeout}
0.1 0.0 0.98
\end{phcodeout}
```
- 中の改行と字下げはそのまま出る。`#` は `\#`、`_` は `\_`、`%` は `\%` と書く。表計算の画面は数学と同じ `\bksheet`。出力の数は必ず実際に動かして確かめる。

## 12. 色と図のきまり（デザイナー）

- 巻の色は群青（`bkTheme`＝`phVol1`、濃い色なので白い字でよい）。巻の色の字は `bkDeep`。
- 囲みの色：モデル化の札 `phModel`（茶）、桁の感覚 `phKeta`、まだわかっていないこと `phMada`（藍）、この先は大学で `phSaki`、工学の駅 `phInk`（墨）、一般の式→公式 `bkTheme`／`phFlowR`（だいだい）。白地の上に明るい色の細い字を置かない（字は `…Deep` の色か `bkInk`）。
- 図は数学と同じきまり（`bk node`・`bk link`、字は footnotesize 以上、字と線の間 1.5 mm 以上、はば 132 mm 以内、囲みの中は 122 mm 以内）。物理の図は多めに（依頼者の要求②）。
