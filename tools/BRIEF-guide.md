## 4. ファイルと組み方

- 親ファイル `tex/guide.tex`（G-A が作る。`\usepackage[vol=0]{bk-b5}`、`\input{vol9-meta}`、本文は `\input{guide-p1}`・`\input{guide-p2a}`・`\input{guide-p2b}`）。第2部の始まりで、ルビを付けない書き方にする。
- G-A：`tex/guide.tex`・`tex/guide-p1.tex`（頭文字 kga）、G-B：`tex/guide-p2a.tex`（頭文字 kgb）、G-C：`tex/guide-p2b.tex` と `tools/mkguidetables.py`（頭文字 kgc）。新しい部品は自分のファイルの先頭で、自分の頭文字をつけて定義する。共通のファイル（bk-*.sty など）・ほかの組のファイル・ほかの巻は書きかえない。
- 組み方：`cd /home/claude/work/build/tex && flock /tmp/bk-lualatex-slot0.lock flock /tmp/bk-lualatex-slot1.lock lualatex -interaction=nonstopmode guide.tex`（2回）。ほかの組のファイルがまだないときは、`\IfFileExists` で飛ばす形に（G-A が親ファイルでそうしておく）。自分の部分だけ確かめるときは、親ファイルの写しを自分の作業フォルダに作って、自分のファイルだけを読む形にしてよい（tex/ に置く写しは名前を `guide-try-組名.tex` に）。
- 確かめ：エラー0、1.7pt 超のはみ出し0、偶数ページ、画像で全ページを見る（`pdftoppm -r 50`、気になる所は `-r 110`）、行末の記号（`python3 tools/eqend.py tex/guide.pdf 0`）。
