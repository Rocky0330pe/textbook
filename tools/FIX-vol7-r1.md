## 共通の決まり

- 「必ず直す」と「直したほうがよい」は、下の決定のとおりすべて直す。
- 直したあとも章は偶数ページ。確かめ：`cd /home/claude/work/build && python3 tools/tryv.py 7-N <scratchpad の画像フォルダ> --kotae`（エラー0・1.7pt 超のはみ出し0・ページの下へのはみ出し0・行末の記号0・偶数ページ）。直したページは画像で見る。全巻の組み直しは事務局。
- 数を直したら Python で検算し、同じ数が出てくるほかの所（例題・こたえ・表・図・ほかの章）もそろえる。
- **章末問題の★**（全組）：`\bkproblemgroup{基本}{N}` の N は章の★の低いほう、`\bkproblemgroup{チャレンジ}{N}` は高いほう（★が1つの章は、チャレンジを1つ上げる。最大5）。第6巻と同じ。
- **プログラムの枠と実行結果は同じページに**（全組）：bkcode と bkcodeout の前に \Needspace を入れるか、1つの塊にする。
- **こたえのページの行列**（全組）：smallmatrix は字が小さすぎるので、7-2・7-3 の書き方「1行め $(2,\ 1)$、2行め $(1,\ 2)$」にそろえる。
- **明るい青・紫の細い字**は使わない（字に色をつけるときは \bkTT か bkInk）。
