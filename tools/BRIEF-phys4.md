## 2. 第4巻の決まり（第26回で決めたこと。くわしくは `docs/議事録/第26回編集委員会_議事録_物理第4巻の計画.md`）
1. **ファイル**：章は `tex/p4-NN.tex`（電-0 が `p4-00.tex`）。章ごとの絵の部品の名前は `sx`＋章の番号の英小文字（電-1→`sxb…`。第1〜3巻の `px`・`qx`・`rx` とぶつけない）。ラベルは `ph:電-4:sec6`、例題は `ph:電-4:ex3` の形。共通のファイル（`tex/bk-*.sty`、`tex/ph4-*.tex`、`phys/*.py`、`tools/*`）とほかの組の章は書きかえない。要るものは報告に書く。
2. **章の★と3段（Y-1）**：章の★は `phys/series_phys.py` のとおり（第26回で計画書の案に直した）。3段にする章は、★5 をふくむ電-2・3・7・8・11・12・13・14・15。章末問題の基本は章の★の低いほう（T-4・U-2・X-1）。ベクトル解析の場の法則（積分形の当てはめ）・ラプラス変換・フェーザ・四端子定数は★4 の道具とする（X-1 の当てはめ）。
3. **磁場（Y-2）**：E-B 対応。$\vec B$ を基本の場として「磁場（磁束密度）」とよぶ（数学 8-10・8-14 と同じ）。$\vec H$ は電-7 で物の中に入ってから「磁場の強さ」として出す。高校の教科書の $H$（磁場）と $B$（磁束密度）の関係 $B=\mu_0H$ は電-6 で一言。「電界・磁界」は「専門書をのぞいてみよう」で読み方だけ。
4. **電圧の記号（Y-3）**：電位 $\phi$（数学 8-4 と同じ）、電圧 $V$、場の章の起電力 $\mathcal E$。回路の章（電-9〜13）の電源の電圧は瞬時 $e$、直流と実効値 $E$、部品の電圧の瞬時値 $v$、電流の瞬時値 $i$・実効値 $I$。前付の相似の表（力 $F$ ↔ 電圧 $e$）と数学 6-15 の約束に合わせる。実効値は添字なしの大文字（数学 4-9 の $V_{\mathrm e}$ は「思い出そう」で一言）。
5. **ほかの記号（Y-4）**：トルク $T$（電-12 のカードに、第1巻 $\vec N$・波-4 $\tau_{\mathrm m}$ との対応を書く）。面積は電-1〜13 で $S$、第4部（電-14・15）は $A$（ポインティングベクトル $\vec S$ のため）。電-4 の電荷密度は $\rho_{\mathrm q}$（抵抗率 $\rho$ と分ける）。特性インピーダンス $Z_0$（電-13）、波のインピーダンス $\eta$（電-15）。電-13 の1 m あたりの量は $R'$・$L'$・$G'$・$C'$ とし、四端子定数は行列 $\begin{pmatrix}A&B\\C&D\end{pmatrix}$ のまま扱い、静電容量とぶつかる所は本文で断る。そのほかは計画書 C-1 の表のとおり。同じ章で同じ文字を2つの意味にしない。記号カードは「記号と意味の組」ごとに、はじめて出た章に1枚（X-2）。
6. **ベクトル解析の深さ（Y-5）**：法則は積分形（袋・道を選ぶ形）を主にする。微分形（div・rot）は「式でわかる」の段に置き、数学 8-9〜8-14 を指す。ベクトルポテンシャル・遅延ポテンシャルは結果だけか「この先の学び」。
7. **単位と定数（Y-6）**：SI だけ（cgs は専門書の囲みで換算だけ）。本文の丸め：$k=8.99\times10^9$ N·m²/C²、$\varepsilon_0=8.85\times10^{-12}$ F/m、$\mu_0=4\pi\times10^{-7}$ N/A²（2019 年の SI 改定で測る値になったこと、差は相対 $10^{-10}$ ほどであることを、はじめて出る章で一言）、$e=1.60\times10^{-19}$ C、$c=3.00\times10^8$ m/s。3けたを超えて要る所は CODATA 2022 の値を書く。
8. **周波数（Y-8）**：第4巻は「周波数」を使う。電-10 ①で「波動の本の振動数と同じ量」と一言。
9. **数学・前の巻との重なり（Y-9）**：W-6 と同じ。数学 6-4・6-6・6-7・6-9〜6-13・7-3〜7-5・8-5〜8-14・9-7 で計算が済んでいる所は、物理の章では「どの法則から出るか」「エネルギー」「相似の理由」「実物」を主にし、同じ計算は数学の章を「（6-13⑩）」の形で指す。第3巻の波-1・2 の RLC（W-9）は、電-4・8・9・10 で法則から回収する。
10. **後の巻（Y-10）**：磁区のしくみ・超伝導・半導体・ダイオード・トランジスタは、「物理シリーズの『原子』（原-N）で学ぶ」と書いて結果だけ使う。スイッチ・ダイオードは理想の部品（オン・オフだけ、一方通行の弁）として扱う。
11. **前の巻との約束**：第1〜3巻が『電磁気学』に送った約束（計画書 A-6 の45件）は、割りふった章で必ず果たす。とくに、前付の相似の地図の「出会う章 電-9」、W-8（電-15 で「出す光の強さは加速度の2乗に比例」を導く）、波-4 の DC モーター（電-12 ④）、波-7 の 50 Ω・75 Ω（電-13 ⑧）、波-13 の反射率とブルースター角（電-15 ⑨）、熱-10 の燃料電池 1.23 V と熱-1 の熱電対（電-4）。前の巻の章を指すときは、その原稿の節の番号・記号・数にそろえる。数学の本が「物理 電-N」と引いている所（計画書 C-6-2）も、割りふった章で扱う。数学の本の文・数は変えない。

## 3. 試し組みと見直し（必ずやる）

1. `export TEXMFHOME=$PWD/texmf`（リポジトリの根で）。
2. `python3 tools/tryp.py 電-N 画像のフォルダ --kotae`。画像のフォルダは scratchpad の下に置く。通す条件は次のとおり。
   - エラー 0
   - 1.7pt をこえるはみ出し 0
   - ページの下へのはみ出し 0
   - 未定義の参照 0
   - フォントにない字 0
   - 偶数ページ
3. `python3 tools/check_overlap.py tex/tryp-p4-NN.pdf --out 画像のフォルダ`。赤い枠の候補を画像で見て、本物の重なりを直す。
4. 全ページを画像で見る。見るのは、図と字の重なり、図の中の字の大きさ（\footnotesize 以上）、空き、見出しの残り、字の間ののびた行。
5. 使った漢字を全部ぬき出し、常用漢字にない字がないことを確かめる。
6. 数値は、例題・じぶんでとこう・章末問題・こたえ・表・グラフのすべてを Python で計算して確かめる。スクリプトは `checks/物理第4巻/電-N/` に置く。
7. 物理として正しいかを確かめる。式の条件、符号（とくに電流・起電力・誘導の向き、右ねじ、力の向き）、単位（Wb・T・H・F・Ω・S・W・var・VA）、歴史の事実。
8. LuaLaTeX は重い。ほかの組も同時に組んでいるので、ロックファイルは消さない。`tex/tryp-*` は終わったら消す。

## 6. あとから足した決まり（まとめ役）

- **℃ の書き方**（熱W1 の報告から）：物理の共通部品で、`\qty{20}{\celsius}` も本文と同じ「℃」の1字で組むようにした。どちらの書き方でもよい（`\qty{20}{\celsius}` か「20\,℃」）。単位の積 `J/(kg.K)` は「J/(kg·K)」と、点の前後をあけずに組まれる。
- **ph4-pages.tex**：`tools/tryp.py` が、なければ自動で作る（`phys/gen_phys.py`）。
- **nullfont の「.01pt」の警告**（電W6・電W7 の報告から）：pgfplots の `\addplot[only marks]`・`\addplot coordinates`・`table` で出ることがある。紙面の字は欠けないが、`\draw`・`\fill` と `axis cs:` の線に置きかえると消える。
- **`phcodeout` の中身の最初の行が「[」で始まる**と、題として読まれる（電W3 の報告から）。`\begin{phcodeout}[実行結果]` のように題を書いてよける。
