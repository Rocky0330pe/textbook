# 補助教材のアニメーションを作る組への手引き（第34回）

依頼者の指示（11月12日）：「アニメーションは169項目全て作成してください。」
見せ方：ホームページの HTML で、スライダーで値を変える。PDF の図からリンクで飛ぶ（紙に QR コードは足さない）。
あなたの組は、依頼のメッセージに書いた候補（ID）を、1つずつ1ページのアニメーションにする。作業も報告も日本語で行う。

## 2. 作るもの

- 1つの候補 → `anim/items/<ID を小文字>.js`（例：`M3-07` → `anim/items/m3-07.js`）。ファイルの頭に次の行を書く：
  ```
  // @id m3-07
  // @title 短冊を細かくすると面積に近づく
  // @vol 数学5            （数学1〜9・物理1〜5 のどれか。いちばん主になる巻）
  // @uses 3d              （3次元の部品を使うときだけ）
  // @from 数学 5-9・5-10（ch5-09:204 …）
  ```
- 中身は `A.item({...})` を1回よぶ。場面（scenes）は2〜5つ。各場面は、候補の表の「動かすもの」「操作」を1つずつ形にしたもの。
- `@title` は短い名前（ほかの候補と同じ題にしない）。`from` には、もとの巻・章・節を書く（読む人がどの図から来たかわかるように）。
- 書いてよいのは、自分の担当の `anim/items/*.js` だけ。`anim/lib/`・`anim/build/`・ほかの組の項目・`tex/` は変えない（要るものは報告に書く）。ほかのファイルを作るときは、`checks/アニメ/<ID>/` に検算のスクリプトを置いてよい。

## 3. 部品（`anim/lib/core.js`）

- `A.item({ id, title, from, ruby, W, H, state, scenes:[…] })`：ページを作る。`W`×`H` はキャンバスの論理の大きさ（ふつう 880×400〜460）。
- 場面：`{ key, label, lead, note, miss, legend, controls, state, init(st), step(st, dt), draw(cv, st, api), drag, readout(st), autoplay }`
  - `lead`：場面の上の1〜2文（何をするか）。`note`：わかること（下の囲み）。`miss`：まちがえやすいところ（本の「まちがえやすいところ」をもとに）。
  - `step` があると「▶ 再生・ゆっくり」が出る。`false` を返すと止まる。`st.t` などの時間は自分で進める。
  - `controls`：`{ range:'k', label, min, max, step, fmt, d, on }`（スライダー）、`{ seg:'k', label, options:[[値,'名前'],…] }`（切りかえ）、`{ check:'k', label, text }`、`{ button:'名前', act(st, api) }`。**1つの場面にスライダーは3本まで**。
  - `drag`：`{ hit(st, x, y, api) → 何か（null なら当たらない）, move(st, x, y, api, h), end }`。x・y はキャンバスの論理の座標。3次元を回すのは `A.rotDrag([左,上,幅,高さ])`。
  - `readout(st)`：キャンバスの下に出す1行（いまの数）。
  - `legend`：`[['名前', { color, style, shape, noline }], …]`。**線は色と形（style：solid・dash・dot・dashdot・long）、点は形（shape：circle・square・tri・diamond・cross）でも分ける**（K-15）。
- 文：`$…$` は数式（`\frac`・`\sqrt`・`^`・`_`・`\vec`・ギリシャ文字）、`《漢字|よみ》` はルビ、`**…**` は強調。キャンバスの中の文字にはルビはつかない（`《》` は取り除かれる）。
- 描く：`cv.view({ x0, x1, y0, y1, box:[左,上,幅,高さ], equal })` で座標の窓 → `v.axes({ xt, yt, xl, yl, xfmt })`、`v.plot(f, {color, style, width})`、`v.param`、`v.line`、`v.poly`、`v.area`、`v.arrow`、`v.dot`、`v.circle`、`v.text`、`v.inv(px,py)`（ドラッグで値に直す）。キャンバスの座標のままなら `cv.line`・`cv.arrow`・`cv.text` など。
- 色の名前：`a`（青）・`b`（だいだい）・`c`（緑）・`d`（紫）・`e`（黄土）・`ink`・`sub`・`grid`・`hl`。暗い画面でも自動で変わる。
- 便利なもの：`A.num(v, けた)`（マイナスは −）、`A.pi(v)`（π の目もり）、`A.range`、`A.clamp`、`A.rng(種)`（毎回同じ乱数）、`A.gauss`、`A.rk4`。3次元：`new A.View3(cv, { box, yaw, pitch, scale, center })` → `line3`・`arrow3`・`dot3`・`poly3`・`text3`・`axes3`・`surface` → 最後に `flush()`。

## 4. 書き方の決まり

1. **本とそろえる**：数・記号・単位・例題の値・ことば（「まちがえやすいところ」の言い方も）を、もとの章と同じにする。新しい数を出すときは Python か Node で計算して確かめる。
2. **読む人**：第1・2・3巻の候補（M1-・M2-01〜12）は、その巻と同じにひらがなを多くし、漢字には `《漢字|よみ》` でルビをつける（第1巻はとくにやさしく、見本 m1-01）。第4巻から先と物理は、ルビなし・常用漢字まで（本と同じ）。
3. **最初は再生だけで意味がわかる**ようにし、さわると深まる順にする。場面の `lead` で「何を見るか」を1文で言う。
4. **色だけで分けない**：線の形・点の形・文字の札でも分ける。図の中の字は 14px 以上。
5. **スマートフォン**：幅 390px でも横にはみ出さない（キャンバスは自動で縮む。字が小さくなりすぎないよう、キャンバスの中の字は 15px 以上を目安に）。
6. **外のものを使わない**：外のライブラリ・画像・書体を読みこまない。必要な形は自分で描く。1つの項目は 200 KB 以下（ふつうは 60 KB ほど）。
7. **安全・ことば**：放射線・原子力の項目（崩壊・連鎖反応など）は、あおらない。「こわい」演出をしない（N-6・N-7）。危ない実験をまねさせる絵を出さない。
8. **数値計算の項目**（オイラー法・差分・ルンゲ・クッタ）は、本の式と同じ式・同じ刻みで計算し、こわれるようすもそのまま見せる。乱数を使うときは `A.rng(種)` で種を決める。
9. 場面の `key` は英小文字の短い名前（PDF からのリンク `…/<id>.html#<key>` に使う。あとで変えない）。

## 5. 確かめ（項目ごとに必ず）

1. `node anim/build/mk_anim.js <id> …` で組み立てる（`anim/dist/<id>.html` ができる。dist はコミットしない）。
2. `node anim/build/check.js <id> … --shots <scratchpad の下のフォルダ>`：エラー0、キャンバスが空でない、390px ではみ出さない、が通ること。
3. 保存した画像を、場面ごとに全部見る：字と線の重なり、はみ出し、凡例と絵が合っているか、数が本と同じか、動きが正しいか（物理として・数学として）。おかしければ直して、もう一度 1〜3。
4. 再生して最後まで動かしたとき（`step` を長く回したとき）に、値が発散したり、絵が画面の外へ消えたりしないか（check.js は 1.5 秒ぶんしか動かさないので、ちがう時刻の画像も自分で見る：`__ANIM.run(秒)` を使う）。

## 7. 組の報告から足した決まり（11月12日）

- **`A.item({...})` はファイルの最後に書く**（または、描く関数を `function` で書く）。`A.item` は呼ばれたその場で `#場面` を読んで描くので、その下にある `const`・`let` を描く関数で使うと、リンクで開いたときに止まる。check.js は場面ごとに `#key` で開いて確かめる。
- 数式：`\frac{1}{2}` と書く（`\frac12` も1字ずつなら読める）。`\div` は ÷、発散は `\mathrm{div}`。`\dot`・`\ddot`・`\phantom`・`\mathcal{E}`・`\bigl(`・`\overrightarrow` が使える。`pmatrix` は使えない（文で書く）。
- `**…$x$…**` のように、強調の中に数式を入れてよい。
- 確かめの口：`__ANIM.run(秒)`（step がない場面でも描き直す）、`__ANIM.set({名前: 値})`、`__ANIM.redraw()`。
- `#場面&名前=値` の値は、`true`・`false` も使える。値を入れたあと、その名前のコントロールの `on` と、場面の `onhash(st)` が呼ばれる。
- 第1〜3巻（`ruby: true`）は、「再生」「止める」「大きく見る」と足もとの文にも自動でルビがつく。
- スマートフォン：幅が狭いとき、キャンバスの中の字は自動で少し大きくなる（最大 1.3 倍）。「大きく見る」で全画面（横向き）にできる。
- scratchpad は組ごとに自分の下のフォルダ（例 `scratchpad/a13/`）を使う。ほかの組のファイルを上書きしない。
