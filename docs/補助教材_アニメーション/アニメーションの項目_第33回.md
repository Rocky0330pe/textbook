# 補助教材のアニメーション：作る項目（第33回編集委員会）

依頼者の指示（11月12日）：数学1〜9巻・物理1〜5巻の補助教材として、図やグラフのアニメーションを作る。全部は作れないので、理解が深まる図を選ぶ。見せ方は、ホームページの HTML で、スライダーで値を変える。PDF の図から、リンクでそのアニメーションに飛べるようにする（紙の本に QR コードは足さない）。

6つの組（M1〜M4・P1・P2）が14巻の原稿を読み、候補を169個あげた（`候補_*.md`）。同じ考えの図が巻をまたいで何度も出てくるので、**1つのアニメーションを、いくつもの巻・章の図からリンクする**形にまとめた。その結果、作る項目は **48** になった。

## 決めたこと

1. **項目の単位**：1つの項目＝ホームページの1つのページ（HTML 1つ、外のファイルを読みこまない）。中に「場面」（タブ）をいくつか持てる。スライダー・ドラッグ・再生で動かす。スマートフォンでも動くようにする。
2. **リンク**：各項目に変わらない名前（下の表の「名前」。アドレスは `…/anim/名前` の形）をつける。PDF では、表の「リンクする図」の図の横に印を置き、その場面へ直接飛ぶ（`…/anim/名前#場面`）。印の入れ方（共通部品）は、作り始める前にもう一度依頼者と相談する（教科書の全巻が組み直しになるため）。
3. **本とそろえる**：数・記号・ことばは、リンクする章と同じにする（例：ボールの初速 20 m/s、行列 A=(2 1;1 2)、熱の棒の r）。第1〜3巻からリンクする項目は、その巻と同じくルビをつけ、ひらがなを多くする。色だけで分けない（K-15）。
4. **作る順**：第1期（20項目）→ 第2期（14項目）→ 第3期（14項目）。第1期は、多くの巻にまたがるもの・まちがえやすいところを解くもの・各巻に1つ以上、の順で選んだ。
5. **共通の部品**：下の10の部品を先に作り、項目はその組み合わせで作る（作る量を減らす）。

## 作らないことにしたもの

候補のうち、次のものは作らない（または、ほかの項目の場面に入れる）。くわしい理由は `候補_*.md` の「選ばなかったが迷ったもの」。
- 静止画で十分に伝わるもの（2直線の交点、円周角、内角の和、目の高さ、計算の順番、崩壊系列、ヒステリシスなど）。
- 本物の実験・動画・ソフトのほうがよいもの（水のかさ、座屈、翼のまわりの流れ、表計算の番地）。
- 優先度 B・C の単独の候補（M1-05〜09・12・20・22・23、M2-03・05〜08・11・12・17、M3-03・06・09・11・16・25、M4-17、P1-04・09・11・12・16・17・24・25・27・28、P2-11・15・18・24・25・31・32 など）。第3期のあと、余裕があれば足す。
