2. うなりから波束、そして粒へ：P2-27 → P2-10 → P2-29 → P2-26（数学9-4 が土台）。
3. ゆれがつながって波になり、定在波が量子になる：P2-04 → P2-07 → P2-08 → P2-28 → P2-30（分かれ道に P2-31）。
