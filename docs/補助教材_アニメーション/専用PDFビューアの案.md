# 補助教材のアニメーション：専用の PDF ビューアでリンクを出す案（11月12日）

依頼者の問い：「PDFすべてを変えるのではなく、専用PDFビューア上の実装だけでなんとかなりませんか？」

## 答え：できる

本の PDF は変えずに、ホームページに専用の PDF ビューアを置く。ビューアが、アニメーションのある図の上（図の説明の横）に「▶ 動かしてみる」のボタンを重ねて出す。押すとその項目の場面が開く（`…/anim/<id>.html#<場面>`）。

- 共通部品（`tex/bk-*.sty`）は変えない。教科書の全巻の組み直しも要らない。
- リンクの追加・直しは、ビューアの「図の場所の表」（JSON）を変えるだけ。本の版を出し直さなくてよい。

## しくみ

1. **PDF を表示**：PDF.js（Mozilla、Apache-2.0）をビューアの HTML に入れる（外のファイルを読みこまない決まりのため。約 1.5 MB。利用条件の文をビューアに書く）。ページは見えている所だけ描くので、780ページの本でも軽い。
2. **図の場所の表を自動で作る**：候補の表の原稿の行（例 `p5-15:283`）から、そこの図の説明（`\bkfigcaption`）の文を取り出し、組んだ PDF の中でその文をさがして、ページと位置を得る（PyMuPDF）。本の新しい版が出たら、作り直すだけ。
   - 試し（第5巻、11月12日）：候補 P2 の第5巻の図 22 か所のうち **19 か所（86 %）が自動で見つかった**（例：P2-35 の図はまだ見つからない）。見つからないもの（数式の多い図の説明、図の説明のない囲み・プログラム）は、近くの文でさがすか、手で場所を書く。
3. **ボタンを重ねる**：ページの絵の上に、表の位置でボタンを置く。拡大・縮小に合わせて動く。

## 気をつけること

| 件 | 中身 | 対応 |
| --- | --- | --- |
| 読む場所 | ボタンが出るのは、このビューアで読むときだけ。ダウンロードした PDF を手元のアプリで読むときは出ない | ホームページの本のページから「ビューアで読む」をすすめる。手元のアプリ向けには、のちに本の新しい版を出すとき、ついでにリンクを入れることもできる（入れなくてもよい） |
| PDF の置き場所 | ブラウザの決まりで、GitHub の Releases の PDF をビューアから直接は読めない。ホームページに PDF を置く必要がある | 1冊 6〜7 MB（vol6・vol9・物理1・3・4 の実測）、14冊で約 90 MB。1ファイル 50 MB 未満の決まりには入る。版を出すたびにホームページの履歴が約 90 MB ずつふえる（GitHub Pages の 1 GB に対して、数回の版までは問題ない） |
| ページの番号 | 版が変わると、図のページがずれる | 表を版ごとに作り直す（自動） |

## 進め方（案）

1. 169項目のアニメーションを作り終える（いま13組で作っている）。
2. ビューアと、図の場所の表を作る（第5巻で試してから全巻）。
3. ホームページへ送る前に依頼者に確かめる：PDF をホームページに置いてよいか、置き場所（`apps/anim/`・`apps/viewer/` など）。
