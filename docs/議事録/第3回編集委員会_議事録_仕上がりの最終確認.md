## 4. 議論の記録

### 「はてな？」の札の色（指摘2）

- デザイナー：「文字を黄色く」とのご提案ですが、白地に黄色の文字は明るさの差が小さく読みにくくなります。囲みと同じ「？」のアイコンを入れ、地を淡い黄色、文字を濃い黄色（からし色）の太字にします。黄色の囲みを指していることは色でも形でもわかります。
- 特別支援学校教諭：色だけに頼らず、アイコンの形でも見分けられるのがよいです。色の見え方がちがう子にも届きます。
- 小学校教師：本文から例題を指すときにも使えます。2-3のヒント「例題1と同じ」を同じ札にしましょう。
- YouTuber：ボタンのように見えるので、「戻って見てみよう」という気持ちになります。
- 結論：囲みを指す札を部品にし（はてな？・例題・やってみよう）、本文で囲みを指すときは必ずこの札を使う。

### 章の帯（指摘1）

- 数学教授：帯の高さが章ごとに変わってよいのですか。
- デザイナー：1行の題名は今までと同じ 3.1 cm のままで、2行のときだけ高くなります。上下の空きはいつも同じ比率なので、そろって見えます。★は題名とぶつからないよう、部の名前と同じ上の行に移します。
- 結論：帯は題名の高さに合わせて自動で決める。

### 空いているページ（No.19）

- デザイナー：46・52・55ページに大きな空きがあります。章は14ページと決まっているので、ページは余っています。
- 教育学教授：飾りで埋めるのではなく、中身で埋めましょう。この章で出会った記号（Δ と m/s）を記号カードにすれば、巻末の記号カードの練習にもなります。
- 電気工学教授：52ページには、家の電気のメーターの kWh を入れたい。「1時間あたりの量×時間」で新しい単位ができる、この章の考えそのものです。
- 心理士：章の終わりのページには、メモらんがあると安心します。書いて考える場所になります。
- 特別支援学校教諭：メモらんの線は細い点線にして、目立ちすぎないように。
- 結論：46に記号カード、52にコラム、55に次の章への案内とメモらん。ふきだしは「1見開き1回まで」の約束を守る。

### 例題を5つにするか（No.29）

- 教育学教授：「この本の使い方」に「例題は、章末問題に出てくる問題の形を、ぜんぶ1回ずつ解いて見せています」と書いてあります。基本2の「たせる・たせない」は、この章のいちばん大事な目標なのに、例題がありません。
- 小学校教師：まちがえやすいところで「1 m＋50 cm」は見せていますが、子どもは囲みの種類で探します。例題の形にしてください。
- デザイナー：例題を足すと1ページあふれます。Δのコラムは46ページの記号カードと同じ中身なので外し、じぶんでとこうの「しき」と「こたえ」を1行にすれば、14ページに収まります。
- 数学教授：例題4つは「最低限」と考えましょう。約束を守るほうが先です。
- 結論：例題1「たし算：たせる？ たせない？」を足して5つにする。第2回の「1章の例題は4つ」は「4つを基本とし、足りなければ足す」に改める。

### 第4巻からの「式」「答え」（No.11）

- 数学教授：第8巻では、例題は「しき」、書きこみらんは「式」でした。どちらかにそろえます。
- 小学校教師：第1〜3巻は「しき」「こたえ」でそろっているので変えないでください。小さい子には、ひらがなのほうがラベルとして読みやすいです。
- 結論：第1〜3巻は「しき」「こたえ」、第4巻からは「式」「答え」。巻の番号で自動で切りかえる。

### 内容のまちがい（No.20〜22）

- 電気工学教授：ガウスの法則は、電場の発散と「電荷の密度」の関係です。「電荷に比例」と書くと、点の電荷のまわりでも発散が0でないように読めてしまいます。
- 機械工学教授：熱の流れの発散は「出ていく量」です。熱がたまって温度が上がる所は、入るほうが多いので負になります。前の書き方では符号が逆に読めました。
- 数学教授：マイナス記号とハイフンは別の記号です。表の数値は必ずマイナス記号で書きます。式が行末で2つに割れるのも禁止です。
- 結論：3件とも直した。物理の説明は、その分野の教授が必ず読む。

### 第1巻の前付け（No.14〜16）

- 幼稚園教諭：表2のなかまの紹介は、おうちの人といっしょに読むページですが、子どもが自分でも読めるようにしたいです。
- 特別支援学校教諭：語の途中で改行すると、そこで読めなくなる子がいます。本文と同じ分かち書きにしてください。
- 心理士：もくじは「この本で何ができるか」を見る大事なページです。1ページに1つの部なら、見通しが立ちやすくなります。
- 結論：第1巻は前付けも分かち書き。もくじは1ページに1部。保護者向けの囲みは大人向けなので今のまま。
