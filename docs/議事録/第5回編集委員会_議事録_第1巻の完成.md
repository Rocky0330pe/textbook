## 4. 第1巻のことばのきまり（第5回で足したもの）

| きまり | 理由 |
| --- | --- |
| 「くらい」は位（十の くらい）の意味だけに使う。「だいたい」の意味には「だいたい」「ほど」 | 「ゆびの はば くらい」と「十の くらい」がまぎれる（教育学教授） |
| 「くり上がり」「くり下がり」は 1-7 で教える。1-4 では「10を こえる」と言う | 1-10 の「60で くり上がる」が、説明のないことばになっていた |
| 「ばい」は使わない | 説明していない（倍は第2巻）。路線の名前「倍々の 路線」だけは固有名として残す |
| 「1つ\R{分}{ぶん}」の書き方を1つにする | 「1つ 分」「1つぶん」「1つ分」がまざっていた |
| 「たんい」はひらがなで書く | 部扉と巻末だけ漢字になっていた |
| 名前を紹介したあとは「数直線」 | 1-6 の中で「かずの 線」とまざっていた |
| ことばだけで式を決めない（「〜ずつは かけ算」「きましたは たし算」など） | 1-14（3こずつ 分ける＝わり算）、1-5（ふえた分を きくなら ひき算）と食い違う。場面で「何を きいて いるか」から式を決める |
| 案内役に敬称はつけない（ソラ・ミナ・デルタ） | 1か所だけ「ソラさん」になっていた |

## 9. 変えなかったことと、その理由

- **右ページの柱（章名）はひらがなのまま**：左ページは部の名前を漢字とルビで、右ページは章名をひらがなで出している（「1-14 わりざんは…」）。柱の字は小さいので、ルビをつけると読めない。漢字だけにすると1年生が読めない（特別支援学校教諭・デザイナー）。
- **もくじは1部1ページのまま**：1ページに入れる量をしぼるため（第3回の決定）。部の少ないページは下が空くが、そのままにした。
- **章の題名「かわった 量」の字間**：「量」のルビ「りょう」が親字より長いので、前の空白と合わせて少し広く見える。ルビを前の字にかける設定も試したが変わらず、読みに支障はないので許容した。
- **時計の長針が数字に重なる場面**：本物の時計でも起こることなので、問題になる場面（はてな？・ストップウォッチ）だけ時刻をずらし、ほかはそのままにした。
- **「倍々の 路線」の名前**：「ばい」は使わないきまりだが、路線の名前は全巻共通の固有名なので残した。
- **1-19 のさくいんの語が12語**：きまり（1章に3〜5語）より多いが、形の名前（三角形・四角形・長方形・正方形・直角三角形・直径など）はどれも引きたい語なので、そのままにした。
- **一部の何十の計算（70 － 40、90 － 70、6 ＋ 12）には手がかりをつけていない**：1-7 のれいだい1（10の まとまり）の形そのもので、ページにも余裕がないため。
- **ひっ算の部品を共通の部品にすること**：1-7 の担当から提案があったが、第2巻からは電卓と表計算を使う方針なので、第1巻の中にとどめた。問題集を作るときに共通にする。
