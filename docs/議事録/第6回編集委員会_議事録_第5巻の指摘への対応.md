## 2. 分科会の話し合い

### A 定積分の教え方（V10〜V13）

**原因**
- 「はばをかぎりなく細くする」は、表の数字と文章だけで説明していた。図は n＝4 の1枚だけだった。
- ∫₀¹x²dx＝1/3 は、③で求めた lim Sₙ＝1/3 と同じものだと、どこにも書いていなかった。そのうえ③と④のあいだに「もっと知りたい」が2つはさまり、話が切れていた。
- 記号の説明が一般形（f(x)、a、b）から始まり、xₖ・Δx も定義していなかった。
- 「たいせつ」に、意味（定義）と計算の結果 b³/3 を同じ形で並べていたため、結果が「覚える公式」に見えた。
- 例題3は b に3を入れたことが書かれていなかった（3が3つ出てきて、どれが何かわからない）。例題4は「3は外に出せる」の理由がかっこ書き1文だけだった。

**委員の意見**
- 数学教授：「右はしの和の極限が1/3」と「ほんとうの面積が1/3」は別のこと。はさみうちで面積が1/3だと言い切る1行がいる。定数倍は「長方形が3倍→和が3倍→極限も3倍」で正確に言える。
- 教育学教授：数（表）→形（図）→記号の順にすれば、∫ が「細い長方形の和の行き先」として入る。まず具体的な ∫₀¹x²dx で記号の各部分を読ませ、そのあと一般の形にする。
- 小学校教師：黒板なら n＝4→8→16 とかいて見せる場面。はみ出しを指させるように色を分けてほしい。「3が3つ」と「3×8/3 の約分」は授業で必ず止まる所。
- 心理士：1/3 は「自分たちが表で見つけた数」だと書けば、知らない式ではなく自分の発見になる。「覚えなくても、いつでも作れる」の一言で暗記の負担と不安がへる。

### B 図・挿絵（V1〜V3、V7、V9、V14）

**原因**
- V1・V2：線をなめらかにつないでいたので、水平な（止まっている）区間がなく、ゆるい波にしか見えなかった。「信号で止まった」の引き出し線が曲線とほぼ平行に線の上を走っていた。
- V3：タイヤの矢印が反時計回りだった（右へ転がるなら時計回り）。タイヤの大きさと目もりの縮尺も合っていなかった。
- V7：歯数の比（18：6：3）は合っていたが、歯車どうしにすき間があり、歯と歯が正面からぶつかる位置で、3枚歯の歯車はありえない形だった。説明文が A の歯に重なっていた。
- V9：目もり数字 3・5 が、−4 の赤い四角の中に出ていた。
- V14：円板の塗りは長方形、輪郭はだ円で、形がずれていた。y の矢印は円板からはなれた所で終わり、r には半径の線がなかった。

**委員の意見**
- 機械工学教授：信号1回の停止は1〜2分で、この縮尺では幅1mmにもならない。長く止まる区間は「止まった（休けい）」とし、信号は本文でふれる。歯車は、ピッチ円どうしが接し、片方の歯がもう片方の歯みぞに入るように。かみ合う歯車は逆向きに回ることも矢印で示す。
- 電気工学教授：例題1の表（0.5時間ごとの位置）とグラフがずれると子どもが混乱するので、新しいグラフもその点を必ず通すこと。歯の数を書けば「数の比＝回転数の逆比」（変圧器の巻数比と同じ考え）につながる。
- YouTuber：「線が寝ている＝止まっている」「坂がゆるい＝のろのろ」を、色の帯でひと目でわかるようにしたい。
- イラストレーター：引き出し線は使わず、区間に薄い帯を敷いて見出しを帯の真上に置く。歯車は歯つきの外形を1本の線で描き、塗り分ける。円板は上面を明るく、側面を濃く、塗りと輪郭を同じ形で描く。

### C レイアウト（V4〜V6、V8、V15〜V17）

**原因**
- V4：「まちがえやすいところ」の帯に、名前と題を1行で入れていた。題が長いと帯が箱の右の枠から最大5mm はみ出した（第5巻で4か所）。
- V5：文中の式は「＝」「＋」のあとで改行できる設定のままだった。×の式と○の式を1行に並べていたため、入りきらずに「＝」のあとで折り返した。第5巻には、ほかにも約50行、行末に「＝」が残る行があった。
- V6：箱の中身が箱の幅より広く、箱が広がった分だけ、座標で描いていた矢印が枠に刺さった。
- V8：箱の内側の余白が2mm しかなく、矢印の文字は8pt で、点線のラベルが右の箱の枠にかかっていた。
- V15：行と行の最小のすき間が1pt のままで、分数のある行どうしが近づいていた。箱の下の余白は最後の行の下から測るため、分母のすぐ下に枠が来ていた。記号カードの前後は6pt しかなかった。
- V16：第5回で、もくじの巻末の行を全巻で直していた（\bktocbacklist）。今の版では直っていることを確かめた。
- V17：部扉の左上の「1」は、部のつめ（インデックス）の番号だった。色の面の上につめを描いていたため、四角が背景にとけて白い数字だけが浮いて見えた。

**委員の意見**
- デザイナー：帯は部品の名前、題は中身。帯の長さを全部そろえれば右端がそろう。行の終わりに「＝」を残さない。矢印は必ず箱の名前どうしでつなぎ、両端をはなす。余白の値は全巻で1つにそろえる。部扉は色の面がページの端まであるので、つめは要らない。
- 特別支援学校教諭：題が箱の1行目にあれば、「題→×→○→わけ」と上から1本の流れで読める。×は上、○は下に置き、記号の位置をそろえる。「はい は右、いいえ は下」と向きを決めると迷わない。意味のわからない数字は読む子のじゃまになる。
- 幼稚園教諭：答えが次の行の頭にぽつんと出ると、子どもが不安になる。最後の答えが枠から離れていると、ほっとして読み終われる。

### 4.1 共通の部品を変えたことで、ページ数がふえた章の調整

3.2 の共通の部品の直し（とくに「＝」のあとで改行しない、行の最小のすき間、まちがえやすいところの題の行、×と○を1行ずつ）を入れると、第5巻の18章のうち15章が、計画のページ数（12・16）を1〜2ページこえた。そこで、章ごとに担当を決めて組み直した。

- 長い文中の式は別行立てにし、それでも入らないときは「＝」の前で切って、次の行を「＝」から始めた。
- 詰め方の順番は次のとおり。例題・じぶんでとこう・章末問題・途中式は1つも消していない。

  3. 言い回し・くり返しをけずる
  4. 同じ節の中で箱の順番を入れかえる
