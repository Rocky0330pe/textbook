## 決まったこと

### M-1 書名と、教科書との関係

- 書名は『物理を理解するための数学 問題集』第1〜9巻とする。
- 巻の色・章の番号・ふりがなの決まりは、教科書の同じ巻にそろえる。
  - 第1巻はひらがな中心、第2巻からは常用漢字にルビ、というように、教科書と同じ決まりにする。
- どのパターンにも、教科書のどの章・節で学ぶかの札をつける（例：「教科書 2-4 ③」）。
- 問題集だけで読んでもわかるように、パターンのページには「なぜ楽になるか」を1〜3行で書く。くわしい説明は教科書を指す。

### M-2 本の大きさ

- 問題集の本は、教科書と同じ **B5（182×257 mm）** にする。
  - 理由1：本だなで教科書と並ぶ。
  - 理由2：教科書の部品（色・札・囲み・記号カード）をそのまま使える。
- 練習プリントのアプリは **A4** で出す（学校・家庭のプリンターの紙）。本とアプリは同じパターンの番号でつなぐ（M-9）。
- 書きこみ方は、教科書と同じ考え方にする。
  - 第1〜2巻：本に書きこむ。答えの欄と、計算の余白をとる。
  - 第3〜9巻：答えの欄だけを置き、途中の計算はノートに書く。

### M-3 単位は「パターン」、1パターン＝見開き1つ

1つのパターンを、見開き（左右2ページ）にまとめる。式が長い巻（第5〜9巻）は、見開き2つまでとする。

```
┌──────────────── 左ページ ────────────────┐┌──────────────── 右ページ ────────────────┐
│［P2-4-03］× 9 は「10倍して1つ引く」   教科書 2-4│ステップ2　少し形を変える（8〜10問）         │
│                                        ★の段  ││ 例：19×9、9×47、99×6 …                     │
│■ 見分ける目印（どこを見ればよいか）            ││                                            │
│  かける数が 9・99・999（10・100 に近い）       ││ステップ3　見かけがちがう（6〜8問）          │
│■ 楽な形にする（ふつうの解き方と並べる）        ││ 例：48×11、25×36、998×7 …                 │
│  ふつう：筆算で 3 行  ／ 楽：1 行              ││                                            │
│  47×9 ＝ 47×10 − 47 ＝ 470 − 47 ＝ 423        ││わなに注意（2〜3問）                        │
│■ なぜ楽になる？（分配法則。教科書 2-3）        ││ 目印に似ているが、楽にならない問題          │
│■ 使えないとき・気をつけること                  ││ 例：47×8（10−2 にすると、かえって手間）     │
│                                                ││                                            │
│ステップ1　そのまま使う（10問）                  ││ふりかえり：□10問 □18問 □26問 解けた       │
│ 例：23×9、56×9 …                               ││                                            │
└────────────────────────────────────────────────┘└────────────────────────────────────────────┘
```

- 1パターンの問題数は **20〜30問**。次の4つの段に分ける。

| 段 | 中身 | 数の目安 |
| --- | --- | --- |
| ステップ1　そのまま使う | 目印がはっきり見え、すぐ楽な形にできる | 10問 |
| ステップ2　少し形を変える | 1つ手を加えると目印が出る（例：$9\times47$、$19\times9$） | 8〜10問 |
| ステップ3　見かけがちがう | 同じしくみが、ちがう姿で出る（例：$\times11=\times10+\times1$、$\times99$、$998\times7$） | 6〜8問 |
| わなに注意 | 目印に似ているが、楽にならない・使えない問題 | 2〜3問 |

- 左ページには、次のものを置く。
  - パターンの名前と番号
  - 見分ける目印
  - 「ふつうの解き方」と「楽な解き方」を並べた図。手間の差を、行数や手順の数で見せる。
  - なぜ楽になるか
  - 使えないとき・気をつけること
- 答えには、数の答えだけでなく、**途中の「楽な形」**（例：$470-47$）も書く。

### M-4 「見分ける力」を養うページ

- 章（またはいくつかのパターン）の終わりに、**「見分けよう」**の見開きを置く。
  - いろいろなパターンの問題をまぜて並べる。
  - 1問ごとに、まず使うパターンの記号（ア・イ・ウ…、または番号）を書き、それから解く。
  - 答えには、使えるパターンをすべて書く。1つの問題に2つ以上使えるときは、どちらが楽かも書く。
- 「わなに注意」の問題もまぜる。「どれも使わない（ふつうに解く）」も、答えの1つにする。

### M-5 「作る力」を養うページ

- 章の終わりに、**「作ってみよう」**を置く。問いの形は、次の3つにする。
  - 楽な形に作りかえる：「$36\times25$ を、楽に計算できる形に書きかえよう」
  - 楽に解ける問題を作る：「$\times9$ のパターンで楽に解ける問題を3つ作ろう」
  - 楽になるように数を選ぶ：「□に数を入れて、因数分解できる式にしよう」
- 答えが1つに決まらない問いには、答えの例と、「こうなっていれば正解」という確かめ方を書く。

### M-6 巻の組み立て

- 巻の頭に「この巻のパターン一覧」を置く。番号・名前・目印・ページ・教科書の章の表にする。
- 本文は、教科書の章の順にパターンを並べる。
- 巻末には次のものを置く。
  - こたえ（楽な形つき）
  - パターンのさくいん（目印から引ける）
  - 教科書との対応表
- 1冊のパターンの数は、章あたり2〜6を目安にする。すべての章にパターンがあるわけではない。図・言葉の章（例：1-19 かたち、4-1 定義・公理）は少なくてよい。
- 教科書の「★の段」に合わせて、パターンにも★をつける（物理の巻ではなく、数学シリーズの★の物差し）。

### M-7 パターンの書き方の決まり

- パターンの番号は「P巻-章-通し番号」（例：P2-4-03）。本とアプリで同じ番号を使う。
- 1つのパターンには、次の5つを必ず書く。
  1. 目印
  2. 楽な形
  3. なぜ楽になるか（どの法則か）
  4. 使えないとき
  5. ふつうの解き方との手間の差
- 色だけで目印を示さない。下線・囲み・矢印でも示す（K-15 と同じ）。

### M-8 作り方

- はじめに、巻ごとの**パターン目録**（パターンの一覧と、目印・楽な形・問題の作り方）を作る。目録は、第3巻の計画書と同じように、委員会で決める。
- 問題の数は、プログラムで作って検算する（M-9 のアプリと同じ作り方）。人が選んで並べ、ステップ3・わな・作ってみようは人が書く。
- 順番：第1巻と第2巻の目録と見本の見開きを先に作って委員会で見る。そのあと、第3〜9巻へ進む。

### M-9 練習プリント自動作成アプリの方針

- **ブラウザだけで動く**ようにする。サーバーも生成AIも使わない。
  - 静的なページ1つにまとめ、GitHub Pages などに置ける形にする。
  - オフラインでも動くように、使うライブラリはリポジトリに入れる。
- 使い方：
  - パターン（または章）・問題の数・段（ステップ1〜3・わな・まぜる）を選ぶ。
  - A4 のプリント（問題）と、こたえのページ（楽な形つき）を、ブラウザの印刷から出す。
- 同じプリントをもう一度出せるように、プリントに**種の番号**（乱数の種）を印刷する。
- 数式は KaTeX、図は SVG で組む。A4 は CSS の `@page { size: A4 }` で決める。
- 問題を作るプログラム（パターンごとの「作り方」）は **JavaScript で1つだけ**書く。
  - アプリは、そのプログラムをブラウザで動かす。
  - 本は、同じプログラムを Node.js で動かし、LaTeX の問題と答えを書き出す。
  - こうすると、本とアプリの問題の作り方・数・答えが、1つのところから出てずれない。
- 答えは、作るときに決める。答えから問題を逆に作る（例：因数分解は、因数を先に選んでから展開する）。そのあと、数をいくつか代入して、問題と答えが等しいことを確かめる。

## アルゴリズムだけで作れる分野・作れない分野

### 分け方

| 区分 | 意味 | 作り方 |
| --- | --- | --- |
| **A　自動で作れる** | 数や式を変えて何問でも作れる。答えと検算も自動 | 生成のプログラムだけ |
| **B　型紙があれば作れる** | 人が書いた文・図の「型紙」に、数を入れかえて作る | 人が型紙を書き、プログラムが数を選んで検算する |
| **C　自動では作れない** | 問題そのものや、答えの正しさの判定を、アルゴリズムで作れない | 人が作った問題を、問題の在庫から選ぶだけ |

### 分野ごとの判定

| 分野 | 区分 | 理由・作り方 |
| --- | --- | --- |
| 整数の四則・九九・筆算・暗算のパターン（$\times9$、$\times25$、$\times11$、補数、分配法則、くり上がり） | A | 数を選ぶだけ。筆算の形も、けたをそろえた表で組める |
| 分数・小数の計算、約分・通分、比・割合・百分率 | A | 有理数をそのまま扱う（BigInt の分数）。約分しやすい数を先に選ぶ |
| 単位の換算（長さ・かさ・時間・SI） | A | 換算表から作る |
| 時計の読み・目もりの読み・数直線 | A | 針・目もりを SVG でかく |
| 正負の数、累乗・指数法則、平方根の簡約・有理化 | A | 決まった変形の組み合わせ |
| 2進数・16進数 | A | 変換の手順がそのまま答え |
| 文字式の計算・代入・式の変形（ほしい文字について解く） | A | 式の木（数式を枝分かれで表したもの）で計算する。1次の式なら、どの文字についても解ける |
| 展開・因数分解・平方完成 | A | 因数を先に選んで展開すると、必ず因数分解できる問題になる |
| 1次方程式・連立方程式・2次方程式・不等式 | A | 解を先に選び、そこから式を作る |
| 比例・反比例・1次関数・2次関数の式とグラフ | A | グラフは SVG。きれいな格子点を通るように係数を選ぶ |
| 指数関数・対数の計算 | A | 底と真数を、答えが整数や簡単な分数になるように選ぶ |
| 平均・中央値・分散・標準偏差・相関・最小二乗 | A | 答えがきれいな数になるデータを、先に作る |
| 角度・ラジアンの換算、特別な角の三角比 | A | 表から作る |
| 三平方の定理・相似比・正弦定理・余弦定理 | A | ピタゴラス数や、きれいな値になる三角形を先に選ぶ。図は SVG |
| 加法定理・三角関数の合成・うなり | A | 決まった変形 |
| ベクトルの成分・内積・外積・座標の変換 | A | 整数の成分で作る |
| 極限（多項式・有理式・決まった形） | A | 型ごとに作る |
| 微分（多項式・積・商・合成・三角・指数・対数） | A | 微分は決まった規則の計算なので、式の木でできる |
| 積分（不定積分・定積分・置換・部分積分） | A | ある関数を微分して問題を作る（逆向きに作る）と、必ず答えのある問題になる。置換・部分積分は「型」を決めて作る |
| テイラー展開・近似の計算 | A | 係数の計算 |
| 微分方程式（変数分離・1階線形・定数係数2階・強制振動の特殊解） | A | 特性方程式の解を先に選ぶ。係数比較の型で作る |
| オイラー法の表 | A | 表を計算して出す |
| 複素数・複素平面・オイラーの公式・双曲線関数 | A | 決まった計算 |
| 行列の計算・行列式・逆行列・回転・固有値・対角化 | A | 固有値と固有ベクトルを先に選び、$PDP^{-1}$ で作ると整数の答えになる |
| 偏微分・全微分・grad・div・rot・ラプラシアン | A | 多項式や決まった関数のベクトル場なら、微分の規則で計算できる |
| 重積分・線積分・面積分（長方形・三角形・円・球などの決まった形） | A | 形ごとの型で作る |
| フーリエ級数の係数（方形波・のこぎり波・三角波など）・直交性 | A | 波の型と、周期・高さを入れかえて作る |
| ラプラス変換と逆変換・部分分数・伝達関数・極と安定性・行列の指数関数 | A | 極を先に選び、部分分数で答えが出るように作る |
| 文章題（買い物・速さ・割合・追いつく・濃さ など） | B | 人が書いた文の型に、自然な範囲の数を入れる。「人数が整数」「答えが現実的」などの条件をプログラムで確かめる。新しい場面の文を作ることは、生成AIなしではできない |
| 図形の角・面積・体積 | B | 三角形・四角形・円・決まった立体なら、形を変えて SVG でかける。補助線が要る問題や、組み合わせた図形は、人が作った型紙が要る |
| 表・グラフの読み取り | B | データとグラフは作れる。問いの文は型紙 |
| 確率・場合の数 | B | さいころ・コイン・カードなどの型紙で作る。数え上げで答えを確かめられる |
| 物理や暮らしのモデル化（仕事・流量・冷めるお湯・ばね・回路・強制振動 など） | B | 場面の型紙に数を入れる。式と答えは自動 |
| 偏微分方程式・div と rot の式を読む（8-13・8-14） | B | 変数分離で解ける型だけ作れる。式の意味を読み取る問いは型紙が要る |
| プログラムや表計算の結果を読む（2-18・2-19） | B | 短いプログラムの型に数を入れ、実行して答えを出す |
| 「見分けよう」（まぜた問題で、使うパターンを答える） | A（計算の分野）／B（文章題・図形） | 問題を作ったプログラムが、どのパターンで作ったかを知っているので、答えを自動で出せる。ほかのパターンでも楽に解けるかは、目印を判定するプログラム（パターンごとの判定の規則）で確かめる。計算の分野なら規則で判定できるが、積分の解き方の選び方などは、あいまいな場合がある |
| 「作ってみよう」（楽な形に作りかえる・数を選ぶ） | B | 問いは型紙で作れる。答えの例も出せる。数式で答えが書かれていれば等しいかを確かめられるが、プリントでは採点しない |
| 「作ってみよう」（楽に解ける問題を自分で作る） | C | 答えが自由で、よい問題かどうかを判定できない。答えの例と確かめ方を、人が書く |
| 証明（定義・公理・定理、図形の証明、4-1 など） | C | 意味のある証明問題を作ることも、書かれた証明の正しさを判定することもできない。人が作った問題の在庫から出す |
| 「なぜ〜か説明しよう」・言葉で答える問い | C | 答えの文を作ることも判定することもできない |
| 新しい場面の文章題・身近な場面の絵 | C | 新しい場面の文や絵を作るのは、生成AIの役目になる。人が書いた型紙と、絵の部品の在庫で代える |

### まとめ

- 数学シリーズの計算の分野は、第1巻の四則から第9巻のラプラス変換まで、ほとんどが **A（自動で作れる）**。
  - 大事なのは「答えを先に選んで、問題を逆に作る」ことと、「数を代入して確かめる」ことの2つ。これで、きれいな答えの問題を何問でも作れ、答えのまちがいも防げる。
- 文章題・図形・モデル化は **B（型紙）**。人が型紙を書けば、数を変えて何問でも作れる。型紙の数が、問題の幅になる。
- 証明・説明・自由に作る問題は **C**。アプリでは、人が作った問題の在庫から出すか、扱わない。

## 議論の記録

- **小学校教師**：$\times9$ のような工夫は、子どもが自分で見つけるとうれしいものです。ただ、「わな」がないと、何にでも当てはめようとします。目印に似ているのに楽にならない問題を、必ず入れてください。
- **数学教授**：楽な形は、どれも分配法則・結合法則・交換法則・乗法公式・対称性のどれかから来ています。パターンのページには「なぜ楽になるか」を1行書き、教科書のその節を指すと、暗記で終わりません。高い巻では、置換積分・部分分数・対角化・極の位置など、「楽な形を作る」こと自体が解き方の中心になります。
- **教育学教授**：見分ける力は、パターンごとの練習だけでは育ちません。まぜた問題で「どれを使うか」を先に言わせる「見分けよう」を、章ごとに置くのがよいと思います。作る力は、答えが1つでない問いになるので、確かめ方を示すことが大事です。
- **心理士**：1パターン20〜30問は、続けて解くと疲れます。ステップごとに区切りと「ふりかえり」の印を置き、できた数がわかるようにしましょう。
- **特別支援学校教諭・デザイナー**：目印は色だけでなく、下線・囲み・矢印でも示してください。1ページの問題の数を詰めすぎず、答えの欄を大きくとります。第1巻の書きこみ欄は、教科書の `\bkshikiran` と同じ形がよいと思います。
- **幼稚園教諭・イラストレーター**：第1巻は、おはじき・10のまとまりの絵が楽な形の理由になります。絵の部品は教科書の第1巻のものを使えます。アプリでも、同じ部品を SVG にしておくと、プリントに絵を入れられます。
- **電気工学教授**：アプリで本と同じ問題を出すには、問題を作るプログラムを1つにまとめることが大事です。JavaScript で書けば、ブラウザでも Node.js でも動きます。答えは、作るときに決めてから、数を代入して確かめれば、まちがいを防げます。
- **機械工学教授**：第6〜9巻は、生成AIがなくても、ほとんど自動で作れます。固有値や極を先に選べば、整数のきれいな答えになります。むずかしいのは、物理の場面の文章題です。型紙を人が書く必要があります。
- **YouTuber**：プリントに種の番号が入っていれば、「この番号のプリントをやってみて」と同じ問題を配れます。動画や授業で使いやすくなります。
- **校長（まとめ）**：本は B5 で教科書と並べ、アプリは A4 で数を変えて何枚でも出せるようにします。2つは同じパターンの番号と、同じ問題を作るプログラムでつなぎます。まず第1・2巻の目録と見本の見開き、アプリの試作を作って、次回の委員会で見ます。
