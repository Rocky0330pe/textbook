## 決まったこと

1. **目録を決めた。**
   - 目録の組（2つ）が、教科書 第2巻（2-1〜2-19）・第3巻（3-1〜3-17）の章を読み、楽に解ける形を洗い出した。
   - 第2巻 99わざ（6部）、第3巻 99わざ（6部）。番号は2けたまで（アプリに入れる番号なので変えない）。案の「あとで足す候補」から、新しいわざにするものを 2-90〜2-99・3-91〜3-99 として足し、のこりはほかのわざのステップ3・わなに入れた。
   - ★は第1巻と同じく「1＝教科書のその巻の中、2＝少し先」。教科書の章の★（むずかしさの段）とは別の物差しで、前付に書く。
   - 外したもの（ことばで答える問い・証明・図がいるグラフの読み・表計算の操作など）は、目録にわけを書いた。図がいるものは第2版で考える。
2. **エンジンを広げた（第2巻から）。**
   - 文の中の式を `$…$`（TeX の書き方の一部）で書く。本ではそのまま TeX（分数は大きく、指数の中は小さく）、アプリでは HTML の式（分数・ルート・指数・斜体の文字）に組む。外のライブラリは使わない。
   - 検算：答えが式なら、文字に3とおりの値を入れて、問題・答え・楽な形の式が同じ値か確かめる（`evalMath`）。方程式の解・変域・ことばの答えは、組が `verify` で確かめる。帯分数・`\log`・`\sqrt[n]{}` も読む。
   - 分数の部品 `M.F`、「分」の読みの部品 `M.fun`、コード（`` `…` ``）の組み方、高い欄（`boxh`）。
   - 第2巻からは、見出し・前付・見わけよう・作ってみようの言葉を、教科書と同じく漢字にルビにする（分かち書きにしない）。
3. **書く組12（第2巻 a〜f、第3巻 a〜f）が、同時に書いた。** 組ごとに別の作業場所（worktree）で書き、部の表（`parts.js`）は組ごとの部の項目を組み立てた（`mondai/build/merge_parts.py`）。
4. **確認は4つの組（各巻 R1・R2）で1回。**
   - 指摘は159件（第2巻 R1 40・R2 40、第3巻 R1 34・R2 45）。**数学の答えのまちがいは0**（本に出る問題、見わけよう、作ってみようの答えを、目と、わざとは別に書いた計算で確かめた。第2巻 R2 は約16000問を計算し直した）。
   - おもな指摘：そのわざ自身で解けてしまう「わな」、ルビの読み（分・人・本など）、教科書の札と★、表紙・使い方の見本が第1巻のまま、奥付のルビ、アプリの欄・分数の線・A4 のあふれ、2-86 の `\times` が「imes」になる字化け。
5. **J-1〜J-10 を決めた**（`決定_第30回.md`）。事務局が共通部分を、直しの組4つ（各巻の前半・後半）がわざを直した。
