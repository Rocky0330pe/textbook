# 第33回編集委員会 議事録：補助教材のアニメーションにする図

- 日時：2026年11月12日
- 出席：12人全員（校長〈まとめ役〉、数学・電気工学・機械工学・教育学の各教授、幼稚園教諭、特別支援学校教諭、心理士、科学解説 YouTuber、小学校教師、デザイナー、イラストレーター）
- 依頼者の指示（11月12日）：「数学1〜9、物理1〜5巻の補助教材として、グラフや図のアニメーションを作ろうと考えてます。全てのアニメーションを作ることは現実的ではないので、どの教科書のどの図やグラフをアニメーションにしたら理解が深まるかを話し合い、アニメーションにする項目を洗い出してください。」
- 見せ方（依頼者）：ホームページで、スライダーで値を変える。PDF 閲覧アプリで本を読んでいるとき、アニメーションにした図からリンクで飛べる。紙の本に QR コードは足さない。
- 渡すもの：6つの組の候補 `docs/補助教材_アニメーション/候補_M1〜M4・P1・P2_*.md`（169個）

## 選ぶ観点（組に渡したもの）

1. 動きや変化そのものが学ぶ中身（時間で変わる、値を変えるとどうなるか、近づいていく、手順）
2. 紙ではコマを何枚も並べたり、矢印で動きを表したりしている
3. 3次元・回転・切り口など、紙では見えにくい
4. 「まちがえやすいところ」の誤解が、動かすと解ける
5. 1つのアニメーションが、ほかの章・巻でも使える

## 決まったこと

1. **作る項目は48**（`docs/補助教材_アニメーション/アニメーションの項目_第33回.md`）。169の候補のうち、巻をまたいで同じ考えのものを1つの項目にまとめた（例：単位円の影＝数学4-8・5-15・6-6、波-1、電-10）。第1期20・第2期14・第3期14。
2. **1項目＝ホームページの1ページ**（HTML 1つ、外のファイルを読みこまない）。中に場面（タブ）を持ち、PDF の図からその場面へ直接リンクする。項目の名前（アドレスの最後）は変えない。
3. **本とそろえる**：数・記号・ことばはリンクする章と同じ。第1〜3巻からリンクする項目は、ルビ・ひらがなをその巻に合わせる。色だけで分けない（K-15）。
4. **共通の部品10個（K1〜K10）を先に作る**：数直線、時間の記録、単位円と回る矢印、平面の矢印と行列、3次元ビューア、ばね・おもり、1次元の波、場、粒の箱、1歩ずつの計算。
5. **PDF の印**：図の横に「動かしてみる」の印とリンクを置く。印は共通部品（`tex/bk-*.sty`）に足すことになり、教科書の全巻が組み直しになる。そのため、入れ方とどの版で入れるかは、作り始める前に依頼者と相談する。
6. **作らないもの**：静止画で十分に伝わるもの、本物の実験・動画・ソフトのほうがよいもの。B・C の単独の候補は、第3期のあとに余裕があれば足す。

## 議論の記録

- **数学教授**：候補を並べると、「回る点の影」「割線から接線」「短冊」「1歩ずつの計算」が、何巻にもわたって出てくる。これを1つずつ作れば、シリーズの背骨が動くようになる。第1期はここから。
- **機械工学教授**：物理1・2巻は、エネルギーの棒グラフ（AN-18）と、分子からエンジンまで（AN-19）を第1期に。熱学は静止画では「何が動いているか」がいちばん伝わりにくい。
- **電気工学教授**：交流は、発電機から三相の回転磁界まで1本でつながる（AN-20）。数学6-10 の回る矢印と同じ部品で作れるので、まとめて第1期に。
- **教育学教授**：まちがえやすいところを解くものを優先したい。投げたボール（「最高点で加速度は0？」）、割線から接線、減衰（「ブレーキが強いほど早く止まる？」）は、どれも誤解を動きで解ける。
- **幼稚園教諭・小学校教師**：第1・2巻は、数直線（AN-01）とくり上がり（AN-02）。指でさわって動かせることが大事。スマートフォンで動くように。
- **特別支援学校教諭**：スライダーは大きく、キーボードでも動かせるように。再生の速さを遅くできるように。色だけで分けない。
- **心理士**：原子力（連鎖反応 AN-44）は、読みものの章の書き方（N-7）と同じく、あおらない見せ方に。「こわい」演出はしない。
- **科学解説 YouTuber**：1つの画面にスライダーは2〜3本まで。最初は「再生」だけで意味がわかり、さわると深まる、の順にする。
- **デザイナー・イラストレーター**：本の図と同じ色と線の形を使い、PDF から飛んだときに「同じ図が動き出した」と感じられるようにする。
