# 物理第5巻『原子』 Ver2 で確かめること（11月12日）

Ver1 では、作業環境から一次資料に届かなかった4つを、二次資料で照らし合わせた値で書いた。Ver2 の前に、下のサイトを作業環境の許可に足して確かめ直す。

## 作業環境の許可に足すサイト（コピペ用）

```
www.tepco.co.jp
www.pref.fukushima.lg.jp
www.nature.com
www.hitachi.co.jp
cir.nii.ac.jp
www.jps.or.jp
```

- 足す先は、この作業が動いている環境（claude.ai の Claude Code の環境の設定で、名前が「Default」の環境）の「許可するサイト」の一覧。「Default」が3つあるので、11月11日に核データのサイト（nds.iaea.org など）を足したものと同じ環境に足す。
- 11月12日に試したときは、6つとも作業環境の許可がないために止められた（相手のサイトの返事ではない）。足したあとに、相手のサイトが自動の読み取りを断ることもある（そのときは二次資料のまま）。
- www.jstage.jst.go.jp と doi.org は、もう許可に入っていて届く。
