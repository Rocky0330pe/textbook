## 確認する組の決まり

- 例題・じぶんでとこう・章末問題・こたえ・表・グラフの数を、Python で計算し直す。物性値（音速・密度・屈折率など）は、NIST などの出典と Python で確かめる。

## 観点
1. **内容**
   - 物理として正しいか（式の条件・符号・単位、とくに反射係数の符号の数え方、位相、dB の計算）。
   - 数が合っているか。
   - 歴史・実機の値が正しいか（WebSearch を使ってよい）。
   - なぜその式になるか、身近な例・図があるか（依頼者の要求①〜④）。
2. **決定**：手引き `tools/BRIEF-phys3.md` と、次の決定に合っているか（第2巻の U-1〜U-13 `docs/修正事項/物理第2巻_確認/決定_第23回.md`、第24回の W-1〜W-10 もふくむ）。
   - BRIEF-phys1 6章（第19回）
   - `docs/修正事項/物理第1巻_委員確認/決定_第21回.md` の K-1〜K-20
   - `docs/議事録/第22回…` の T-1〜T-6
3. **紙面**
   - 見出しだけがページの最後に残る所
   - 下3分の1をこえる空き
   - 短い囲みのまたぎ
   - 図と字の重なり（`tools/check_overlap.py` の候補も見る）
   - 字の間がのびた行
   - 図の中の字の大きさ
   - 色だけで指す所
4. **巻のつながり**
   - ほかの章・第1巻・数学の本を指す所が正しいか。
   - 記号が巻でそろっているか。
   - 巻末の表と本文の値がそろっているか。
