## とくに見るよう頼まれた所

- **波-10**
  - センサーの式は ζ と ω_n で書かれていて、減衰係数 c は出てこない。W-4 のとおり。
  - 運動方程式、H の式、加速度計（ω≪ω_n）・変位計（ω≫ω_n）の極限、ζ=1/√2 で (ω/ω_n)² の項が消えること、専門書の囲みの符号は、どれも正しい。
  - 圧電素子：Q=d₃₃F、PZT 400 pC/N、水晶2.3 pC/N、32 768 Hz、正しい。
  - ひずみゲージ：力-9 ⑩（120 Ω・ゲージ率2）と合っている。0.048 Ω と 41 MPa も正しい。
  - 例題・じぶんでとこう・章末問題の数は、P5-4 のほかはすべて合っていた。
- **波-11**
  - サンプリング定理の導き方、見かけの周波数、車輪の 41.25°→−3.75°→90°/s、Δf=f_s/N=1/T_m、ハンの窓の表（Python で同じ値が出る）、窓なしの −48 dB とハンの窓の −61 dB・−120 dB 以下は、どれも合っていた。
  - 量子化の雑音：q²/12 → 6.02b+1.76 の導き方は正しい。
  - 平均の雑音：0.924・0.259・0.101 は、Python で同じ値が出た。
  - 情報量とエントロピー・熱-15 とのつながり：熱-15 ④・この先の学び・例題11（2.9×10⁻²¹ J）と合っていて、k_B ln2 ≈ 9.6×10⁻²⁴ J/K も正しい。
  - 気になるのは P5-8（モデム）と P5-21（P_i の大文字）。
- **波-12**
  - 屈折の法則（フェルマーの原理からの導き方、2回微分まで）、レンズメーカーの式、レンズの式、行列から導くレンズの式（B=0、A=−b/a）、合成焦点距離、照度の cos θ/r² は、どれも正しい。
  - プリズムの偏角の表は Python で同じ値が出た。
  - 虹の角：赤42.37°・黄42.08°・紫40.65° も正しい。数がちがうのは、じぶんでとこう10の途中の値だけ（P5-3）。

## よかった所

- 反射係数の符号を、本文③（「音圧で数えた r押。この章では r と書く」）と巻末の表で、ていねいに断っている。
- 加速度計と地震計を1つの式から「よく使う式」として導く流れ図が、とてもわかりやすい。
- 波-11 は、9-4 との約束（窓関数・440.5 Hz のもれ・7 kHz→1 kHz・車輪）をすべて同じ数で果たしている。表計算 → Python → 式の3段もきれいにつながっている。
- 波-12 で反射・屈折の法則を、最短の道・ライフガード・微分の3通りで導き、波-8 のホイヘンスの原理とつないでいる。依頼者の要求①②に合っている。
- 「まだわかっていないこと」（コウモリの混信、カクテルパーティー効果、ミツバチの偏光）が、言いすぎない書き方になっている。
