# 物理第1巻 委員確認の指摘への決定（第21回編集委員会）

委員確認の指摘（R1〜R4）のうち、巻全体にかかるものを委員会で決めた。直す組は、この決定と手引き `tools/BRIEF-phys1.md` 6章に従う。

## 直す範囲

- 「必ず直す」「直したほうがよい」はすべて直す。
- 「好み」は、下の決定にかかわるものと、すぐ直せるものを直す。直さないものは理由を FIX に書く。

## 巻全体の決定

| No | 指摘 | 決定 |
| --- | --- | --- |
| K-1 | 表の見出し・グラフの軸の単位（R2-8） | 数学第6〜9巻にそろえる。**表の見出しは「記号〔単位〕」**（例：時刻 $t$〔s〕）。**グラフの軸のラベルは（ ）のまま**（数学第6〜9巻も軸は「時刻（分）」）。数の組のあとの（m）、式の答えの単位もそのまま。 |
| K-2 | 「振り子」と「ふりこ」（R2-20） | 手引き 6-4-10 のとおり「ふりこ」にそろえる。 |
| K-3 | 語末の長音（R2-7・R2-33・R3-32） | 「ワイヤー」「ドアクローザー」「ベルトコンベヤー」。JIS の用語「ワイヤロープ」はそのまま。 |
| K-4 | 表記のゆれ（R3-31） | 「押す」は漢字（おし縮め→押し縮め）。「いちばん」はかな。「探す」は漢字。 |
| K-5 | 札のあとの改行・札にふれる句読点（R2-4・R3-17・R3-20） | 事務局が物理の共通部品（`tex/bk-physbody.sty` の `\bkboxref`）で直した。札のあとで改行せず、札の前のすき間を 0.12em から 0.22em にした。**章の側では直さない**（`\nobreak` や `\,` を足さない）。数学シリーズの紙面は変えない。 |
| K-6 | 文中の分数（R2-16・R3-8） | 手引き 6-4-1 をきびしく当てはめる。<br>・文字だけの簡単な分数（$\tfrac{w}{2}$、$\tfrac{v}{r}$ など）は $w/2$、$v/r$ に。かっこが要るものは $1/(2\mu)$ に。<br>・添字・指数・和差・根号がある分数、大事な式、例題の式、「たいせつ」の式は、別の行に `\[ … \]` で大きく出す。<br>・数だけの分数（$\tfrac12$ など）はそのままでよい。 |
| K-7 | 「大学で学ぶ」「大学院の内容」（R3-9・R3-26） | 手引き 6-1-3 のとおり「専門の本で扱います」などに。巻全体を `大学` で検索して直す（「大学の初め」などの★の説明と、歴史・人物の説明はそのまま）。 |
| K-8 | 「この章で導く中学・高校の公式」に、ほかの章の公式がある（R2-21・R3-12・R3-29） | 手引き 6-1-2 のとおり、その章で本当に導く行だけを残す。ほかの章で導く公式は「思い出そう」に移すか、けずる。残る行がなければ欄ごとけずる。 |
| K-9 | 形だけの段（R2-9・R3-13） | 手引き 6-1-1 のとおりけずる。 |
| K-10 | チャレンジが例題の数を変えただけ（R2-14） | 各章1〜2問を、例題を組み合わせる問題か、一歩先の問題に差しかえる。こたえも書き、Python で検算する。**表や本文に答えがそのまま載っている問題は、必ず差しかえる**（力-7 の12など）。 |
| K-11 | 奇数ページで入るメモのページ（R2-13・R3-10・R3-38） | 中身で偶数ページにする。たとえば、ページの空きを詰める、短い「もっと知りたい」やチャレンジを足す。中身を足すときは、その章の★と内容に合うものに限る。 |
| K-12 | 安全率の丸め（R3-27） | 安全率は**切り捨て**（安全の側）。4.08→4.0、2.45→2.4、2.67→2.6、4.65→4.6。こたえも合わせる。 |
| K-13 | 数学の章の指し方（R3-24・R3-28・R2-23） | 「（4-6）」のような章だけの指し方は、章全体を指すときはそのままでよい。決まった式・節を指すときは「（4-14②）」の形。「積分：5-10」「4-7の式」「数学の 7-2⑧ でも」は「積分（5-10）」「順運動学の式（4-7）」「（7-2⑧）でも」の形に。 |
| K-14 | 物理のほかの巻の指し方（R2-24） | はじめて出る所は「物理シリーズの『波動』（波-3）」の形。2回めからは（波-3）でよい。 |
| K-15 | 色だけで指す（R2-6・R2-19・R3-19・R3-33） | 色だけで区別せず、形・記号・番号でも指す。「（赤い点線）」は「（点線）」か、形も書く。図を場所（次の図・右の図）で指さない。 |

| K-18 | 図・表の番号（R3-21・R3-22） | 本文から指す図・表には番号をつけ、「図○」で指す。図は、はじめて指す所の近くに置く。 |
