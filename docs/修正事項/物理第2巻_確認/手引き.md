# 物理第2巻『熱学』 確認の手引き（第23回）

第1巻では、原稿の精査（第19回）と、組んだ紙面の委員確認（第21回）を2回に分けて行った。第2巻は、第1巻で決めたことを手引きに書いてから書いた。そこで、この2つを1回にまとめて行う。

## 確認する組の決まり
- 原稿は直さない。git の操作もしない。原稿を上書きするスクリプトも動かさない。
- 一時ファイルは scratchpad の下の自分のフォルダだけに置く。
- 見る範囲は、組んだ PDF のページで、依頼のメッセージに書いてある。全ページを画像で見る（75〜100 dpi の見開き、細かい所は 200 dpi）。
- 原稿（`tex/p2-NN.tex`・`tex/ph2-*.tex`）も読む。
- 例題・じぶんでとこう・章末問題・こたえ・表・グラフの数を、Python で計算し直す。蒸気・冷媒・湿り空気の値は `iapws`・CoolProp で確かめる。

## 観点
1. **内容**
   - 物理として正しいか（式の条件・符号・単位、とくに第一法則と仕事の向き、K と ℃）。
   - 数が合っているか。
   - 歴史・実機の値が正しいか（WebSearch を使ってよい）。
   - なぜその式になるか、身近な例・図があるか（依頼者の要求①〜④）。
2. **決定**：手引き `tools/BRIEF-phys2.md` と、次の決定に合っているか。
   - BRIEF-phys1 6章（第19回）
   - `docs/修正事項/物理第1巻_委員確認/決定_第21回.md` の K-1〜K-20
   - `docs/議事録/第22回…` の T-1〜T-6
3. **紙面**
   - 見出しだけがページの最後に残る所
   - 下3分の1をこえる空き
   - 短い囲みのまたぎ
   - 図と字の重なり（`tools/check_overlap.py` の候補も見る）
   - 字の間がのびた行
   - 図の中の字の大きさ
   - 色だけで指す所
4. **巻のつながり**
   - ほかの章・第1巻・数学の本を指す所が正しいか。
   - 記号が巻でそろっているか。
   - 巻末の表と本文の値がそろっているか。
