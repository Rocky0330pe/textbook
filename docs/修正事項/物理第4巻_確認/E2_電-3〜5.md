## 出典の確かめ（電気の安全をふくむ）

- **家庭の電圧**：e-Gov の API で電気事業法施行規則（平成七年通商産業省令第七十七号）第38条を読みました。「百一ボルトの上下六ボルト」「二百二ボルトの上下二十ボルト」で、本文（⑫・例題1・桁の感覚）と合います。
- **感電の電流**：1 mA で感じ始め、10 mA で離せなくなり、100 mA で心室細動（交流・1秒）という数は、国立病院機構 福島病院の資料などで確かめました。ただし通り道は書かれていないので、E2-16 を出しました。
- **漏電遮断器**：30 mA・0.1 秒以内（高速形）は、パナソニックの解説と製品の仕様書で確かめました。電流則で行きと帰りの差を見るという説明も正しいです。
- **延長コード**：15 A・1500 W、並列で電流がたし算になること、束ねると危ないことの説明は正しいです。
- **やってみよう**：3 章とも乾電池・アルミはく・AM ラジオ・テスターまでで、コンセントや高電圧は使っていません。例題2 の 1 kV には「計算だけで、実際にかけてはいけない」、ライデンびんのコラムにも危険の注意があります。
- **そのほかの出典**：気象庁の雷の注意（車の中は比較的安全、オープンカーは別）、Pt100 の 138.51 Ω、K 熱電対の 12.209 mV・0.798 mV、ΔG＝−237.13 kJ/mol、アルカリ単3 の内部抵抗 0.15〜0.3 Ω は、どれも頭のコメントの出典と本文が合います。Wikipedia を出典にした所はありません。

## よかった所

- **式の導き方がていねい**：$Q=CV$ と ½CV² を、ガウスの法則から2通り（電気力線を数える・平面の電場をたす）で導いています。数学 6-4⑦・6-6⑧・8-11⑦ がそれを使っていた所と、はっきりつないでいます（P45 の約束を回収）。
- **電-3 のプログラムと図**：鏡像法のプログラムで地面の電荷の合計が −19.98 C になり、5000 km より外の分 0.02 C まで説明しています。図10 の曲線とも数が合っています。
- **電-4 の一般の式から**：$\vec j=\sigma\vec E$ からオームの法則、$\vec j\cdot\vec E$ からジュール熱、連続の式から電流則と、流れ図で導いています。ドルーデのモデルのオイラー法の出力（−0.275〜−0.421 mm/s）も正しいです。
- **前の巻との約束**：熱-1 の 72 kJ、熱-10 の 1.23 V、力-9 の 0.12 Ω、波-10 の 0.048 Ω が同じ数でそろっています。燃料電池の起電力を $q\mathcal E=-\Delta G$ で示しているのもよいです。
- **電-5 の組み立て**：数学 3-6⑦ の回路を、網目電流・節点電位・重ね合わせ・テブナンの4通りで解いて、答えを照らし合わせています。テブナンの定理を重ね合わせから証明し、「電池そのものがテブナンの形」とまとめた所もわかりやすいです。
- **身近な例と黄金比**：はしごの黄金比の囲み（出力も合う）、鳥の感電（4000万倍・5 µA）、電圧計をつなぐとはかりたい電圧が変わる例（3.3 V と 5.00 V）がよい題材です。
- **数と決まり**：計算し直した数は、指摘した所（E2-1・7・8）のほかはすべて合っています。Z-3（ρq）・Z-4（銅 1.72）・Z-5（同軸の言い方）・Z-9 も守られています。
