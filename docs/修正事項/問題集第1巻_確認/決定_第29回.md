# 問題集 第1巻 確認の指摘への決定（第29回編集委員会）

確認の組 R1（前付・第1部、30件）と R2（第2〜4部・こたえ・アプリ、40件）。算数の答えのまちがいは0。直す所は、わなの作り方・見わけようの答え・組み方・ことば。

## 決定

| No | 決定 |
| --- | --- |
| H-1 | **わな**：わなの問題は、同じ部のほかのわざで楽にならないものにする（`node mondai/build/check_fits.js 1` の「わなに当たる fits」を0に近づける）。どうしても当たるときは、楽な形（easy）に行き先を書き（「（くり下がらない。わざ 1-18 で）」）、`also` にその番号を入れる。目印に似ているが楽にならない形にする（R1-12〜16、R2-4・10〜12・29〜31） |
| H-2 | **見わけようの答え**：使えるわざをすべて書く（fits と also）。わなの問題も、ほかのわざで楽になるなら書く。わざがないときは「わざ なし」。書かせる欄の「ー」は「なし」にする |
| H-3 | **漢字**：問題集 第1巻は、教科書 第1巻の本文で使っている漢字だけ（`mondai/v1/kanji1.txt`、check.js が確かめる）。「教科書」は「きょうかしょ」、「問」は「もん」とひらがなで書く。1人・2人は「ひとり」「ふたり」とひらがな |
| H-4 | **まだ習わないこと**：第1部・第2部では × を使わない（1-24 の楽な形は「11が 5くみ」）。★2 でも、4けたのひき算・なん十×なん十が要る問題は出さない（R2-13・33） |
| H-5 | **ことば**：「かける かず」は使わず、教科書のことば（「1つ分」「いくつ分」「〜の だん」）にする（R2-9）。気温のグラフは「℃」（R2-14） |
| H-6 | **同じ問題**：入れかえただけの問題（8 ＋ 7 と 7 ＋ 8）は、同じ見開きに出さない（問題の物に `key` をつける。core.js が使う）（R1-19） |
| H-7 | **組み方**：第1巻は教科書と同じ分かち書きの改行（空白と句読点のところだけ、右はそろえない）。左ページの説明の字を大きくする。目印はゴシックの太字。見わけようの見開きに、その部のわざの番号と名前の表を置く。見わけようの答えの欄のはばはそろえる。こたえにステップの区切り。わざの一覧に目印・教科書の章・見わけよう・作ってみよう・こたえの行（R1-1・6・7・10・20・21、R2-2・3・20・40） |
| H-8 | **作ってみよう**：答えが1つに決まる問いは、作る問いに直す。第2部・第4部は問いを足す（R2-19・38） |
| H-9 | **わざを足す**（網羅。番号はうしろに足す）：第5部 ひっ算（1-63〜1-82、依頼者の指示 11月6日）のあとに、第1部 1-83〜1-86（なん十・なん百の まとまり、大きい ほうから たす、0を たす・ひく、ひき算の たしかめ）、第2〜4部 1-87〜1-92（km と m、正午を はさむ 時間、時計の はりの 角、0.5 は 1/2、かわり方は ひき算で くらべる、× 10 は 0を つける） |
| H-10 | **アプリ**：番号のつづき（2枚目からの番号）、こたえのページわけ、スマホの幅で見本を縮める、「33-40」も範囲として読む、作れた問題が足りないときに知らせる、ステップを1つも選ばないときに知らせる（R2-6・22〜25・39） |
| H-11 | あとで（第2版）：目もり・ぼうグラフ・方眼の絵（R2-15）、どちらのわざが楽かの一言（R1-11） |
