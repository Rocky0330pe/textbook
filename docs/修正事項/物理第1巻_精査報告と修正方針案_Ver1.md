## 2. 結論

1. **本文の出来はよい。** 17章とも、計画書 A で割りふった中学・高校の公式をほぼすべて導いており（抜けはふりこの予告など数か所）、例題は全部で214題（力-0・力-16 をのぞく15章は各10〜16題）、ほとんどが7段そろっている。
2. **数値の誤りは少ない。** 例題・じぶんでとこう・章末問題・こたえ・表・グラフ・プログラムの出力を計算し直したうち、合わなかったのは**約15か所**（3章 A は0）。
3. **数学第1〜9巻とのつながりは強い。** 第7・8巻が物理から引いた数・式（2リンクの手 (0.325, 0.391)、力-4 の線積分の例、第4部の流体の式など）は、ほぼすべて一致した。ずれは数か所（4章の方針3）。
4. **力-0（序章）・力-16（読みもの）は、ほぼ仕上がっている。** 書きかけ・仮・TODO はない（力-16 は必ず直す4件が残る）。ただし組んで見た記録がない。
5. **直す量の多くは、第6〜9巻で決めた紙面の決まり（C の20項目）。** 文中の大きな分数の候補が約1060行、図の中の小さな字が132か所などで、機械で候補を出して画像で確かめる作業になる（5章）。
6. **記号の決まりが章の中でくずれている所がある。** 計画書 C-1 の「部が分かれるからぶつからない」という前提が、同じ章の中で成り立っていない（周期 $T$ と張力 $T$、棒の長さ $L$ と角運動量 $\vec L$、重さ $W$ など）。計画書を直してから全章をそろえる（4章の方針1）。
7. **巻末は「仮の表」のまま。** 物性値・定数の表と記号の表を作り直す必要がある（事務局_巻末.md）。

## 4. 巻全体の修正方針（案）

### 方針1　記号の決まりを直してから、全章をそろえる

計画書 C-1・E-2 が古いまま（「ベクトルは太字」が残る）で、守られていない約束もある。次の順で進める。

1. 計画書 C-1 を今の決まりに直す：ベクトルは矢印、太字は \symbfit で専門書の見本だけ。
2. 同じ章の中のぶつかりを解く（決めてほしいこと4）：
   - 周期 $T$ と張力 $T$（力-2・力-6）、棒の長さ $L$ と $\vec L$（力-6・力-7）→ 文字を変える。
   - 重さ $W$（力-2・力-5・力-12）→ 本文は $mg$。
   - 損失係数 $K$（力-14）→ $\zeta$。トルク $T$（力-13）→ $N$。座屈の $k$（力-11）→ $\kappa$（数学 6-6 と同じ）。
   - 垂直抗力 $N$ とトルク $N$・軸力 $N$、$\lambda$（管摩擦係数・固有値・細長比）、$S$（安全率と面積）、$Q$・$P$（力-8）→ 記号カードと巻末の表で断る。
3. 巻末の「分野で記号がぶつかるもの」と記号カードを作り直す（引き継ぎメモ3-4 の直し、$\lambda$・$\zeta$・$H$・$a$・$k$・$S$ の行を足す。運動量は $\vec p$）。

### 方針3　数学の巻との整合を保つ（No.52）

- 数学第6〜9巻は、物理の文・式・数をそのまま引いている（例：6-2・6-5・6-11・8-5・8-11・8-14・9-back が力-2 を、7-5・6-4 が力-5・6 を、第8巻が力-4・力-12〜15 を引く）。物理を直すときは、**引かれている文言・数を変えない**。変えるときは数学の側も同時に直す。

  - 8-8 507行：「物理 力-14 と同じ数（31.4 mL）」だが、力-14 にその数がない（E-34）。

  - 7-2 625行：応力の定義は力-8（D の気づき）。
  - 7-5：表計算の答えの並べ方（C-51）。
- 「数学の章の指し方」が章ごとに「数学 4-14②」と「（4-14）」に分かれているので、1つにする（決めてほしいこと5）。
