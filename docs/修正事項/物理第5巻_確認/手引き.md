## 確認する組の決まり

- 見る範囲は、組んだ PDF のページで、依頼のメッセージに書いてある。全ページを画像で見る（75〜100 dpi の見開き、細かい所は 200 dpi）。
- 原稿（`tex/p5-NN.tex`・`tex/ph5-*.tex`）も読む。
- 例題・じぶんでとこう・章末問題・こたえ・表・グラフの数を、Python で計算し直す。物性値・定数（CODATA 2022 の定数、原子の質量、半減期・γ線のエネルギー、減弱係数、線量の係数など）は、NIST・IAEA LiveChart の API（`https://nds.iaea.org/relnsd/v1/data?fields=ground_states&nuclides=137cs` の形）・環境省の基礎資料などの出典と Python で確かめる。
