# 問題集 第2巻・第3巻 確認の指摘への決定（第30回編集委員会）

確認の組（第2巻 R1 40件・R2 40件、第3巻 R1 34件・R2 45件、あわせて159件）の指摘への決定。**数学の答えのまちがいは、どの組も0**（本に出る問題と見わけよう・作ってみようの答えを、目と別の計算で確かめた）。直す所は、わな、ルビ、教科書との食いちがい、組み、アプリが中心。第3巻の決定もこのファイルにまとめる。

## 事務局が共通部分で直したもの（組は直さない）

- 表紙のわざの見本・使い方の「たとえば」を巻ごとに（`tex/mq2.tex`・`mq3.tex`）。★は問題集の物差しで教科書の★とは別、と前付に書く。奥付にルビ。
- 教科書の札（`chap`）もルビを通す（`mk_book.js`）。`check.js` が `chap` のルビと、制御文字（JS の `'\t'` など）を確かめる。
- □ のすぐあとの単位は同じ行に置く（式の中の欄も）。「ふつうに解くと」「楽な形にすると」の箱は右をそろえない。見わけようの「わざ」の欄を 20mm に（番号を2つ書ける）。「作ってみよう」を第2巻から分かち書きにしない。
- アプリ：分数の線（`.frac > span`）、式の答えで欄が2つ以上のときは欄に分けない、式の字体（数字も Times）、解き方の式を大きく、式の問題は1ページの数を減らす（A4 をこえない）、まぜるときの前書き・見出しを第2巻から漢字にルビ。
- 「分」の読みの部品 `M.fun(n)`（`'《分|ぷん》'`／`'《分|ふん》'`。一の位が 1・3・4・6・8・0 なら ぷん）。

## 組が直すもの（J-1〜J-10）

| No | 決定 |
| --- | --- |
| J-1 | **わな**（H-1 の再確認）：わなは「目印に似ているが、このわざでは楽にならない」問題にする。**そのわざ自身で解ける問題をわなにしない**（第2巻 R1-4・R2-3・R2-8、第3巻 R2-10 など）。ほかのわざで楽になるなら easy に行き先と `also`。 |
| J-2 | **ステップの問題が、そのわざの練習になること**：目印に合わない問題、ほかのわざのほうがずっと楽になる問題（式が同じ数でわれる連立など）を、ステップ1・2に入れない（第3巻 R1-8、R2-13 など）。 |
| J-3 | **「分」の読み**は `M.fun(n)` を使う。ほかのルビの読みの誤り（2人・4日・組 など）も直す。1人・2人は「ひとり」「ふたり」。 |
| J-4 | **教科書の札と★**：教科書にない内容は★2 にして、札は「2-9①の《先\|さき》」の形（ルビつき）。節の番号（③など）をなるべく書く。教科書で教えていない書きかえ（÷ の入れかえなど）は、教科書の章に合わせるか★2 に。 |
| J-5 | **答えの `a` に単位を重ねない**：問題の文で欄のあとに単位があるときは、`a` は数だけ。 |
| J-6 | **わざの番号を文で書くとき**は「わざ 2-83」（教科書の章「2-8」と見分ける）。 |
| J-7 | **楽な形の見せ方**：約分しても同じ形（$\frac{3}{8}=\frac{3}{8}$）を出さない。ふつう・楽な形の例は同じ問題にする。「ふつう」の欄に「まちがい」「まよう」などの気持ちを書かない（M-7）。 |
| J-8 | **問いの文**：答えの書き方（10進数で、分数で、小数第2位まで など）を問いに書く。欄が2つのときは、どちらの欄に何を書くかわかるように。 |
| J-9 | **文字列の \\**：JS の文字列では `'\\times'`・`'\\frac'` と書く（`'\t'` はタブになる）。`check.js` が見つける。 |
| J-10 | **好み**の指摘は、組の判断で直してよい。直さないものは報告に書く。第2版にまわすもの（図がいるもの、どちらのわざが楽かの一言など）は H-11 と同じ。 |
