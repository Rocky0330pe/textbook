## 3. 章をこえる気づき
1. 数学の章の指し方が章ごとにちがう（「数学 4-14②」と「（4-14）」）。巻で1つに。
2. 同じ章の中で記号がぶつかる（力-5 の N・M・W、力-6 の T・L、力-7 の N・L・l）。計画書 C-1 の前提が成り立っていない。
3. 重さの W：力-2 は W=mg を出し、計画書は禁止。
4. 単位の点「N m」と「N·m」がまざる（共通部品で1か所）。
5. カタカナ語「モーター」約55か所（力-6・7・series_phys.py）。ほかの語に広げるか未定。
6. こたえのけた数：「2けたが基本」と数学第7巻の3けたの数がずれる。
7. 数学からの逆の参照（No.52）：7-5・6-4 が力-5・6 の言い方と数を引いているので、C-32・C-51 は数学も同時に。
8. 図の中の \scriptsize 17、白地のラベル25（画像で全部確かめる）。
9. 文中の分数の候補約180（直すとページがふえる）。
10. 「流れ図」の名前（No.26）。
