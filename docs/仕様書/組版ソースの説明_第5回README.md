# 物理を理解するための数学：表紙・もくじ・B5本文フォーマット（第5回編集委員会で最終確認ずみ）

全9巻の表紙（表1）・表2・扉・もくじ・路線図・裏表紙（表4）・カバー展開図と、本文見本3章を組むためのソース一式です。本文見本は、第1巻（第1部扉・1-4章）、第2巻（この本の使い方・第1部扉・2-3章）、第8巻（第3部扉・8-9章）に入っています。**第1巻・第2巻・第5巻をすべて組んであります（第11回の版：第1巻400ページ・第2巻・第5巻はページ制限なしで書き足した版）**。前回の A4 片面版（butsuri-sugaku-template.zip）を、B5・両面・CMYK に作り直しました。

## 作り方

TeX Live 2023 以降（MacTeX フルインストールなど、LuaLaTeX と LuaTeX-ja が入っているもの）と Python 3 が必要です。

```bash
python3 gen.py            # series.py（全巻の章データ）から、各巻のデータと親ファイルを作る
./build.sh                # 全9巻を組む（./build.sh 2 のように巻を指定できる）
cd tex
for n in 1 2 3 4 5 6 7 8 9; do lualatex wrap$n.tex; done   # カバー展開図（入稿用）
lualatex overview.tex     # 全9巻の表紙一覧（各巻のPDFを組んだあとで）
```

各巻は lualatex を2回まわします（ルビの位置とページ参照のため）。build.sh がやります。

## 決まりごと（第2回編集委員会）

- **判型**：B5（182×257 mm）、両面、ソフトカバー無線綴じ。のど20・小口22・天20・地22 mm、本文 140×215 mm。
- **章は見開き（偶数ページ）から**始める。章のページ数は、第1巻10・★〜★★★の章12・★★★★16・★★★★★18・序章/終章4・読みもの8（第3回・第4回で改めた）。
- **前付**：p.1 扉、p.2〜3 もくじ、p.4〜5 路線図、p.6〜7 この本の使い方。第1巻だけ もくじを p.2〜5 にする（文字が大きいため）。
- **色**：すべて CMYK。巻ごとに虹の順の9色（`bkVol1`〜`bkVol9`）。黄（第3巻）と黄緑（第4巻）は、色の上の文字を濃い色にする。
- **ルビ**：第1〜3巻は総ルビ（`\R{親字}{よ|み}`）。第4巻以降はルビなし（`\R` は親字だけを出す）で、使う漢字は常用漢字まで。共通部品にはルビを書いておけば、巻ごとに自動で切りかわる。
- **書体**：第1巻の本文は教科書体の予定。今は仮に Klee One（教科書体に近い無料書体）を使っている。
- **学年**は生徒用の紙面に書かない（指導書にだけ書く。第4回で裏表紙の「保護者・先生の方へ」はなくした）。
- **巻末の解答は「こたえ」だけ**。そのかわり、章末問題に出る問題の形は、必ず例題で1回解いて見せる（1章に例題4つを基本とし、足りなければ足す）。
- **第1巻の分かち書き**：文節の間に半角の空白を入れて書く。`\bkvolonebody` の中では、ひらがな・カタカナの前後で改行せず、空白と句読点のところだけで改行する（行の右はそろえない）。式は全角の「＋」「＝」「－」で書く。第1巻は数字も教科書体ふうの字形（Klee One）。
- **大学の内容の章（18ページ）**：`\bkstage{me|te|shiki}{段の名前}{見出し}{レベル}` で3段に分け、「手でわかる」の終わりに `\bkkokomade`（ここまでで十分の旗）を置く。
- **背幅**は「本文ページ数÷2×0.09 mm」で計算している。紙が決まったら印刷所に確認して `gen.py` の 0.09 を直す。
- カバー展開図には、塗り足し3 mm・トンボ・TrimBox/BleedBox を入れてある。本文ページの入稿用（塗り足しつき）は、これから作る。

## 第3回編集委員会で足した決まりと部品

- **仕上げのきまり**：作ったものは、渡す前に必ず編集委員会で最終確認する。①機械の確認（`build.sh` のエラー0・overfull 1.7 pt以下・章のページ数、`tools/check_ruby.py` で第1〜3巻のルビ0、第4巻以降の常用漢字外0）→ ②全ページを見開きで画面確認（気になる所は拡大）→ ③委員ごとの観点で確認 → ④直したら組み直して再確認 → ⑤議事録を残す。
- **囲みを指す札**：本文から囲みを指すときは `\bkhatenaref`（はてな？）、`\bkreidairef{番号}`（例題）、`\bkyattemiyouref`（やってみよう）を使う。囲みと同じアイコンと色の札になる（一般形は `\bkboxref{アイコン}{色}{文字}`）。
- **章の帯**：題名の高さを測って帯の高さを自動で決める。2行の題名は `\\` で改行する。★は帯の右上（部の名前と同じ行）。
- **表記**：「まちがえやすいところ」の囲み（`tsumazuki`）の名前は全巻共通。「しき」「こたえ」のラベルは `\bkshikilabel`・`\bkkotaelabel` で、第4巻から「式」「答え」に自動で切りかわる。表の数のマイナスはハイフンでなくマイナス記号。
- **第1巻の前付け**：`\bkwakachi`（分かち書きの改行だけ）を使う。表2など、版面の外（shipout）で組む文は、改行の位置を `\\` で決めておく（分かち書きの改行が効かないため）。もくじは1ページに1部。
- **メモらん**：`\bkmemo` で、章の終わりのページの残りをメモの行にする。
- **表紙一覧**（`overview.tex`）：裏表紙は各巻のPDFの最後のページを自動で読む。

## 第6回編集委員会で足した決まりと部品（第5巻への指摘と全巻の修正）

- **「まちがえやすいところ」**：帯は名前だけにし、題は箱の中の1行目に出す（`\begin{tsumazuki}{題}`、第2〜9巻）。×と○は `\bkng{…}`・`\bkok{…}` で1行に1つ。
- **行の終わりに「＝」「＋」を残さない**：文中の式は「＝」「＋」のあとで改行しない（`\relpenalty`・`\binoppenalty`）。入らない式は別行立てにし、それでも入らないときは「＝」の前で切る。こたえのページだけは、数式の「＝」の前で自動で折り返す。確かめは `python3 tools/eqend.py PDF 1ページめのノンブル`。
- **行と囲みの余白**：行の最小のすき間 2.5 pt、囲みの下の余白 3.5 mm、例題の札の前 2 pt、記号カードの前後 10・12 pt（第2〜9巻）。見出しのあとに必要な行数を増やした（小見出し4.2行、節見出し5行）。
- **図のきまり**：箱は `bk node`、箱と箱をつなぐ矢印は `bk link`（名前どうしでつなぎ、両端を1.5 mm はなす）、矢印の字は `bk link label`。図の中の字は footnotesize 以上、文字と線・枠のあいだは1.5 mm 以上。
- **グラフ**（`bkplot`）：格子は線・色の面の下、軸・目もり・目もり数字は上に描く層の組 `bk` を使う（第7回で直した）。axis のオプションに `set layers`・`axis on top` を書かない。
- **部扉**：色の面の上のつめは出さない。
- **1つの章だけ試し組み（どの巻でも）**：`python3 tools/tryv.py 5-7 画像のフォルダ [--kotae]`。lualatex を同時に2つまでしか動かさない（`/tmp/bk-lualatex-slot0.lock`・`slot1.lock` の2つの席。メモリが8 GB のため）。本全体を組むときも `flock /tmp/bk-lualatex-slot0.lock ./build.sh 5` のように席をとる。
- **5-10 は★★〜★★★★の16ページ**の章にした。章の帯の★は、もくじと同じく範囲で書く（`\bklevelrange{2}{4}`）。
