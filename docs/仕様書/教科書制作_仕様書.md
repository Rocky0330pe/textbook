## 2. プロジェクトの概要

小1の「リンゴは何個？」から、工学部で使うベクトル解析・ラプラス変換・フーリエ解析・行列・微分方程式までを、一続きの9巻で学べる教科書を作ります。入試のための発想力の数学ではなく、物理や工学の現象を説明するための数学を、子どもの「なぜ？」に答えながら教えるのがねらいです。

### 依頼の要点

- 国の方針で、工学の研究を発展させるために小学校〜高校の算数・数学カリキュラムを一新する。その教材を作る編集委員会として、各委員の目線で評価・議論しながら作る。
- この教科書を終えて大学の専門書を読むと、すんなり頭に入る状態を目標にする。
- 工学の例：電磁気学・流体力学の3次元ベクトル解析、古典制御・現代制御のラプラス変換による微分方程式の立式と解析、動力学・逆運動学の行列と行列式、回路網理論の分布定数回路の四端子定数モデル。
- 形：B5・フルカラー、裏表と見開きを考えた製本、ユニバーサルデザイン、厚くなりすぎないよう数冊に分ける、もくじは見やすくキャッチーに、表・図・グラフを多く、項目の難しさを★で示す。
- 問題集と教員向け指導書も作るが、教科書が先。
- 設計思想は「物理を理解するための数学」教科書制作 引き継ぎ書に沿い、必要な補足や章を足す。

## 5. 内容の編集方針

どの章も、現象や実験から入り、表と図で確かめ、式は最後に出します。子どもは学年ではなく★と道しるべで進み、7本の路線で大学の工学までつながります。

### 編集方針（10項目、第1回）

1. 量＝数値×単位から出発する。「5」ではなく「5 m」。
2. 具体→表→グラフ→式の順。式は「表とグラフを短く書く方法」として最後に出す。
3. 大学まで続く種を早くまく（ひき算＝変化量、かけ算＝面積、九九の表＝行列）。7本の路線でつなぐ。
4. 微分方程式は「次の瞬間を決めるルール」。式で解く前に表計算で解く。第6巻を全巻の乗りかえ駅にする。
5. 計算の量より意味。九九と筆算は第1巻で手でできるまで練習し、第2巻からは電卓・表計算・プログラムに任せる。
6. どの章も実験や現象とセット。大学の章も、家や教室で確かめられる現象から入る。
7. 物理や工学で使わない単元は省くか軽くする（統計は戻した）。
8. 大学の内容も中学生の言葉で。「目でわかる→手でわかる→式でわかる」の3段で、前の2段は★★★以下の道具だけ。
9. 専門書の書き方に慣れさせる。新しい記号は1章に2つまでで、読み方・意味・英語を記号カードで示す。
10. 学年ではなく、★と道しるべで進む。

### 子どもに伝わる書き方の原則

第4回の依頼者の指摘（大人向けの説明を幼児語に言い換えるだけでは子どもに伝わらない）と第5巻への指摘（公式ありき・丸暗記・途中式の省略・図がない）から作った原則です。第2巻からは書きはじめから守ります。

1. **場面 → ふしぎ・こまったこと → 手を動かす（はかる・数える・表にする・図をかく）→ 気づく → ことば・記号・式**の順に書く。名前は最後。
   - ×「割合とは、比べる量がもとにする量の何倍にあたるかを表した数です。」（定義から始めている）
   - ○「シュートを10本打って6本入ったAさんと、20本打って11本入ったBさん。どちらが上手かな？」→1本あたり0.6本と0.55本→「この0.6のように、もとにする数を1とみたときの大きさを**割合**といいます。」
2. \*\*公式は「作ってから使う」。\*\*表や図でいくつかの数で同じことが起きるのを確かめてからきまりにする。「覚えなくても、こう考えればいつでも作れる」と書けるなら書く。
3. \*\*数字と文章だけで説明しない。\*\*新しい考えには必ず図（数直線・テープ図・面積図・表・グラフ・機械の絵）。図と説明の文は同じページ、できれば左右に並べる。
4. **例題は、考え方と途中式を1行ずつ全部書く。**「〜なので」「ここで両方を2でわる」のように、その行で何をしたかを書く。答えだけ・式だけの例題は作らない。
5. \*\*1つの文には1つのことだけ。\*\*1文は3行まで（第1巻は2行まで）。新しいことばは体験のあとで「このことを〇〇といいます」と1回だけ紹介し、太字にする。
6. **子どものくらしにある場面**を使う（学校・給食・部活・買い物・料理・ゲーム・スマホ・自転車・電車・天気・スポーツ・家の電気製品など）。
7. **問いかけは、子どもが答えを予想できる形で。**「どっちが多いかな？」はよい。「〇〇について考えてみよう」は使わない。
8. **できなくても大丈夫、という声かけ**（心理士）。「まちがえたら、どの行でまちがえたかを見つければいい」。
9. **1ページの情報はしぼる**（特別支援学校教諭）。手順には番号。図と文ははなさない。
10. \*\*工学につなげる。\*\*本物の機械・しくみで、その章の数学がどう働いているかを見せる。大学の工学への「種」を1つ入れる。絵の物理は正しく。

このほか、数学としてあとで困る言い方をしない（「かけ算すると大きくなる」と言い切らない、「0でわる」はできないと書く、√ は＋のほう）、ことばだけで式を決めない（「〜ずつはかけ算」と教えない）、たとえ話には「せいかくに言うと」を添える、も守ります。

## 7. 表記のルール

第1〜3巻は総ルビ、第4巻からはルビなしで常用漢字までです。数と単位・記号・改行のきまりは全巻共通で、共通部品で自動に効くものが多くあります。

### ふりがなと漢字

| 巻 | ルビ | 漢字にする語 | 分かち書き |
| --- | --- | --- | --- |
| 第1巻 | 総ルビ | 小1〜3の教科書でふつう漢字で書く語だけ（人・円・本・時・分・左右・上下・大小・数・算・表・長さなど）。あとはひらがな | する（文節の間に半角の空白） |
| 第2・3巻 | 総ルビ | その学年の教科書でふつう漢字で書く語は漢字（全部ひらがなにしない） | しない |
| 第4〜9巻 | なし | 常用漢字（2,136字）まで | しない |

- 読みは漢字1字ごとに区切る。熟字訓は1つにまとめる（今日・大人・時計・今年・上手）。連濁・促音は文の中の正しい読みにする（1本＝ぽん、3分＝ぷん、1辺＝ぺん、一定＝いってい）。
- 柱・図の中のラベル・共通部品（「思い出そう」の見出し、こたえや記号カードの説明、「序章」）にもルビをつける。PDF のしおりは親字だけ。
- 数式の中や √ の中に漢字を入れない。量は記号で書き、記号の意味は本文で言う。
- まちがえやすい読み（第2巻の最終確認で「要」になったもの）：スイッチの「入（いり）」「切（きり）」、「400本（ぽん）」、「行（い）ったり」、「間かく」→「間隔」。

### 数と単位

- 量＝数値×単位。数と単位は `\qty{5}{m}` で組み、別の行に分けない。式にも単位ごと書く（Δt＝25 s−10 s）。
- 3けたの区切り：第1〜3巻は区切らない（10000）。第4巻から区切る。グラフの目もりには全巻でカンマをつけない。
- 第1巻：数と単位の間は細い空き（5 cm）、° は数にくっつける。助数詞はくっつける（3こ、5人）。「たんい」はひらがな。
- マイクロ（μ）は立てた字（変数の μ と区別）。符号つきの量（＋3 m）の＋を残す。
- ℃：式の中は単位の組み方（°C）、文と表は1文字の℃。どちらかにそろえるかは次の巻で決める。

### 記号と式

- マイナスはハイフンでなくマイナス記号（表や目もりの数も）。全角の「＋」を使う所では「－」も全角にそろえる。
- 第1巻の式は半角の数字と全角の記号で、記号の前後に半角の空白（3 ＋ 2 ＝ 5）。
- ×と÷は 2-11 まで使い、2-12 で約束を学んだあとは文字式の×を省く。
- 分数は文中でも大きく組む。帯分数は紹介だけで、計算は仮分数。
- 不等号は日本の教科書の形（＜・＞・≦・≧）。2進数は 1011₍₂₎。
- ことばの式は、ふつうの文の中に全角の記号で書く（道のり＝速さ×時間）。
- 虚数単位は j。微分は dx/dt・d²x/dt²・ẋ・ẍ・f′(a)。極限に ε-δ は使わない。
- 距離の文字は d。積分の上端と中の文字は区別する（∫₀ˣ ks ds）。

### 禁則と改行

- 文中の式は「＝」「＋」のあとで改行しない。入らない式は別行に立て、それでも入らないときは「＝」の前で切って次の行を「＝」から始める。こたえのページだけは「＝」の前で自動で折り返す。
- 全角の「＝＋－×÷」を行末に、小さい「ぁぃぅぇぉっゃゅょゎ」とカタカナの小書きを行頭に置かない。
- 章番号「2-12」をハイフンで切らない。小問の番号「（1）」のあとで改行しない。記号と答えを分けない。
- 語の途中で切らず、行末の泣き別れ（1語だけ次の行）を避ける。字の間が1割ほどのびた行は言い回しで直す。
- 章の題名は「：」のあとで改行する。「？：」と続くときは「：」をとる。
- 第1巻の分かち書きは、空白と句読点の所でだけ改行し、数と単位・熟語・ルビの語・式の中では改行しない（行の右はそろえない）。

### ことばとラベル

- 囲みの名前は全巻共通（「まちがえやすいところ」「物理・工学ではこう使う」など）。第1巻は「れいだい」「もんだい」「つかわれている ところ」。
- 札の「しき」「こたえ」は第1〜3巻ではひらがな、第4巻から「式」「答え」（自動で切りかわる）。
- 第1巻のことば：「くらい」は位の意味だけ。「くり上がり」は 1-7 で教える。「ばい」は使わない（路線名の「倍々」だけ残す）。「1つ分」の書き方は1つに。名前を紹介したあとは「数直線」。
- 2つの場面は A・B と書く（あ・い は使わない）。案内役に敬称をつけない。
- 歯車は「歯の数が30の歯車」、図のラベルは「歯 30」。
- 本文から章を指すときは「（2-4）」の形。もくじのページ番号には「P.」をつける。長い表がページをまたぐときは「つぎのページへつづく」と日本語で出す。

### ページの要素

- **柱**：偶数ページは左はしに巻の番号と部の番号・部名、奇数ページは右はしに章番号と章名（どちらも小口側）。第1〜3巻は柱にもルビ。
- **ノンブル**：下の小口側に丸。
- **つめ**：小口側、高さ28 mm（間隔32 mm）で、部の位置と番号を示す。部扉の色の面の上には出さない。

## 10. 制作の進め方

1冊は、書く前の確かめ、分担しての執筆、書かなかった委員による最終確認、機械チェック、議事録の順に作ります。依頼者の指摘を直すときは、洗い出し→話し合い→方針→直しの順です。

①書く前の確かめ → ②きまりと手引き → ③分担して執筆 → ④試し組み・自己点検 → ⑤全巻を組み直す → ⑥最終確認（書かなかった委員） → ⑦直す → ⑧機械チェック → ⑨議事録を書いて渡す

④と⑧は合格するまでくり返します。共通部品を直したときは、⑤で完成した巻も組み直します。

### 新しい巻を作るとき

1. **書く前の確かめ**：できている巻がこの巻をどう指しているか、その学年の内容にもれがないか、第4回の補足、前の巻で決めたことばと路線の駅。
2. **書き方のきまりを決める**：依頼者の指摘をはじめからきまりにする（第7回の K1〜K9）。章の題名・★・部の割りふりを直すなら series.py を直す。
3. **執筆の手引きを作る**（tools/BRIEF-volN.md）：依頼者の指摘、書き方の原則、表記、章の型、部品、図のきまり、章の並びと必ず入れる中身、ほかの巻から指されている所、試し組みと見直しの手順、報告の形。第2巻の手引きがいちばん新しい手本。
4. **組に分けて同時に書く**（第2巻は7組、2〜3章ずつ）。共通のファイル（bk-\*.sty・bk-howto.tex・series.py・gen.py・volN-body.tex・ほかの人の章）は書きかえず、直したい所は報告に書く。章で作る絵の部品は、章ごとの頭文字を名前につけてぶつからないようにする。
5. **組どうしの調整**：ことばのそろえ方、記号カードをどの章が作るか、予告と受けを決める（例：N と Ω のカードは 2-15、2-13 の予告を 2-14 の例題で受ける）。
6. **試し組みと自分での見直し**：章ごとにページ数・エラー・はみ出し・参照・ルビ・行末の記号を合格させ、画像で全ページを見る。計算とプログラムの出力は Python で確かめる。委員の観点で見直す。
7. **共通部品を直したら全巻を組み直す**：とくに完成した巻（第1・5巻）でページのずれが0のままかを確かめる。
8. **最終確認**：その章を書かなかった委員が3組に分かれ、全ページを1ページずつ画面で見る（図は拡大）。例題・問題・こたえの数値をもう一度 Python で計算する。指摘は次の3つに分ける。
   - **要**：直さないと出せない。
   - **望**：直したい。
   - **任**：余裕があれば。
9. **話し合いが要る指摘を決める**（第7回の D1〜D9）。章どうしで内容が重なるときは、直す所が少なく、章のテーマに合う方をとる。
10. **直す**：要と望はすべて、任はページ数を守れる範囲で。章を書いた組が自分の章を直す。
11. **全体を組み直して機械チェック**し、要の所を画面で1つずつ確かめる。
12. **議事録を書いて渡す**。

第2巻の最終確認では、指摘が157件（要 13・望 67・任 77）ありました。こたえの値のまちがいは0件でした。要の例は、「1より小さい数でわると大きくなる」という言い切り（負の数では成り立たない）、有理数の定義の抜け、歯車の絵の形（本体がなく歯が浮いていた）、ルビの読み、半分近く空いたページです。

### 依頼者の指摘を直すとき

1. 指摘を洗い出す。どの巻のどのページかを特定し、番号（V1…）をつける。
2. 分科会で原因と意見を出す。第6回は A 教え方（数学・教育学の教授、小学校教師、心理士）、B 図・挿絵（機械・電気の教授、YouTuber、イラストレーター）、C レイアウト（デザイナー、特別支援学校教諭、幼稚園教諭）。校長が全体をまとめる。
3. 方針を決める。その所だけ直すものと、共通部品で直して全巻に効かせるものに分ける。ページ数の判断は校長。
4. 直す。ページ数をこえた章は詰め方の順番で収め、例題などは1つも消さない。
5. 直しを担当しなかった委員が最終確認する。数学の正しさは数学の教授、図の物理は工学の教授が必ず読む。

### 議事録の書き方

- ファイル名は「第N回編集委員会\_議事録\_主題.md」。
- はじめに日時・出席・議題・確認したもの。次に「決まったこと」を番号つきで。
- 指摘や不備は表にする（No｜見つけた人｜場所｜不備｜直し方｜確認）。番号は、第4回（No.1〜33）と第5回（No.34〜99）が通し番号。第6回からは記号つき（V1〜V17・F1〜F11、K1〜K9・D1〜D9、最終確認は組ごとの A・B・C 番号）。
- 委員の発言は「役職：発言」の形。
- 後半に「確認したこと（項目｜方法｜結果）」「変えなかったこととその理由」「ほかの巻への影響」「次回に向けて」。ページ番号がどの版のものかも書き添える。

## 11. 技術仕様（組版のしくみ）

本は LuaLaTeX で組みます。全巻の章データは series.py の1か所にあり、gen.py が各巻のファイルを作ります。ソース一式は butsuri-sugaku-b5-src.zip（第7回版）です。

### 必要なもの

- TeX Live 2023 以降（LuaLaTeX・LuaTeX-ja・tcolorbox・TikZ・pgfplots・tabularray・siunitx・unicode-math）、Python 3（Pillow・numpy・scipy）、poppler（pdfinfo・pdftoppm・pdftotext）、ImageMagick（montage・convert）。

### おもなしくみ

- **ルビ**：`\R{親字}{よ|み}`。第1〜3巻はルビを出し、第4巻からは親字だけを出す。区切りの「|」の数が字数と合わないとき（熟字訓）か、読みが2字をこえる字があるときはグループルビ、それ以外はモノルビにする（Lua）。共通部品にもルビを書いておけば、巻ごとに自動で切りかわる。
- **巻ごとの切りかえ**（`\bkvol`）：ルビ、「しき」→「式」・「こたえ」→「答え」（第4巻から）、書きこみらん（第1巻だけ）、数字の3けた区切り（第4巻から）、式の中のすき間（第2巻から広げる）。
- **こたえの自動収集**：じぶんでとこうの `\bkjans{…}`、章末問題の `\bkpans{…}` が巻末の「こたえ」（`\bkAnswerPages`）に集まる。
- **記号カード**：章の `\bkkigocard{記号}{読み方}{意味}{英語}{章}` が巻末の一覧（`\bkKigoPages`）に集まる。
- **さくいん**：`\bkidx{よみ}{語}`。1回前の組版の結果を読むので 2 回組む。
- **章の帯と★**：`\bkchapter`。★は series.py と同じにし、範囲のときは `\bklevelrange{1}{2}`。題名の高さで帯の高さを自動で決める。
- **道しるべ**：`\bkmichishirube{前に読む章}{この章の先に}`。「この章の先に」から mknext.py が「つぎの巻へ」の表を作る。
- **ページの記録**：章と巻末の始まりでログに BKPAGE を書き出し、check\_pages.py がもくじの計画と照らし合わせる。
- **グラフ**：`\begin{axis}[bkplot, …]`。層の組 `bk` で、格子を線・色の面の下、軸・目もり・目もり数字を上に描く。axis に set layers や axis on top を書かない。
- **禁則と式の改行**：`\relpenalty=10000`・`\binoppenalty=10000`（文中の式を「＝」「＋」のあとで切らない）、`\exhyphenpenalty=10000`（「5-12」のような章番号を切らない）、小さい「っゃゅょぁぃぅぇぉ」とカタカナの小書きを行頭に置かない（prebreakpenalty）、全角の「＝＋－×÷」を行末に置かない（postbreakpenalty）。
- **背幅**：本文ページ数÷2×0.09 mm（gen.py）。紙が決まったら印刷所に確かめて 0.09 を直す。

## 14. ノウハウ集（起きた問題と対処）

直しはできるかぎり共通の部品で行い、直したら全巻を組み直してページのずれを確かめるのが基本です。共通部品の直しは全巻に効く反面、どこかのページをずらすことがあります。

### 組版・レイアウト

| 起きたこと | 原因 | 対処 |
| --- | --- | --- |
| グラフの格子が線・色の面・目もり数字の上を通る | axis on top が層の並びを決め直すため、格子を背景の層に移しても効かなかった | 層の組 bk を新しく作り、axis に set layers や axis on top を書かない |
| 目もり数字の白い下地が近くの線を切る | 下地が大きい | 下地をやめた |
| 式が「＝」のあとで折り返す | 文中の式が「＝」「＋」のあとで改行できた | 改行を禁止し、入らない式は別行立て。eqend.py で検査 |
| 章番号が「5-」「12」に分かれる、小さい「ょ」が行頭、全角の「÷」が行末 | 禁則の設定がなかった | ハイフン、小さいかな、全角の記号の禁則を共通部品に足した |
| 両端そろえで式の「＋」「＝」の周りが0まで縮む | 式のすき間が縮みすぎた | 第2巻から縮む量を小さくした |
| 矢印が箱の枠に刺さる、文字と四角の間がせまい | 箱が中身で広がり、座標で描いた矢印がずれた | 箱の名前どうしを bk link でつなぐ。内側の余白を広げた |
| 「まちがえやすいところ」の帯が箱からはみ出す | 帯に名前と題を1行で入れていた | 帯は名前だけ、題は箱の1行目 |
| 分数のある行どうしが近づく、答えの前に間がない | 行の最小のすき間が 1 pt | 2.5 pt にし、答えの前に空きを入れた |
| 部扉に白い「1」が浮いて見える | 色の面の上につめを描いていた | 部扉ではつめを出さない |
| 第1巻で式の途中で改行し、行頭に「＝」 | 全角記号の前に入る幅0の部品で、分かち書きの判定が効かなかった | 空白に接する側の字だけを見るように直した |
| 長い表に英語の「Continued」が出る | 表の部品の初期設定 | 「つぎのページへつづく」にした |
| もくじの巻末の行があふれる、字の形が変わる | 項目の数を前提に組んでいた | 項目がいくつでも組める部品にした |
| 数式の Ω が出ない | 書体にその字の形がない | 表では文字の Ω を使う |
| しおりやページの記録にルビが混ざる | 巻末の見出しにルビをつけた | しおりと記録では親字だけを出す |

### ページ数

| 起きたこと | 原因 | 対処 |
| --- | --- | --- |
| 共通部品の直しで、後ろのページが全部ずれた | 記号カードの一覧や「この本の使い方」が1ページ増えた | 列の幅や箱の高さを直して元のページ数に戻し、全巻で check\_pages.py を通した |
