# 第1〜8巻 検算Python一式

数学シリーズ第1〜8巻（と物理第1巻）の原稿を作るときに、**数を確かめるために使った Python**（例題・じぶんでとこう・章末問題・こたえ・表・グラフの点・本文の Python の枠の実行結果・物理の数値・照らし合わせ）を、巻ごとに集めたものです。第9巻の分は別の zip にあります。

## 使い方

- `python3 ファイル名.py` で動きます。多くは numpy だけ、一部が scipy・sympy・matplotlib を使います（`pip install numpy scipy sympy matplotlib`）。
- 中に書いてあるパス（`/home/claude/work/build/tex/…` など）は作業環境のものです。原稿を読むもの（`v8-3/py/c85.py`、`back8/cmpmap.py`、`allvol/*.py` など）は、手元の原稿の場所に書きかえてから動かしてください。
- フォルダの中から読みこむものがあります（`v3-5/chk39*.py`・`chk310.py` → `poly.py`、`v8-2/py/ex82b.py` → `chk.py`、`phys1/力-15/rain.py` → `c15.py`、`allvol/chk2.py` → `chk_all.py`）。そのフォルダに移ってから動かしてください。
- 図の点を書き出すもの（`v6-8/curves.py`・`mkdata.py`、`v8-3/py/c85b.py`）は、動かしたフォルダにテキストファイルを作ります。原稿は書きかえません。
- フォルダ名は作業のときのものをのこしています。フォルダ名の番号と章の番号は同じとはかぎりません（たとえば `v7-4/` には 7-6・7-7 の検算が入っています）。章は表の「章」の欄を見てください。
